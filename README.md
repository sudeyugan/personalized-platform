## 当前可用

- Tauri 2 + React 19 + TypeScript 6 桌面工程。
- 作品、卷、章节生命周期、拖放排序、回收站、多标签和会话恢复。
- Tiptap 富文本、`/` 菜单、650ms 防抖保存、异常草稿恢复、版本固定/预览/恢复。
- 中文字数、目标、专注模式和 SQLite FTS5 中文搜索。
- 人物、人物关系、地点、事件、自定义字段与五类时间精度。
- 章节/文本锚点双向引用、写作资料侧栏、固定资料卡、时间线手动排序和资料回收站。
- 图片拖放/粘贴/选择导入、缩略图、正文图片块、元数据、引用追踪、孤儿扫描与素材回收站。
- 可替换 AI provider、Windows DPAPI 密钥保存，以及候选确认后才入库的章节印象图流程；默认 Mock 不联网。
- 每日/手动完整备份、SHA-256 校验、恢复预览与恢复前安全快照，可选择备份目录和保留数量。
- Markdown＋图片、DOCX、PDF 导出，以及 DOCX、Markdown、TXT 预览后导入。
- 作品级 Argon2id + XChaCha20-Poly1305 加密 vault、自动重锁、锁定态索引/图片/会话隔离。
- 温暖、明亮、深色主题，以及背景图、布局、导航顺序和模块启停持久化。
- Rust `command → service → repository`、SQLite v5 资料/素材/AI 投影、事务 revision 保护；浏览器开发模式提供 localStorage 回退。
- 三步首次启动向导，可在建库前选择资料库、备份目录和默认主题，并兼容接入已有资料库。
- 内置帮助中心，以及不含正文、标题、完整路径和 API Key 的脱敏诊断包；不设置固定人工场景或连续试用打卡。
- 正文选词可标记并关联/创建人物、地点或事件；AI 印象图默认把已标记资料替换为匿名占位符，并显示实际发送预览。
- 人物、地点、事件、作品、卷、章节和素材使用统一的主题化删除确认框，清楚区分回收站与永久删除，并优先聚焦安全操作。
- 本地音乐曲库、可排序队列、三种循环方式、快捷键与跨页面持续播放；按全局、作品、章节、专注四层设置播放上下文。
- 写作侧栏伙伴、基础静态表情和离线 Mock 对话；作品、章节、资料和音乐上下文均需在权限中心逐项授权，加密作品另需本次解锁许可。
- 智能创作设置采用统一的紧凑层级和折叠权限范围；窄窗口仍可通过伙伴抽屉使用对话，音乐队列会按小屏重新排布。
- 正文工具栏按操作语义分组，支持三级标题、文字高亮、四种对齐、五档行间距、待办列表、链接、清除格式、列表缩进和查找替换，并继续保留图片与资料标记入口。
- 写作正文占满可用编辑画布且没有左右分隔边框；工具栏空间不足时自动收起次要操作，章节行提供明确的删除入口和可恢复回收站。
- 帮助中心“常用指南”中的自定义背景图小项提供 GPT Image 2 的生成数量、尺寸与可复制统一风格模板。
- M8 桌面伙伴使用透明置顶独立窗口，可拖动、隐藏并与侧栏共享外观/动作状态；窗口只接收裁剪后的显示快照，全部资料库 command 在 Rust 层拒绝非主窗口调用。
- 伙伴记忆支持来源、时间、置信度、查看、编辑、授权、删除和 JSON 导出；删除或撤销后立即停止注入，加密作品对话不能保存为普通长期记忆。
- 伙伴支持发型/服装组合、AI 形象草稿确认后入正式素材库，以及默认关闭、带完整日志和回退/重置的性格成长。
- 桌面伙伴可导入由 `character.json` 描述的标准角色文件夹，运行主体/眼睛/眉毛/嘴巴/覆盖层差分和 wave/nod/surprise/sleep PNG 序列；主窗口退出时会同步结束伙伴窗口。
- M9 本地候选功能：月历可添加日程事务，右侧按日期查看 16 周学期内有效课程和待办；截图中的 13 条课程一次性导入。日记在创作空间单栏编辑，日历保留日期跳转。待办支持不重复、每日和每周自选星期，重复任务自动显示累计完成与完成率。

`1.2.0` 仍以自动门禁为主要发布依据，安装后按自己的方式自然体验即可；没有固定场景或连续天数要求。复杂 DOCX/PDF 版式仍不能保证无损往返，也不建议把唯一一份重要原稿只放在单一应用或设备中。

## 开发命令

```powershell
pnpm install
pnpm dev
pnpm tauri:dev
pnpm test
pnpm typecheck
pnpm lint
pnpm build
pnpm tauri:build
pnpm docs:sync
pnpm docs:check
```

里程碑与发布文档自动化：

```powershell
# 人工验收当前阶段后
pnpm release:accept 'M4–M5'

# 开始下一阶段
pnpm milestone:start M6 M7

# 阶段完成后：同步版本、运行全部门禁、构建安装包并更新文档
pnpm release:prepare 1.0.0 M6 M7 "完成首个长期可用版的稳定性与发布验收"

# 当前体验版本打补丁，不增加版本号
pnpm release:patch

# 纯前端/UI 同版本补丁：省略独立 Rust 测试，仍构建生产桌面版与 NSIS
pnpm release:patch:ui
```

开发中优先运行受影响的定向测试；如果马上执行发布命令，不要提前重复其已经包含的类型检查、lint 或全量测试。`release:patch:ui` 仅限未修改 Rust、Cargo/Tauri 配置、存储、备份、加密和权限边界的 UI 补丁，范围不清楚时使用完整 `release:patch`。`docs:check` 适用于源码和 CI；`release:check` 还会校验本机安装包及 SHA-256。

Rust 测试：

```powershell
cd apps/desktop/src-tauri
cargo test
```
