# 一隅 Yiyu

一隅是一个安静、温暖、本地优先的 Windows 个人数字空间。它把长期写作、日常规划、情绪记录、音乐和可交互的 AI 桌面伙伴放在同一个应用中，同时让模块、数据外发和电脑操作保持可见、可控、可关闭。

为个人使用而设计：功能可以丰富，操作保持简单，不以商业化、积分或复杂养成为目标。

### 写作与资料

- 管理作品、卷和章节，支持拖放排序、回收站、多标签与会话恢复。
- 使用 Tiptap 富文本编辑器，支持标题、列表、待办、链接、高亮、对齐、行距、查找替换、图片和资料标记。
- 自动保存正文、恢复异常草稿，并提供版本预览、固定与恢复。
- 创作空间保留写作、日记、资料；人物/地点/时间线在资料内切换，可显式选择现实记录或作品设定、可选归属作品，旧实体、关系、章节锚点和双向引用不变。图片管理转设置→数据管理。
- 导入 DOCX、Markdown 和 TXT；导出 DOCX、PDF、Markdown 与图片资源。
- 通过 SQLite FTS5 搜索中文内容，浏览器开发模式使用 localStorage 回退。

### 日常空间

- 日历可添加事务，并在侧栏查看当天课程和待办；内置七天六节、16 周课表结构。
- 日记位于创作空间，默认打开当天，支持自动保存和从日历跳转到指定日期。
- 待办支持不重复、每日、每周指定星期，以及按日、周、月完成若干次的周期目标；可将当天设为休假。
- 首页可在早、午、晚分别分配五枚情绪点，记录混合情绪和备注，并查看周/月回望。
- “朝问”每天北京时间 08:00 生成一个以自我觉察为主的思考问题；问题保留 90 天，回答只有主动写下后才进入日记。
- “答案之书”使用 300 条本地语料随机回答，不调用 AI；只有主动收藏才保存问题、答案与时间。
- “真心话”提供 150 道含蓄心动、八卦与亲密经历的本地原创题，统一题库、艺术翻卡、本轮不重复；模块可关闭，不收集回答、不调用 AI 或网络。
- “一隅签”提供今日、恋爱、前程三筒，共96支原创签，各类每天一支；临时“替别人抽”不占个人次数、不保存来客记录，可在设置中关闭。
- “经历册”记录看过的作品与走过的地方：纸卡、可选感想/模糊时间、自定义“从夯到拉”排行；封面按需搜索并保存本地小图，搜不到使用书名纸封/足迹印记。中文网文沿用联网搜索配置检索起点、番茄、晋江、纵横、七猫、17K公开作品信息，书名/作者核对、有限更名和跨站召回，兼容已支持的旧/移动作品链接；不绕过验证，微信读书可选，离线无密钥仍能记录。见[经历册使用说明](docs/经历册使用说明.md)。
- 小鱼伴听通过Windows系统会话跟随QQ音乐，桌宠/WebM分模式呈现；个人歌词库保存LRC及逐曲校准，可选自动收集同步歌词，并可单独启用QQ音乐优先、LRCLIB兜底；已存歌词离线复用，无需新增密钥。明确开关与手动播放控制，不读账号、扫描收藏或保存收听历史。封面/歌词支持按需复用腾讯搜索与DeepSeek寻找线索，私人感想和歌词正文不进入AI。详见[伴听与空间设置](docs/伴听与空间设置.md)。

### AI 伙伴与桌面形象

- 自有轻量 Agent Runtime，不绑定大型 Agent Framework；模型只能通过 Tool Registry 使用应用能力，不能直接访问 Store、Repository 或 SQLite。
- DeepSeek 支持 SSE 流式对话与 Tool Calling；Provider 层保留替换 OpenAI、Claude、Gemini 和本地模型的接口。
- 伙伴可在已授权范围内读取、跳转、创建和修改日记、待办、日历、课表、情绪、作品、章节和人物资料等应用内容。
- Tool 调用统一经过参数校验、细分 capability、风险等级、资源 scope、确认策略、默认最多8步和审计记录。
- 通用任务通过 TaskActionRegistry 接入合格的现有 Tool，支持分步规划、结果引用、逐步确认、暂停与恢复；角色旁短暂任务提示可打开同一会话的详情，不自动批准操作。
- 桌面形象支持透明 PNG/WebP 和透明 WebM 动作库，包含倾听、回答、表情，以及整理衣服/头发、背手轻摇、合手、探身和轻快摇晃等；同一动作可保存多个片段并独立校准位置与缩放。
- `idle` 是常驻基底，多段待机与已配置动作均衡轮换；倾听、回答由真实交互状态调度。切换保留旧画面/末帧，待新片段实际呈帧后接替，不依赖人为交叉淡化；预热按需安排，不一次性解码整个库。
- 独立可关闭的 Pixel Pet 模式保留Q版、像素和精细三套造型，使用批准的静态母图与代码实时眼动/眨眼，不是预渲染动画序列；支持左右扒边、底部趴边、自然半身、拖动吸边、摸头回应、视觉休息与简洁右键菜单。入口为“设置 → 桌面伙伴 → 桌宠与造型”，Ctrl+Alt+Q切换桌宠与原WebM/立绘，原素材与校准保留。
- 原角色伙伴窗口无边框、可拖动，可切换互动、安静穿透、普通非置顶和隐藏状态，并支持全局快捷键与系统托盘兜底。
- ElevenLabs 提供流式中文 STT 和分句 TTS；回答可暂停、继续、中止，并支持有效人声打断。
- 伙伴名字绑定AI身份与本地唤醒名，默认“小鱼”，可选声纹过滤；本地 sherpa-onnx 待机音频不上传，只有唤醒通过后才连接在线语音服务。
- 桌宠轻量对白与WebM完整聊天沿用同一会话；语音框优先当前实际朗读句子，结束短暂保留，长回答按需展开，翻历史不被流式回复拉回底部。两种角色分别适配样式与贴边位置，不新建第二套聊天或绕过确认。
- Windows BLE实时心率默认关闭，首次连接后可记住本机手表，可选启动自动连接；角色旁常驻数字、分模式小心形和装饰脉动。仅桌宠会对持续明显变化低频看一眼标记；不存心率历史、不进AI、不作健康或情绪判断，手表仍须自行开启广播。

### 联网、隐私与电脑能力

- 联网查询通过独立 `web.search` Tool 接入，可选择腾讯云或博查；Bing 只作为可关闭的应急降级，不依赖模型自身具备联网能力。
- 外发内容统一经过本地 Egress Gateway。手机号、身份证、银行卡、邮箱、IP、本机路径和用户私密词可使用会话内稳定化名；密钥、密码和令牌类内容直接阻断。
- 设置提供默认开启的“小鱼完整程序权限”，可关闭后分别授权各类本地资料、写入提议和联网查询；经历册可读取并确认后保存，素材只查看元数据。外部AI、最近对话、应用上下文及长期记忆仍有独立控制，加密作品须本次解锁；电脑权限单独管理。
- 电脑能力覆盖受控的应用/网址打开、窗口、输入、剪贴板、通知、限定目录文件、受管理进程、截图和 FFmpeg 录屏。
- 前端 Permission Engine 与 Rust 主进程进行双重检查；删除、关闭、移动、停止进程、Shell 和其他高影响操作保持逐次确认或默认关闭。
- Tool 调用记录包含时间、工具、权限结论、状态与耗时；诊断信息不记录 API Key、Cookie、完整隐私正文或无关内部实现。

### 本地数据与个性化

- 支持默认每 3 天、保留 3 份的自动快照：WebM、图片、音乐与加密 vault 按内容共享保存，减少重复占用；手动完整备份仍可单文件恢复。自动快照从记录中预览恢复，迁移需复制整个备份目录（含“共享素材”）；所有恢复先校验并创建恢复前完整备份，可配置目录、间隔与保留数量。
- 作品可使用 Argon2id + XChaCha20-Poly1305 加密；锁定后标题、正文、图片、索引和会话上下文均隔离。
- API Key、声纹特征等敏感配置通过 Windows DPAPI 保存，不写入普通资料或 Prompt。
- 设置按外观、桌面伙伴、AI伙伴、功能与导航、数据与备份、隐私与安全分区；提供温暖、明亮和深色主题，可调整布局、导航和模块显示，WebM库按需展开。
- 背景默认一张通用图，可选跨侧栏/正文连续壁纸或保留完整比例的插画，前景纸张独立保护阅读；场景覆盖在高级选项。图片经素材引用复用，旧内嵌图保存成功才迁移。
- 三步首次启动向导可在建库前选择资料库、备份目录和默认主题，也可接入已有资料库。

## 技术结构

```text
React UI / Companion Window
            ↓
       Agent Runtime
       ↙           ↘
Model Provider   Context / Session
       ↓
   Tool Registry
       ↓
Permission Engine + Egress Gateway
       ↓
Application Service
       ↓
Rust Commands → Services → Repositories → SQLite / File System
```

核心技术栈：Tauri 2、Rust、React 19、TypeScript 6、Vite 8、Zustand、Tiptap、SQLite。应用以 Windows 10/11 为目标平台。

## 本地开发

需要预先安装 Node.js、pnpm、Rust/MSVC 工具链和 WebView2。首次进入仓库后：

```powershell
pnpm install
pnpm tauri:dev
```

常用命令：

```powershell
pnpm dev              # 仅启动 Web 开发界面
pnpm tauri:dev        # 启动完整桌面开发版
pnpm typecheck        # TypeScript 类型检查
pnpm lint             # 前端静态检查
pnpm test             # 前端测试
pnpm verify:quick -- <test-file...> # 仅运行指定回归文件
pnpm verify:ui        # typecheck、lint 和 Web build
pnpm verify:full      # 完整跨层门禁
pnpm tauri:build      # Windows Release 与 NSIS
```

Rust 测试：

```powershell
cd apps/desktop/src-tauri
cargo test
```

## 外部服务

应用的主体数据和大多数功能可离线使用。以下能力需要用户自行配置并明确开启：

- DeepSeek：伙伴对话、Agent 推理和“朝问”。
- ElevenLabs：实时语音识别与语音合成。
- 腾讯云或博查：受控网页搜索。
- OpenRouter 图像生成：仅保留配置入口，当前尚未完成正式生图流程。

本地唤醒、声纹过滤、资料库、备份、写作、日历、待办、日记、情绪、答案之书和本地音乐不要求持续连接上述服务。
