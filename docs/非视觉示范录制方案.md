# 非视觉示范：教小鱼做一次

第一阶段支持已连接Edge的授权网页，不是录屏，也不是后台记录电脑所有操作。网站必须在一隅和扩展两侧授权；小鱼不会为了找账号遍历其他网站。录制只在本机运行，不调用模型整理。

## 使用

1. 设置 → AI伙伴权限 → Edge浏览器连接 →「教小鱼做一次」。填写目标，选已添加的网站，获取页面并明确选择一个标签页。
2. 点击「开始这次示范」，等Edge页面右下角出现「正在示范 · 不录屏」再操作。不要离开一隅设置页；可以在Edge操作，设置页留着即可。
3. 操作完成后，在网页浮条或一隅点「停止」，编辑方法名称、步骤和完成判据。未知控件只显示占位，须补充目的或移除。
4. 核对隐私内容并点「确认保存方法」。只有本机保存确认成功才结束预览；保存失败会保留，重试更新同一方法，不复制新条目。
5. 以后从现有方法册选用。小鱼使用当前页面重新观察并执行已有受控工具，网站或权限变化会停止；方法不能替代导航、登录或高风险动作授权。

## 记录什么

仅固定语义，例如打开收件箱、查看未读、通知、动态、关注、翻页、刷新、搜索和同站导航。重复翻页保留为不同步骤，按钮点击及随后同一次表单提交合并。未知按钮/标签不保存名字，由你补充。登录仅人工认证占位，不记录凭据或选择账号。最长5分钟，7个事件加网站入口一步，达到上限自动停止。

不保存输入内容、键盘原文、密码、Cookie/Token、网页正文、附件、HTML、截图、坐标、页面标题或临时控件引用。选页名称只作当轮本机选择，不进方法。未保存示范只在内存；离开设置、取消或撤销权限会清除。断线/超时停止采集并等待整理，不偷偷继续；注入监听没有续期会在4.5秒内失效。

危险按钮会暂停记录，但**不阻止你的手动操作**。取消不能撤回已经发给网站的请求，取消保存等待也不能撤回已经发出的本地保存。方法会随资料备份；你之后明确要求复现时，步骤可能交给当前配置的模型，请勿在编辑时补入私密正文或凭据。外部模型处理关闭仍可本机示范，AI查询和复现仍受原模型许可限制。

## 当前边界

只覆盖选定标签页的顶层DOM控件。同站跳转可继续，跨站跳转、撤销授权停止；iframe、Canvas控件、跨站SSO、验证码、多账号与Windows UIA桌面录制尚不覆盖。因为不保留私密标签或固定选择器，不能保证一次示范即可无歧义自动完成任何网站；变化时需重新观察或补充步骤，不盲重试或重放旧坐标。

录制使用原只读扩展0.4.2，无需安装可信点击组件。该独立组件只用于另行允许的登录按钮真实点击，不是录制所必需。
