# 非视觉示范流程（评估方案，尚未启用）

有必要，它补足“用户知道流程、模型不知道控件”的情况；不是再录一段屏幕视频，也不能保证一次示范后所有网站都自动兼容。

建议第一步限定已授权Edge网站：点击「开始示范」选定一个网站，扩展仅在这一轮记录DOM点击/导航的控件角色、必要定位特征与动作类型。你完成后停止，预览成“打开收件箱 → 选择未读 → 检查数量”等可编辑步骤，再明确保存到现有方法册。桌面软件之后使用Windows UIA语义控件，不能提供控件的应用明确不支持，不用鼠标坐标录像伪装通用能力。

- 不记截图、键盘原文、输入值、账号/密码、Cookie/Token、完整HTML、邮箱正文或附件。密码/验证码/多账号选择只标记为“人工认证”；不能从示范提取凭据。
- URL删查询/片段，私密控件标签与页面标题也可能泄露信息，须在本机过滤、允许改名；保存前展示实际将保留的字段。录制内容默认本地，不为总结偷偷发模型。
- 最长几分钟/有界步骤，始终可见录制提示、暂停/取消；撤销网站、离开范围或超时即停止。取消丢弃未保存示范，不能删除已经发送给网站的请求。
- 复现重新找控件、复核当前权限、每步动作后观察。登录走独立已授权接续；发送/删除/支付等仍需原确认或直接停止，示范不授予任何新权限。不重放绝对坐标、旧DOM引用或不确定写入。
- 方法只保存步骤与完成判据，不保存上次业务结果。控件变更/歧义/挑战时交人，让你修这一步，不盲重试整条流程。

这一批只修版本/登录/CI；录制涉及新的本地采集与保存范围，实施前再确认范围、字段和保存入口。
