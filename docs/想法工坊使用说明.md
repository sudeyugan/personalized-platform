# 想法工坊 · 念起墨间

从左侧「想法工坊」进入，写下一句尚未想清楚的念头，点击「从这一念开始」。不需要先分类或准备完整方案。

## 一轮一笔

模型每轮回应你的表达，提出一个关键问题和几个方向。可以选一个，也可以用自己的话补充；「都不太贴切」会帮助你转为自由表达。模型会主动澄清、提出不同角度或适度质疑，建议不是已证实的事实，也不代表你已确认的立场。

「先整理到这里」会进行一次阶段收束，保留未确定的部分和可选的小尝试，仍接在当前长卷下方，不强制跳页。需要阅读或编辑整理稿时点击上方「成稿」，点「回到推敲」继续深化。

交流时只显示中央长卷，没有常驻两侧面板。右上「手稿册」按需打开抽屉，可用关闭按钮、抽屉外空白或 Esc 收起；焦点返回原入口。「推敲 / 成稿」只切换阅读方式，不会重新调用模型。尚未提交的本轮自由表达在两种视图之间保留，离开本份手稿或退出程序不保留该未提交表达。

## 手稿与来路

- 原话保留在「最初的一念」与「回看与改选」中。
- 「成稿」默认清晰阅读，点「亲手修订」进入编辑，「落笔，回到阅读」结束；切回推敲也会提交本机编辑。没有手动改稿时显示模型暂定整理；修改后，新建议不会自动覆盖。可展开本轮新整理，明确选择替换，原编辑稿保留在旧版中。
- 返回某一轮会另开思路分支，原手稿不被删除。
- 已完成各折原位保留，选中方向留下「此路续笔」，其他方向退为题注，不自动折叠。可主动「收起这一折」并再展开；「这一折的来路与修订」保留实际变化的前后模型暂稿及另开分支入口。模型改稿不等于你已认同，不伪造用户修订或把未选项当作否定。
- 新一轮在下方续写；接近卷尾时适度跟随，回读上文时不强制拉走。推敲/成稿切换会记住本次推敲滚动位置。
- 手稿册可继续旧想法；收起只移入「收纳袋」，可取回。关闭模块只隐藏入口，不删除记录。
- 请求失败或暂停会保留本轮输入，点「继续这一轮」重试。最多40轮；很长时可把当前手稿作为新念头另起一页。

## 模型与隐私

复用「设置 → AI 伙伴」的对话模型、API Key 和「隐私与安全」规则，不需再配置密钥。Mock不会冒充真实模型生成。每次仅处理这份想法的起点、当前手稿、最多6轮近期来路和本轮表达，不自动读取其他聊天、作品或邮箱，也没有浏览器、文件或其他执行工具。

仍经过既有脱敏和必要的发送前审查；检测到秘密会阻止发送。模型已收到的请求无法因之后暂停而撤回，但晚到结果不会覆盖已经变化的手稿。理解和归纳可能有偏差，请保留自己的判断。

完成轮次保存在本机资料库；编辑稿在短暂防抖或离开编辑框时保存，留意页面保存状态。手稿随完整/共享备份保存，与日记一样是普通本机内容，不是作品vault的独立加密内容。尚未点击开始的起点输入未建立手稿。

## 画面

一卷暖纸、远近墨山、干笔皴痕与淡泊水线；深色另用夜墨配色。原话、推敲、关键问题与未定旁注分层，方向以题签而非聊天卡片呈现；收束进入成稿时重新排布阅读层次。

仅新完成轮次从多处淡墨中非线性显字，不按阅读顺序逐字擦入；局部笔画先显露，墨迹逐渐退去，约三秒内定形，点「即刻读完」可跳过。等待时，下一段留白处出现未成字的淡墨，不生成假思考文字；15秒仍未返回时明确提示可暂停，连接失败/隐私确认正常说明。

恢复旧稿、切换阅读方式、滚动回看不重复显影；系统「减弱动态」下立即清晰显示并关闭墨场呼吸/转场。文字始终可选择，宽窄屏保留同一阅读顺序。纸墨和山景在本机通过SVG/CSS绘制，无远程图片/字体或额外模型调用；是墨迹遮罩显影而非真实流体生成汉字，真实WebView2艺术感与硬件性能仍以自然使用为准。
