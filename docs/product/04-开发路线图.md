# 一隅：开发路线图

版本：0.1  
原则：先验证最危险的技术问题，再搭外壳，再做可靠写作；不以页面数量衡量进度。

## 1. 路线总览

## 2. M0：技术验证

### 目标

在写大量业务代码前验证五项高风险能力。

### 任务

1. **编辑器性能**
   - Tauri + React + Tiptap 最小应用。
   - 中文输入法、撤销/重做、图片块、10 万字单章。
   - 记录启动、输入延迟、滚动和保存序列化时间。
2. **文档转换**
   - 制作包含中文标题、图片、列表、引用和分页的 DOCX fixtures。
   - 验证 DOCX 导入、DOCX/PDF/Markdown 导出及再次打开。
   - 记录丢失项和所用库的许可证。
3. **作品级加密 vault**
   - 标题、正文、图片、缩略图、版本均加密。
   - 锁定后扫描数据库、索引、临时文件和日志，确认无明文。
4. **一致性备份/恢复**
   - 编辑时创建 SQLite 快照，模拟中断、损坏和恢复。
   - 验证附件校验、`.partial` 文件和恢复前快照。
5. **未来桌面伙伴窗口**
   - 只做透明、置顶、可拖动的第二窗口原型。
   - 验证窗口权限能与主窗口隔离；不做角色业务。

### 退出条件

- 每个 spike 有结论：采用 / 调整 / 放弃。
- 关键数字和失败样例写入 `docs/spikes/`。
- 技术栈与许可证清单冻结到 M2 结束。

## 3. M1：应用骨架

### 任务

- 初始化 pnpm workspace、React/TS/Vite 与 Tauri 2。
- 建立 Rust command/service/repository 分层。
- SQLite 迁移框架、应用日志、错误边界。
- App Shell：左侧导航、标签栏、主区、右侧栏。
- 主题令牌、浅/深/温暖主题、背景图。
- 模块 manifest、启停、排序、首页卡片。
- 布局方案：写作/极简，自定义保存与恢复。
- 简体中文 i18n；禁止组件中散落不可翻译字符串。
- Windows NSIS 开发安装包与基础 CI。

### 退出条件

- 全新 Windows 10/11 环境可安装、启动、卸载。
- 重启后主题、导航顺序、模块启停和布局方案保持。
- 禁用模块后路由和入口消失但数据表不删除。

## 4. M2：可靠写作核心

### 任务

- 作品、卷、章节 CRUD、拖动排序和回收站。
- Tiptap schema 与混合式工具栏、`/` 菜单。
- 多标签、资料侧栏占位、会话/光标/滚动恢复。
- 防抖自动保存、revision 并发保护、失败状态。
- 历史版本：自动/手动、固定、预览、差异和恢复。
- 中文字数、目标和专注模式。
- FTS5 非加密内容搜索。
- 10 万字章节与大列表性能基线。

### 退出条件

- 正常写作、异常退出、两个标签编辑冲突和磁盘满测试通过。
- 恢复历史版本不会覆盖当前版本。
- 保存状态只在数据库提交成功后显示“已保存”。

## 5. M3：资料与时间线

### 任务

- 人物、人物关系、地点、事件和自定义字段。
- 精确/月份/年份/大约/未知时间。
- 章节与资料的双向关联和锚点。
- 右侧固定资料卡；从资料卡回到章节位置。
- 人生时间线视图与同时间段手动排序。
- 删除前引用检查和回收站行为。

### 退出条件

- 从章节建立关系后，所有相关资料卡可查到反向引用。
- 删除/恢复资料卡不破坏正文内容。
- 模糊时间能稳定排序且保留用户原始文本。

## 6. M4：图片与 AI 印象图

### 任务

- 拖放/粘贴/选择图片、复制到素材库、缩略图和元数据。
- 图片块的说明、替代文本、宽度与对齐。
- 素材引用追踪与孤儿扫描预览。
- AI provider 接口、API Key 安全存储和连接测试。
- 手动章节印象图：发送预览、提示词编辑、候选区和确认导入。
- 画风预设和作品风格引用。
- mock provider 与网络/配额/内容拒绝错误处理。

### 退出条件

- 移动或删除原图不影响已导入图片。
- 未确认前候选图不进入正式素材库。
- 断网或 AI 失败不影响正文与普通图片。
- API Key 不出现在日志、数据库、备份和错误报告。

## 7. M5：加密、导入导出与备份

建议内部顺序：备份 → 开放格式导出 → 导入 → 加密。加密上线后所有前述功能都必须再跑一遍加密场景。

### 任务

- 每日自动备份、目标目录、保留策略、哈希和记录。
- 完整 `.yiyu-backup` 导出、验证、恢复预览和冲突策略。
- Markdown＋图片、DOCX、PDF 导出。
- DOCX、Markdown、TXT 导入与章节预览。
- 作品/日记加密 vault、解锁时限、休眠/锁屏重锁。
- 加密内容对搜索、会话、缩略图、AI、插件和备份的隔离。
- 恢复包/忘记密码说明与危险操作确认。
- 云端接口与设置占位（不实现同步按钮或伪进度）。

### 退出条件

- 在空资料库从备份恢复并校验正文、图片、关系、版本。
- 三种开放格式可由外部软件读取。
- 错误密码和被篡改 vault 不泄露内容、不破坏原数据。
- 锁定状态全盘搜索应用目录不出现测试私密明文。

### M4–M5 合并实现注记（0.5.0）

- 因 M4 单独交付的用户增量不足，图片/AI 与数据安全合并为一次 `0.5.0` 交付；原任务和退出条件没有删减。
- 已完成图片素材/正文块/孤儿扫描、Mock AI 候选确认、DPAPI 密钥、完整备份/恢复、三类导出、三类导入预览和作品级 vault。
- 自动验证覆盖备份创建/校验/恢复、导出 staging/路径安全、错误密码、vault 无明文、素材复制删除和 SQLite v5 幂等迁移；真实 Windows 锁屏、复杂文档版式与跨机器恢复转入 M6 人工验收。
- 后续公开版本按足量闭环估算：轻量相邻阶段合并，高风险阶段可有内部检查点但不据此中断用户体验。

## 8. M6：首个可用版

### 任务

- 完成第一阶段核心路径自动验收；不设置固定人工场景打卡。
- Windows 10/11、常见缩放比例、中文输入法回归。
- 冷启动、10 万字章节和大资料库性能优化。
- 首次启动向导：资料库位置、备份目录、默认主题。
- 内置帮助：自动保存、备份、加密、导出和忘记密码。
- 崩溃报告脱敏、诊断包导出。
- 安装包、校验值、变更日志和已知问题。

### 发布门槛

- 无已知会导致正文丢失的 P0/P1 问题。
- 自动质量门禁全部通过；安装后自然体验核心写作，发现问题后再做针对性回归。

## 9. M7：音乐

### 任务

- 本地音频导入/引用、播放队列、音量、循环和快捷键。
- 全局、作品、章节、专注四层播放上下文。
- 章节自动切歌默认关闭，切换前遵守用户设置。
- 播放服务跨页面持续，播放器和控件可独立隐藏。
- 定义在线音乐 provider，不立即绑定具体平台。

### 退出条件

- 关闭/隐藏音乐页面不停止已允许的背景播放。
- 删除一隅内的播放记录不删除用户原始音频文件。
- 没有指定音乐时按规则回退，不出现突然静音或抢播。

### 1.2.0 实现注记（2026-08-12）

- M7 已按后续规划合并为“氛围与陪伴基础”：完整本地音乐和四层播放上下文之外，同时实现编辑器伙伴侧栏、静态表情、可替换 provider 与逐项权限中心。
- 音频复制入资料库并进入完整备份；播放器可排序、循环、快捷键和跨页面持续，自动切换默认关闭。
- 伙伴无授权时不读取正文；加密作品需要额外本次会话许可，锁定或撤销后立即失效。
- 桌面悬浮窗口、长期记忆、形象组合和成长仍属于 M8，未因合并基础能力而提前实现。
- 2026-08-13 同版本体验补丁统一智能创作的视觉层级和 Provider 表达，增加窄窗口伙伴抽屉并修正音乐小屏布局；这是 M7 可用性修正，不改变 M8 范围。
- 2026-08-16 同版本体验补丁扩展写作工具栏，补齐三级标题、代码、链接、清除格式和列表缩进，并按语义分组；复用现有 Tiptap schema，不改变数据层边界。
- 同日后续反馈移除代码类入口，替换为文字高亮、段落对齐、待办列表与查找替换；旧节点继续只读兼容，不执行破坏性文稿迁移。
- 同日写作体验补丁将正文改为容器响应式宽度，次要工具在空间不足时折叠，当前章节显性提供删除/回收站入口；GPT Image 2 全局背景图生成工作流最初同时进入帮助中心与本地指南，后续已收拢为帮助中心“常用指南”的一个折叠小项。应用仍只负责导入本地成图，不接入在线绘图协议。
- 后续真实体验表明正文最大 1120px 仍不是完整画布，现已取消全部最大宽度并移除左右分隔边线；音乐空状态提示改为仅音乐页可见且可关闭，背景图帮助降为常用指南小项。该修正不改变音乐播放、数据或在线 provider 范围。
- M7 收尾反馈补充段落/标题五档行间距，属性随 Tiptap 正文持久化并兼容无该属性的旧文稿；不增加资料库 schema 或后端迁移。

## 10. M8：虚拟伙伴

### 第一迭代

- 基础角色立绘、服装/发型/表情组合。
- 编辑器侧栏聊天；桌面悬浮显示、拖动、隐藏。
- 对话 provider、逐项数据授权、权限中心。
- 记忆条目有来源、时间、置信度，支持查看/编辑/删除。

### 第二迭代

- AI 生成角色立绘的草稿—确认—资产流程。
- 表情与动作状态机；渲染器适配接口。
- 性格权重自然变化、变化日志和重置/回退。
- 基于明确授权的音乐与使用习惯进行轻量主动互动。

### 退出条件

- 侧栏与桌面窗口状态一致，但权限不被桌面窗口扩大。
- 撤销授权后无法继续读取旧上下文；缓存按策略清理。
- 删除伙伴记忆后，新对话不再注入该记忆。
- 加密作品未临时授权时不可成为对话上下文。

### M6–M8 实际执行映射（2026-08-09）

- M6 作为 `1.0.0`：完成升级迁移、性能、首次向导、帮助和诊断；2026-08-11 根据用户反馈取消固定 Windows 矩阵、连续 7 天试用和跨机器恢复门槛，并用同版本补丁加入正文资料标记与 AI 脱敏预览。
- M7 建议作为 `1.2.0`“氛围与陪伴基础”：完整实现本地音乐和四层播放上下文，同时加入伙伴侧栏、基础静态形象、对话 provider 与逐项权限中心。单独播放器的产品增量不足，因此与伙伴的安全基础合并。
- M8 建议作为 `2.0.0`“伙伴成长与桌面形态”：实现隔离的桌面窗口、可治理记忆、形象组合/生成、动作和可回退成长。该阶段本身已是大规模高风险能力，不再与 M7 全量合并。
- 云同步、插件市场和在线音乐不进入承诺排期；必须先完成冲突、权限、端到端加密、成本和平台条款决策。

## 11. 待办优先级规则

使用以下顺序判断工作：

1. 数据丢失、泄露或无法恢复。
2. 保存、加密、导入导出和迁移正确性。
3. 核心写作可用性与性能。
4. 模块化与可维护性。
5. 外观、动画和便利功能。

任何涉及正文持久化的任务都必须同时提交测试；仅有 UI 演示不算完成。

## 12. 风险登记

| 风险 | 影响 | 对策 |
|---|---|---|
| DOCX/PDF 转换不完整 | 导入导出不可信 | M0 fixtures；公开限制；Markdown 作为兜底 |
| 加密作品在缓存/索引泄露 | 严重隐私问题 | 独立 vault；全盘明文扫描；安全测试 |
| 长章节导致编辑器卡顿 | 无法日常写作 | M0 10 万字基准；必要时章节拆分/虚拟化 |
| 插件获得过大权限 | 数据与系统风险 | v1 不加载第三方代码；manifest＋沙箱＋授权 |
| 云同步造成冲突/损坏 | 内容丢失 | 第一阶段只定义接口；先同步不可变备份 |
| AI 服务商变化 | 功能失效/成本变化 | provider 抽象、模型配置、mock 和本地模型路线 |
| AI 编程产生跨层耦合 | 后期难维护 | 架构守则、短任务、自动测试和 ADR |

## 13. 版本建议

- `0.0.x`：M0–M1 内部原型。
- `0.1.0`：M2 写作核心预览。
- `0.2.0`：M3 资料与时间线。
- `0.3.0`：M4 图片与 AI 印象图。
- `0.5.0`：M5 数据安全闭环。
- `1.0.0`：M6 首个个人可长期使用版本。
- `1.1+`：音乐。
- `1.5+`：虚拟伙伴；具体版本随验证调整。
