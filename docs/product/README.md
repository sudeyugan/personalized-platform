## 一句话定位

「一隅」是一个安静、温暖、可裁剪的个人数字空间：用户只启用自己需要的模块，在同一个 Windows 桌面应用中写作、听音乐、与逐渐成长的虚拟伙伴相处，并在未来扩展更多个人功能。

## 不可妥协的产品原则

- 本地优先：没有网络也能浏览和编辑本地内容。
- 数据可带走：DOCX、PDF、Markdown、完整备份包均可导出。
- 功能可隐藏：模块、导航、首页卡片、伙伴和播放器均由用户决定是否出现。
- 权限透明：虚拟伙伴和 AI 只能读取逐项授权的内容。
- 私密内容隔离：加密作品锁定时不显示真实标题、封面、摘要或正文预览，也不参与搜索。
- AI 可替换：云端优先，但对话与绘图服务必须经过统一接口，未来可接入本地模型。
