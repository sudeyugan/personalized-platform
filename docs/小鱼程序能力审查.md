# 小鱼程序能力审查

2026-10-08，DEC-074，本地 2.0.0 候选。审查范围是全部 16 个程序页面、伙伴全局工具、即时操作和自主任务执行链路；不是操作系统全权限开放，也不是对每个按钮逐一做原生端到端验收。

## 核心结论

“完整程序权限”授予已经接入的程序内工具。它不能把尚未接入的页面按钮自动变成工具，也不解除加密、删除、秘密或电脑权限保护。此前抽签页只有导航，确实漏接了实际抽签动作；并非仅凭小鱼一句“没有权限”就能判断总开关关闭。

## 本轮发现与处理

| 问题 | 处理 |
|---|---|
| 抽签、真心话只有导航，答案之书只有收藏查询 | 补 fortune.draw、truth.draw、answer_book.draw，从页面原有本地题库实际抽取 |
| 能力清单只列查询，漏写入、课表写入、新建作品、音乐控制 | 根据实际注册工具生成完整清单，保留 tools 名称数组，补动作类型、风险与模块状态 |
| 模块关闭仍可报告“打开成功” | 聊天与自主任务使用同一模块检查，执行时再核对；不替用户开启模块 |
| 播放与暂停都当切换，空播放器也返回成功 | 分别执行 play/pause，重复请求保持相同状态；未选本地歌曲或空切歌队列明确失败 |
| 确认期间撤销权限仍可能沿用旧授权 | 执行前重新检查当前授权；确认不能越过新出现的硬拒绝，取消不能被新自动策略覆盖 |
| 查询服务使用对话开始时的数据/授权快照 | 每次读取重新建立当前访问范围，避免继续返回已撤销范围的数据 |
| 未接入动作被笼统解释为“没有权限” | 模型提示区分未接入、模块关闭、权限拒绝、待确认和执行失败；只有真实工具结果支持完成声明 |

## 页面能力矩阵

“已接入”表示有注册工具和实际应用服务，并由相关回归覆盖；不意味着每个界面按钮都开放给小鱼。

| 页面 | 已接入的小鱼能力 | 仍由界面处理或保持限制 |
|---|---|---|
| 首页 | 朝问查询、情绪按日查询/汇总、记录情绪、跳转回望 | 朝问自动生成、删除情绪记录、健康判断不是通用工具 |
| 抽签 | 今日/恋爱/前程签、临时客签，返回真实签文；个人签跳转对应纸签 | 不重抽同日个人签、不清次数、不作现实预测 |
| 真心话 | 从原有 150 题随机无重复抽卡，在聊天呈现 | 不收集回答；聊天抽卡与页面各有临时牌序，不声称同步翻转页面 |
| 答案之书 | 本地随机翻一句、查询授权收藏，在聊天呈现 | 不分析问题、不自动收藏；页面的问题与收藏操作仍手动 |
| 日历/课表 | 事务查询/创建/修改，课表查询/创建/修改，页面导航 | 删除、完整课表导入仍手动 |
| 待办 | 查询、创建、修改、完成状态、休假设置 | 周期规则/配额统计的全部编辑控件未逐一接入；删除仍手动 |
| 创作空间 | 当前作品查询、新建/重命名作品；章节搜索/读取、新建/重命名/追加正文 | 正文任意范围替换、目录重排、版本恢复、导入导出、批注/关联等不是自动工具 |
| 日记 | 搜索、按日读取、追加/完整改写、指定日期导航 | 删除、版本恢复仍手动；改写按策略确认 |
| 人物 | 搜索、单项读取、新建/主要字段修改、导航 | 关系图、任意扩展字段、删除仍手动 |
| 地点 | 搜索、单项读取、新建/主要字段修改、导航 | 素材关联、任意扩展字段、删除仍手动 |
| 时间线 | 搜索、单项读取、新建/主要字段修改、导航 | 排序、复杂关联、删除仍手动 |
| 素材库 | 文件名/类型/说明等元数据查询、导航 | 不默认读取图片/文件正文；导入/替换/删除和角色素材管理仍手动 |
| 经历册 | 列表/单卡读取、新增/修改记录及档位、导航 | 找封面/采用图片、拖动完整排行、删除/收纳恢复仍手动，不把已查资料当已取封面 |
| 本地音乐 | 当前歌曲摘要、播放/暂停/切歌、导航 | 仅一隅本地曲库；QQ 系统伴听及歌词开关/校准未接入这些工具 |
| 帮助 | 页面导航 | 没有任意修改帮助内容工具 |
| 设置 | 页面/分区导航 | 不能修改权限、密钥、安全/备份策略；主题/布局/角色外观等未逐一自动化 |

## 全局与安全边界

- 伙伴记忆可查询、经确认保存；视觉状态可切换；自主任务可创建。均不是管理密钥或变更自身权限的通道。
- 联网查询沿用现有搜索配置与隐私过滤。程序完整权限不等于允许外部 AI 处理；公开网页内容不能变成执行指令。
- 电脑工具包含应用/窗口、剪贴板、截图/录屏、输入、通知、文件、进程、Shell；仍必须通过独立电脑总开关、目标规则、必要确认和原生复核。本轮未扩大或开启电脑权限。
- 加密作品依然需要解锁及本次临时许可。删除、永久删除、恢复备份、密码/密钥管理等没有因本轮审查开放。
- 本地仪式明确短指令不调用模型，外部 AI 总开关关闭时也可执行；结果不传给模型续写，保留的本地仪式消息标记 localOnly 并排除后续模型历史。它们不进入可由 AI 重规划的通用任务，以保持本地结果边界。
- 语音输入或已配置的云端朗读仍按原独立语音授权联网；“本地抽取”不等于整个语音交谈离线。本轮没有新增或开启语音服务。
- 模糊、讨论、否定、复合动作和指定陌生来客的请求不会被短指令匹配直接执行；可能仍需正常模型理解和外部 AI 授权。若用户主动把结果重新输入普通聊天，则仍按普通聊天隐私设置处理。

## 可以直接试的指令

- 小鱼，帮我抽一根签。
- 抽一支恋爱签。
- 抽一根前程签。
- 替别人抽一根恋爱签。
- 帮我抽一张真心话。
- 翻开答案之书。

个人签各筒每日一支，重复请求返回同一纸签。平衡模式允许低风险抽签直接执行；“所有写入都确认”模式仍会询问，取消不会占用个人签。关闭总权限后，抽签/真心话不执行；答案之书可以沿用单独的答案之书授权。模块关闭时提示先开启，而不是自动改变设置。

## 证据与残余

定向回归覆盖真实题库、三主题独立与同日复用、客签不落个人结果、确认/取消/撤销授权、模块关闭、纸签导航、未来模型历史隔离、任务拒绝边界、能力清单覆盖、播放/暂停幂等及空播放器失败。最终完整门禁与 Windows Release/桌面产物证据见 `.agent/PROJECT_STATE.md` 最新检查点。

没有操作用户已有私人记录或替用户打开电脑权限。模型对模糊中文的工具选择、语音转写、真实 WebView2/设备体验仍需自然使用；不以自动测试宣称所有界面操作已经接入。

localOnly 是新版执行的隐私标记，旧程序可能忽略；不要把本候选的历史隔离保证应用到降级旧版。
