# 一隅：体验反馈与需求补充

- 新版本新增一个版本章节。
- 同版本补丁直接更新原来的问题或补充项，不新增版本章节。
- 只有一个开发阶段完整实现并通过自动验收后才交付新版本；阶段内的技术检查点不新增体验记录，也不打断用户交互。
