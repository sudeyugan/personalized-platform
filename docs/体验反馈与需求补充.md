# 一隅：体验反馈与需求补充

- 新版本新增一个版本章节。
- 同版本补丁直接更新原来的问题或补充项，不新增版本章节。
- 只有一个开发阶段完整实现并通过自动验收后才交付新版本；阶段内的技术检查点不新增体验记录，也不打断用户交互。

### 希望补充的点

## 0.1.0

本版实现：交付 M0 自动技术验证、M1 应用骨架与 M2 可靠写作核心；现在支持作品/卷/章节管理、拖放排序与回收站、富文本与 `/` 菜单、多标签和会话恢复、可靠自动保存与异常草稿恢复、版本预览/固定/恢复、中文全文搜索、专注模式、主题/背景/布局/导航/模块设置。Windows 安装、真实中文输入和异常终止等人工体验结果直接记录在本版本下。

### 发现的问题

- [x] 进入专注模式直接就渲染失败了，页面很怪。— 已在 `0.1.0` 补丁修复：专注模式改为稳定的单栏编辑布局，保留退出入口并补充渲染测试。
- [x] 人物地点时间线这些都没有删除的选项，所以我没法删去默认的那几条，而且似乎也没法编辑，是后面才要实现的功能吗。— 已在 `0.1.0` 补丁补齐：人物、地点和时间线事件均可编辑、删除；更完整的资料关系仍按计划在 M3 实现。
- [x] 把设置的空间背景图的按钮优化一下美术风格，以及我需要上传背景图的尺寸应该是？— 已在 `0.1.0` 补丁优化：改为与主题统一的上传卡片、预览和清除按钮；推荐使用 1920×1080 或更高的 16:9 JPG/PNG/WebP 图片，文件不超过 10 MB，低于 1600×900 时会提示清晰度不足。
- [x] 软件的这个框架优化一下，我指的是最外层的UI，也就是包含最小化、缩小、关闭这一层，现在这个风格和软件不统一。— 已在 `0.1.0` 补丁优化：替换为与应用主题一致的自定义标题栏，并保留拖动、双击最大化、最小化、最大化/还原和关闭操作。
- [x] 现在切换章节会弹出界面暂时无法继续，需要点重新载入才可以。— 已在 `0.1.0` 补丁修复：章节切换时按章节 ID 完整卸载旧编辑器并创建唯一的新实例，同时清理旧章节的延迟任务，避免编辑器生命周期交叠导致界面崩溃。
- [x] 希望人物、地点和时间线这些修改不要以点击修改符号弹出小窗的方式来进行，要么直接修改，要么跳转页面，小窗很繁琐。— 已在 `0.1.0` 补丁调整：人物、地点和时间线事件改为在原卡片内直接展开、编辑、保存或取消，不再弹出遮挡页面的小窗。

## 1.0.0

本版实现：交付 M6 首个长期可用版候选，新增首次启动向导、可配置资料库目录、内置帮助、脱敏诊断包、崩溃标记、升级兼容与大资料库性能基线；同版本补丁移除固定十项验收和七天试用要求，并加入正文选词标记人物、地点、事件、直接建档/关联及 AI 印象图发送前脱敏预览。

### 发现的问题

- [x] 不需要7 天试用和完成十个场景，太繁琐了，真有问题就再说，之后尽量少人工验收。— 已在 `1.0.0` 补丁调整：移除试用计时、场景打卡和固定人工清单；帮助中心只保留使用说明与诊断，默认依靠自动门禁，安装后自然使用中发现问题再反馈。

### 希望补充的点

- [x] 希望新增能够在文中通过选中一个词把它选中为人物、地点、时间线等等以及相关你能想到的功能，这样既方便增添资料，也方便之后AI根据文本作图时脱敏。— 已在 `1.0.0` 补丁加入：选中文字后可标记为人物、地点或事件，关联已有资料或用选中文字直接建档；标记随正文保存并形成章节反向引用，也可从工具栏移除。生成 AI 印象图时默认只把已标记资料替换为稳定的“人物1 / 地点1 / 事件1”占位符，并在发送前展示实际预览与替换数量。
- [x] 优化一下删除人物、地点、时间线等弹窗的UI。— 已在 `1.0.0` 补丁调整：人物、地点、事件、作品、卷、章节和素材不再使用系统原生删除确认框，统一为一隅主题的应用内确认界面；明确区分可恢复的“移入回收站”和不可恢复的“永久删除”，展示对象、引用/影响及恢复方式，默认聚焦“先保留”，并支持 Esc、遮罩取消和小窗口布局。

## 2.0.0

本版实现：M8 伙伴成长与桌面形态，包含隔离的桌面伙伴窗口、可治理记忆、形象组合与候选确认、动作状态和可回退成长。

### 发现的问题

- [x] 现在程序退出，但是伙伴的进程不会关闭，导致程序在后台依然运行，无法关闭。— 已在 `2.0.0` 补丁修正：主窗口收到关闭请求时由 Tauri 生命周期统一退出整个应用，桌面伙伴窗口随主进程一并结束；单独隐藏或关闭伙伴窗口不会反向退出主程序。Rust 回归覆盖主窗口与伙伴窗口的不同关闭语义。

### 希望补充的点

- [x] 关于伙伴形象，可以参考桌面角色_差分立绘与固定动作序列帧_Codex任务说明.md的说明来实现，目前的话可以比如说在页面上可以有提供图片的选项，同时在帮助指南类列出一个小项，告诉我应该用image2来生成哪些图像以实现这个。— 已在 `2.0.0` 补丁实现标准角色包 Runtime：设置页可选择包含 `character.json` 和透明 PNG 的整个文件夹，导入前校验缺失文件、统一画布、动作 FPS 与序列帧自然排序；桌面伙伴支持主体/眼睛/眉毛/嘴巴/覆盖层差分、随机眨眼、按住说话、轻微待机，以及 wave/nod/surprise/sleep 固定序列帧，动作期间不会被眨眼、嘴型或表情覆盖。未导入角色包时继续使用原组合式形象。帮助中心新增“桌面伙伴差分立绘”小项，列出推荐 35–54 张素材、目录规范及 GPT Image 2 母版/差分/动作帧提示词。
- [x] 全画布差分让 AI 很难稳定保持五官像素坐标，希望升级为“局部透明 PNG + 固定 Slot 坐标”，并保留旧角色兼容。— 已在 `2.0.0` 后续补丁实现通用 Slot 资源、可选 offset、自然尺寸绘制、缺失 Slot 回退和开发模式边界显示；眼睛、眉毛、嘴巴与覆盖层共用同一定位机制，旧版 1024×1536 差分无需迁移。
