# 一隅 1.0.0 验收与发布说明

`1.0.0` 是 M6“首个长期可用版”的候选安装包。发布以代码、自动测试、静态检查、文档检查和安装包构建为主要门禁；不要求完成固定十项场景或连续 7 天试用。安装后按自己的方式自然体验，发现问题再反馈即可。

## 安装、升级与卸载

1. 首次安装前保留至少一份原文稿；从旧版升级前先在“设置 → 数据管理”创建完整备份。
2. 运行 NSIS 安装包。首次创建资料库时会出现三步向导；留空使用系统应用数据目录，也可填写 Windows 绝对路径或已有资料库目录。
3. 从 `0.2.0`/`0.5.0` 升级时会自动兼容旧资料；重要文稿仍建议先保留备份。
4. 卸载程序不等同于删除用户资料，也不要把任何仍在使用的文稿只保留一份。

## 轻量体验方式

- 正常写作即可，不需要按清单打卡，也不需要持续指定天数。
- 若遇到中文输入、缩放、休眠恢复、备份或升级问题，把现象写入 `docs/体验反馈与需求补充.md` 的 `1.0.0` 原章节；同版本补丁不新增章节。
- 重要文稿建议继续开启自动备份；跨设备恢复可在实际需要迁移设备时再做。

## 正文资料标记与 AI 脱敏

- 在正文中选中一个词或短语，点击工具栏“标记为资料”，可关联已有的人物、地点、事件，或直接用选中文字新建资料。
- 标记会随正文保存并建立章节反向引用；选中已标记内容后可从工具栏移除正文标记。
- 生成章节 AI 印象图时默认开启“发送前隐去正文资料标记”，同一资料会稳定替换为 `【人物1】`、`【地点1】`、`【事件1】` 等占位符；发送前可查看实际预览和替换数量。
- 只有主动标记的文字会被替换。未标记的敏感信息仍会出现在预览中，发送前应检查；如不需要联网生成，可继续使用本地 Mock provider。

## 删除与回收站

- 人物、地点、事件、作品、卷、章节和素材的删除操作使用统一的一隅确认界面，不再弹出系统原生确认框。
- “移入回收站”仍可恢复；“永久删除”会使用更明显的危险样式并说明无法恢复。确认框同时展示操作对象、引用或影响范围与恢复方式。
- 为降低误操作，打开后默认聚焦“先保留”；可以按 Esc、点击遮罩或右上角关闭取消，只有主动点击危险按钮才执行删除。

## 诊断与隐私

“帮助中心 → 导出诊断包”会在“文档/一隅诊断”生成 ZIP。包内只含应用版本、系统架构、资料数量、文件数量/大小、资料库位置类型（默认/自定义）和脱敏代码崩溃位置。提交前仍应自行打开查看 `diagnostics.json`。

## 已知限制

- 复杂 DOCX/PDF 的浮动图片、字体、分页和嵌套列表不能保证无损往返；长期迁移优先使用 Markdown＋图片。
- Windows 真实锁屏/休眠和具体设备缩放手感无法由当前单机自动测试完全判断，但不再作为固定人工发布门；实际出现问题时针对性回归。
- 已创建的资料库不能在首次向导中直接迁移到另一路径；需要通过完整备份在新的空资料库中恢复。
- 当前没有云同步、在线音乐或第三方插件执行能力；断网不影响核心写作，AI 服务不可用时不会阻塞正文。
