## 维护约定

1. 当前事实替换当前摘要，不再在状态/路线图/审计顶部不断堆积全过程。
2. 过程证据保留在历史，用户原始反馈不删除，同版本只更新原章节处理结果。
3. 改动只同步直接相关文档；产品目标、正式里程碑和人工验收须有明确依据，不因整理而改写。
4. 生成区块不得手改；正式状态变化先修改机器源再运行`pnpm docs:sync`，以`pnpm docs:check`检查。
5. 最新候选hash只在PROJECT_STATE维护；正式机器源hash不被候选静默覆盖。纯文档更新不触发Windows编译。
