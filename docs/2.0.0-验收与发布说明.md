## 本版能力

- 桌面伙伴立绘与轻量聊天分别使用透明置顶子窗口；立绘可拖动、隐藏和唤回主窗口，聊天按屏幕空间贴在立绘左右且不会移动立绘；两者共享名称、表情、动作和最近消息快照。
- 桌面窗口只有拖动与事件权限。Rust 资料库、素材、音频、密钥、备份和加密 command 仅接受 `main` 窗口调用。
- 长期记忆记录来源、时间、置信度与授权状态，可编辑、撤销、删除和导出；未授权或已删除记忆不进入新对话。
- 加密作品仍需本次内存许可才能进入上下文；加密作品对话不允许保存到普通长期记忆。
- 发型/服装可组合；AI 形象候选确认前不入素材库，确认后成为正式伙伴素材。
- 性格成长默认关闭；开启后只根据已授权对话与音乐轻微变化，全部变化可查看、回退或重置。
- 设置页可导入标准角色文件夹；Runtime 按 `character.json` 加载同画布透明 PNG，支持差分表情、随机眨眼、说话、轻微待机，以及 wave/nod/surprise/sleep 固定动作序列。未导入时保留原组合式角色。
- 角色包显示素材仍由主窗口明确授权：桌面窗口只能读取当前角色包白名单内的图片，不能读取其他素材或资料库内容。
- 主窗口关闭时 Tauri 会退出整个应用，桌面伙伴不再作为残留窗口让进程继续驻留；单独隐藏伙伴不会退出主程序。

## 自然体验

安装后按日常方式使用即可，无固定场景或连续天数。桌面窗口的多屏位置、缩放和透明效果受 Windows/WebView2 环境影响，发现具体问题时直接写入 `体验反馈与需求补充.md` 的 `2.0.0` 章节。

当前正式显示方式已在同版本后续补丁改为“设置 → AI 伙伴 → 形象与陪伴”选择单张透明 PNG/WebP；桌面窗口无可见边框，默认 Ctrl+Alt+Y 全局显示/隐藏，默认 Ctrl+Alt+T 在安静穿透与原显示方式之间往返；两个快捷键均可更换或关闭。旧角色包数据保留兼容但不再提供活动导入入口。
