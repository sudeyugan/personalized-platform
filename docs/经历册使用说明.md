# 经历册

入口：侧栏「经历册」。可在「设置 → 功能与导航」关闭，关闭不删除记录。

它只记录自己已经看过的作品、去过的地方，不是待看清单、追更或打卡系统，也不会把这些记录自动交给AI伙伴。

## 留下一张纸卡

在「作品」点击「收进一部作品」，或在「足迹」点击「留下一处足迹」。只有名称必填；作者/地区、感想、时间和档位都可留空。时间可以写「2024」「去年夏天」，不用记得准确日期。

作品类别包括中文网文、动漫、漫画、书籍、电影、剧集、游戏和其他作品。「封面墙」用紧凑竖版封面展示作品，卡片宽度不超过190逻辑像素，不会因记录少而放大；足迹使用横幅照片。名称、作者和实际感想在封面下方，长标题/感想简短预览，点击仍能完整查看和编辑；没写感想或时间就不留占位文字。作品封面保留完整比例，足迹照片裁成横幅；没有图时仍用原来的纸封。可按类别筛选，搜索只在自己的名称、作者、感想和时间里查找，不联网。

点击卡片进入整页编辑；默认填写名称、感想和可选档位，作者/地区、时间和纸封在「再添一点细节」展开。最近一份未保存草稿在切换页面时仅暂留本次运行内存，重新打开相同卡片（或新增入口）可继续，不是持久保存；保存或确认放下后清除。「先放下」不会改动旧记录，有未保存修改时会确认。收起卡片进入「收纳袋」，文字、封面和原有档位仍保留，随时可放回。

## 从夯到拉

切换「从夯到拉」查看个人排行。默认五档为「夯 / 顶级 / 人上人 / NPC / 拉完了」，另有「先不排行」。这些只是你自己的喜好，不是公开评分。

拖卡片到某档加入，拖到同档某卡前面调整顺序；也可用小卡下的档位选择和左右箭头操作。「改档位名称」可以重命名五档，按回车或离开输入框保存。作品与足迹分别排行，共用自定义档位名称。

## 不必逐个上传封面

新卡默认就是排版纸封，可选素纸、墨夜、清蓝、蔷薇；足迹使用山线与印记。不用图也可以正常保存和排行。足迹可以选自己的照片，不自动搜索地点图片或读取位置。

需要封面时，在编辑卡片直接点击「找封面」，默认用已填写的名称，来源/链接/作者与年份提示放在「换个来源 / 用作品链接」里。默认自动按类别选择来源，网文优先已配置的微信读书、无密钥用Open Library；电影/剧集仍需TMDB密钥，来源也可手选。作者提示参与匹配，Open Library还以独立作者参数搜索；年份提示仅用于候选排序/核对，不等于经历时间。只发送名称、作者、类别和接口必要参数，不发送感想、经历日期、排行或整本经历册，不读取微信书架或笔记。

| 来源 | 适合内容 | 配置 |
|---|---|---|
| 微信读书 | 中文网文、中文书籍 | 自己的 API Key |
| Bangumi | 动漫、漫画、游戏 | 不需密钥 |
| Open Library | 普通书籍，外文覆盖通常更好 | 不需密钥 |
| TMDB | 电影、剧集 | 自己的 API Read Access Token（不是短 API Key） |

搜索后最多六个候选，候选小图临时下载用于核对。选择候选还不写入素材库，保存卡片后才缓存选中的小图。查不到或图片失败时，可以补充作品信息，也可以继续用纸封，不会覆盖已填名称、感想或已有封面；已有作者也保留。

候选显示名称/作者/年份核对提示和原始条目，短期重复查找复用内存候选与小图。已有同类别、同名称、同作者封面可直接复用本地素材；主页面只保留作品类型选择与本地搜索，选择「所有作品」、中文网文、动漫等决定当前封面墙和排行展示哪些作品，不改记录，不开启批次或连续弹出编辑器。足迹独立展示，不使用作品类型筛选；点开想补封面的那张即可，只有主动查找才联网。

「辅助搜索公开线索」复用设置中已配置的腾讯搜索等服务，发送前显示目的地、搜索词及Bing可选降级；可额外勾选DeepSeek整理别名/版本，需外部AI开关与原有对话密钥，消耗现有API额度并经过隐私审核。只处理此处名称/作者/年份与最多6条公开摘要，不发送私人感想、排行或聊天。模型最多提出4个搜索词，需点击再查正规封面来源，不直接下载模型给出的图片URL；公开链接仍需你核对，起点/晋江不会因此变成已支持自动解析的来源。

「封面来源设置 · 可选」统一放在「设置 → 功能与导航 → 经历册」内，不重复出现在经历册页面或编辑器。微信读书和TMDB需要自行申请并确认平台使用条款；不配置也能记录、编辑与排行。Windows版将密钥保存在本机DPAPI安全存储，不进入资料备份；跨电脑需要重新配置。保存密钥不代表联网验证成功。

API出处：[微信读书官方仓库](https://github.com/Tencent/WeChatReading)、[Bangumi官方接口](https://github.com/bangumi/api)、[Open Library搜索文档](https://openlibrary.org/dev/docs/api/search)、[TMDB开发文档](https://developer.themoviedb.org/docs/faq)。来源覆盖和服务可用性不保证，微信读书/TMDB真实账号仍需配置后体验。

## 中文网文与链接

中文网文先按书名/作者搜索微信读书。链接识别这一批只支持：

- 番茄公开作品页：`https://fanqienovel.com/page/作品数字ID`，不支持正文阅读链接。
- Bangumi条目：`https://bgm.tv/subject/数字ID`，也接受bangumi.tv、chii.in相同路径。

请使用不带查询参数或片段的作品页链接。起点、晋江直接解析尚未接入，可改用书名搜索或纸封；遇到登录、验证码、访问拒绝或页面格式变化会停止，不获取小说正文，不使用第三方逆向服务，也不会静默换来源。

## 本地、备份与隐私

选图支持JPG、PNG、WebP，单张最多5MB；缓存前将长边缩至最多512像素，以WebP存入既有素材库，避免重复保存大封面。离线打开只读本地小图，不重新请求平台；已缓存图片不会因原链接过期自动消失。记录进入现有资料库，完整备份与共享素材自动备份都会带上记录及本地封面。

查询接口固定，公开链接路径与图片域名受限，只支持HTTPS，不跟随重定向，响应有超时和大小上限，远端脚本不执行。只允许主窗口调用封面命令，不给桌宠或AI Tool新增这项数据权限。

图片仅用于个人记录，保留原始来源；这是缓存机制，不是获得了所有封面的再发布许可。对外分享前请确认图片使用权限。不要用旧版程序重新保存新版经历册，旧版不保证保留不认识的字段。

浏览器开发预览可检查纸卡/排行，外部封面和密钥仅Windows桌面版可用；浏览器临时图片不等于桌面版的持久素材存储。

## 美术与来源署名

纸纹、书名纸封、足迹山线和印记为本地HTML/CSS/SVG绘制，无额外远端背景素材。

本应用使用TMDB API，但不由TMDB认可或认证。`apps/desktop/public/tmdb-attribution.svg`为未修改的TMDB标志，作者Travis Bell，[来源记录](https://commons.wikimedia.org/wiki/File:Tmdb.new.logo.svg)，许可[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。标志许可不代表影片海报许可；应用内封面来源设置同时显示标志、声明与署名。



封面网络修复（DEC-071）：桌面版跟随现有 Windows 系统代理，环境代理变量仍优先；不修改系统配置，不关闭HTTPS证书校验。首次点击查询返回空结果，再次主动「找封面」会重新请求，不继续复用半小时空结果；成功候选及小图仍短期缓存。连接错误区分来源、超时和连接失败，不输出含凭据的原错误。网络修复不保证所有作品收录；中文网文来源的密钥与作品链接要求保持不变。
