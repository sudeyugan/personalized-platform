# 经历册

入口：侧栏「经历册」。可在「设置 → 功能与导航」关闭，关闭不删除记录。

它只记录自己已经看过的作品、去过的地方，不是待看清单、追更或打卡系统，也不会把这些记录自动交给AI伙伴。

## 留下一张纸卡

在「作品」点击「收进一部作品」，或在「足迹」点击「留下一处足迹」。只有名称必填；作者/地区、感想、时间和档位都可留空。时间可以写「2024」「去年夏天」，不用记得准确日期。

作品类别包括中文网文、动漫、漫画、书籍、电影、剧集、游戏和其他作品。「封面墙」用紧凑竖版封面展示作品，卡片宽度不超过190逻辑像素，不会因记录少而放大；足迹使用横幅照片。名称、作者和实际感想在封面下方，长标题/感想简短预览，点击仍能完整查看和编辑；没写感想或时间就不留占位文字。作品封面保留完整比例，足迹照片裁成横幅；没有图时仍用原来的纸封。可按类别筛选，搜索只在自己的名称、作者、感想和时间里查找，不联网。

点击卡片进入整页编辑；默认填写名称、感想和可选档位，作者/地区、时间和纸封在「再添一点细节」展开。最近一份未保存草稿在切换页面时仅暂留本次运行内存，重新打开相同卡片（或新增入口）可继续，不是持久保存；保存或确认放下后清除。「先放下」不会改动旧记录，有未保存修改时会确认。

误录入的卡片可在编辑页底部点击「删除这张卡片」，确认后移入主页面「收纳袋」，从封面墙和排行移除，原文字、封面和档位仍可恢复。未保存修改会放下，恢复不会带回这些修改。需要彻底移除时，在收纳袋点击对应条目的「永久删除」并再次确认；只删除这张经历记录，无法再从收纳袋恢复，不连带删除素材库图片或既有备份。

## 从夯到拉

切换「从夯到拉」查看个人排行。默认五档为「夯 / 顶级 / 人上人 / NPC / 拉完了」，另有「未排行」。这些只是你自己的喜好，不是公开评分。

按住小卡的封面或名称拖到某档加入，也可拖回「未排行」。拖到另一张封面的左半区会插在它前面，右半区会插在它后面；目标档位以淡色底、插入位置以细线提示，松开才保存并缓动落位。拖到页面上下边缘会自动滚动，按Esc或在排行区域外松开可取消；轻点仍打开编辑，拖完不会误开。排行小卡只保留封面和名称，不显示档位下拉或左右调整按钮；需要不用拖动设置档位时，可点开卡片在编辑页的「个人档位」选择并保存，键盘同样可用。系统启用减少动态效果时不播放提起/落位动画。「改档位名称」可以重命名五档，按回车或离开输入框保存。作品与足迹分别排行，共用自定义档位名称。

## 不必逐个上传封面

新卡默认就是排版纸封，可选素纸、墨夜、清蓝、蔷薇；足迹使用山线与印记。不用图也可以正常保存和排行。足迹可以选自己的照片，不自动搜索地点图片或读取位置。

需要封面时，在编辑卡片直接点击「找封面」，默认用已填写的名称，来源/链接/作者与年份提示放在「换个来源 / 用作品链接」里。默认自动按类别选择来源，中文网文沿用「联网搜索」中已选择的腾讯/博查/Bing、密钥与后备设置，查找起点、番茄和晋江的官方作品信息；界面提示实际搜索来源与已有额度，无需网文平台账号。Bing不需要密钥，腾讯/博查使用已配置的本机搜索密钥，不会自动开启已关闭的后备。微信读书可手选。公开目录候选没有图片时可以「采用作品信息」，继续使用书名纸封。电影/剧集仍需TMDB密钥。作者提示参与匹配，Open Library还以独立作者参数搜索；年份提示仅用于候选排序/核对，不等于经历时间。只发送名称、作者、类别和接口必要参数，不发送感想、经历日期、排行或整本经历册，不读取微信书架或笔记。

| 来源 | 适合内容 | 配置 |
|---|---|---|
| 网文平台 | 起点、番茄、晋江、纵横、七猫、17K公开作品信息与可用官方封面；由当前联网搜索服务检索 | 沿用联网搜索配置；Bing无需密钥 |
| 微信读书 | 中文网文、中文书籍 | 自己的 API Key |
| Bangumi | 动漫、漫画、游戏 | 不需密钥 |
| Open Library | 普通书籍，外文覆盖通常更好 | 不需密钥 |
| TMDB | 电影、剧集 | 自己的 API Read Access Token（不是短 API Key） |

搜索后最多六个候选，候选小图临时下载用于核对。下载结束后，同等名称/作者/年份匹配时优先显示已成功取得封面的候选；不同作品或作者不会只因为有图而抢占首位，仍需自行核对选择。选择候选还不写入素材库，保存卡片后才缓存选中的小图。查不到或图片失败时，可以补充作品信息，也可以继续用纸封，不会覆盖已填名称、感想或已有封面；已有作者也保留。

起点候选按已识别的官方作品数字ID读取官方公开书封；番茄读取公开作品页JSON中的封面，晋江只读取公开作品页的书封元素。不会执行页面脚本、登录或读取章节正文。下载成功会显示封面与「采用这张」；图片失败才保留「采用作品信息」，不会将无图结果当成已找到封面。更名候选标记「官方更名线索 · 请核对」，不会被仅包含旧书名的另一部作品优先挤到后面。

候选显示名称/作者/年份核对提示和原始条目，短期重复查找复用内存候选与小图。已有同类别、同名称、同作者封面可直接复用本地素材；主页面只保留作品类型选择与本地搜索，选择「所有作品」、中文网文、动漫等决定当前封面墙和排行展示哪些作品，不改记录，不开启批次或连续弹出编辑器。足迹独立展示，不使用作品类型筛选；点开想补封面的那张即可，只有主动查找才联网。

「辅助搜索公开线索」复用设置中已配置的腾讯搜索等服务，发送前显示目的地、搜索词及Bing可选降级；可额外勾选DeepSeek整理别名/版本，需外部AI开关与原有对话密钥，消耗现有API额度并经过隐私审核。只处理此处名称/作者/年份与最多6条公开摘要，不发送私人感想、排行或聊天。模型最多提出4个搜索词，需点击再查正规封面来源，不直接下载模型给出的图片URL；公开链接仍需你核对，起点/晋江信息通过公开目录识别，不直接抓取平台验证页。

「封面来源设置 · 可选」统一放在「设置 → 功能与导航 → 经历册」内，不重复出现在经历册页面或编辑器。微信读书和TMDB需要自行申请并确认平台使用条款；不配置也能记录、编辑与排行。Windows版将密钥保存在本机DPAPI安全存储，不进入资料备份；跨电脑需要重新配置。保存密钥不代表联网验证成功。

API出处：[微信读书官方仓库](https://github.com/Tencent/WeChatReading)、[Bangumi官方接口](https://github.com/bangumi/api)、[Open Library搜索文档](https://openlibrary.org/dev/docs/api/search)、[TMDB开发文档](https://developer.themoviedb.org/docs/faq)。来源覆盖和服务可用性不保证，微信读书/TMDB真实账号仍需配置后体验。

## 中文网文与链接

中文网文默认按书名检索起点、番茄、晋江、纵横、七猫、17K公开目录；作者提示会参与检索和核对，但绝不把用户提示填成未经核实的候选作者。初轮最多6条站点书名查询＋1条可选作者组合查询，保留书名独立召回，避免加作者反而漏掉作品；官方摘要明确更名时最多2条现名复查，未找到准确作品时最多2条跨站召回，均沿用当前服务额度。所有返回地址仍须通过官方作品页白名单。先按身份匹配排序再限制候选，补全后再核对、去重并最多展示6项，不让先返回的同人挤掉后来的原作。问答、推荐、章节、百科、盗版或电视剧页面自身不作为小说候选，不运行AI、执行摘要指令或无限追查；纵横官方百科仅在参考文献明确指向唯一同名官方作品时跟进一次、再核对真实作品页，最多核实2条百科线索。旧HTTP作品引用只在本地按严格官方路径转为HTTPS，不请求HTTP。例如《我加载了恋爱游戏》依据官方更名线索找现名，《雪中悍刀行》和《剑来》可查纵横原作。查询依赖搜索索引，不保证全部作品或图片；17K当前作品页验证时只提供公开目录信息，不绕过取图。纵横只取公开头部明确作品地址/名称/作者/书封，七猫只取作品信息头部并核对作品ID，不请求其章节；不解析脚本、推荐或试读正文。链接识别支持：

- 起点作品页：`https://www.qidian.com/book/作品数字ID/`，也接受旧版 `https://book.qidian.com/info/作品数字ID/` 和移动版 `https://m.qidian.com/book/作品数字ID/`，规范为同一官方作品页后通过当前搜索服务识别。
- 番茄公开作品页：`https://fanqienovel.com/page/作品数字ID`。也接受 `/keyword/关键词数字ID`，但关键词ID不是作品ID；只有公开数据明确提供唯一主作品的官方作品页时才跟进一次，再读取真实作品信息与封面并去重。不采用推荐、评论或章节地址，不支持正文阅读链接。
- 晋江作品页：`https://www.jjwxc.net/onebook.php?novelid=作品数字ID`，通过公开目录识别。
- 纵横作品页：`https://www.zongheng.com/detail/作品数字ID`，也接受旧版 `https://book.zongheng.com/book/作品数字ID.html`、移动版 `https://m.zongheng.com/book/作品数字ID`；已知 `tabsName=bookinfo` 或 `tabsName=catalogue` 仅规范为无参数作品页，未知参数仍拒绝。作品链接可直接识别公开元数据，不依赖书名索引。
- 七猫作品页：`https://www.qimao.com/shuku/作品数字ID/`，只接受数字作品页，不接受筛选页、带章节后缀地址。
- 17K作品页：`https://www.17k.com/book/作品数字ID.html`，兼容 `h5.17k.com` 相同路径；通过公开目录识别，不访问验证页。
- Bangumi条目：`https://bgm.tv/subject/数字ID`，也接受bangumi.tv、chii.in相同路径。

请使用不带分享追踪参数或片段的作品页链接；晋江只接受必要的单一 `novelid` 参数。公开目录不能识别链接时可改用书名/作者搜索或纸封；遇到登录、验证码、访问拒绝或页面格式变化会停止，不获取小说正文，不使用第三方逆向服务。

### 常见搜索情况与边界

| 输入/情况 | 处理方式与范围 |
|---|---|
| 完整书名，如 `雪中悍刀行` | 查六站公开作品目录，优先准确名称；不依靠单本书硬编码 |
| `《雪中悍刀行》`、中文名中多余空格、全角字符/不可见字符 | 清理外围书名号和输入噪声；英文多词标题、数字/卷名仍保留 |
| 作者框填 `烽火戏诸侯` | 书名＋作者参与检索，候选显示实际作者或待核对，不假称作者匹配 |
| `《雪中悍刀行》 烽火戏诸侯著` 或 `雪中悍刀行 作者：烽火戏诸侯` | 明确拆分书名与作者；作者框若已有输入优先使用 |
| 裸输入 `雪中悍刀行 烽火戏诸侯` | 按整段检索；只有候选实际名称与作者组合一致才标记名称匹配，不猜任意空格后的词是作者 |
| 短名/部分书名，如 `剑来`、`雪中` | 保留完整短名查询，有限跨站召回；部分名称结果需人工核对，不保证唯一 |
| 原名/更名 | 只追官方摘要明确更名关系，至多2条复查；不猜昵称/谐音对应作品 |
| 同名、同人、前传/续作、电视剧/动漫同名 | 名称和真实作者排序；括号中的主演/改编/版本信息不误当作者，同人标为名称待核对，改编用对应作品类别与来源，不能自动当成原作 |
| 原作不在前三站、同作品多平台收录 | 已补纵横/七猫/17K；按规范官方作品URL去重，跨平台保留来源便于选版本 |
| 官方链接、旧版/移动版链接 | 支持上述严格路径并规范为同一作品；正文、分类/书单、账号/凭据、重定向、未知参数与伪装域名拒绝 |
| 封面暂时失败、只有作品信息 | 网文无图候选再次主动查找会重新获取元数据；实际下载失败不存失败图片缓存，不能把信息当成封面成功 |
| 密钥缺失、来源故障、关闭Bing后备、离线 | 尊重当前服务与后备设置，不静默换服务；保留本地记录、纸封与手工图片 |
| 出版书、海外书籍、动漫/影视/游戏 | 根据类别走微信读书/Open Library、Bangumi或TMDB；本网文六站不是全类型数据库，来源可手选 |
| 错字、繁简体、拼音/谐音、只填作者、出版社/ISBN | 没有自动纠错/繁简转换或作者书目/ISBN专门检索，不把猜测当作品；可尝试正式书名＋作者/官方链接，未收录不承诺命中 |

## 本地、备份与隐私

选图支持JPG、PNG、WebP，单张最多5MB；缓存前将长边缩至最多512像素，以WebP存入既有素材库，避免重复保存大封面。离线打开只读本地小图，不重新请求平台；已缓存图片不会因原链接过期自动消失。记录进入现有资料库，完整备份与共享素材自动备份都会带上记录及本地封面。

查询接口固定，公开链接路径与图片域名受限，只支持HTTPS，不跟随重定向，响应有超时和大小上限，远端脚本不执行。只允许主窗口调用封面命令。小鱼的「完整程序权限」开启时可读取经历记录、确认后新增或修改；关闭总权限后按「经历册」逐项授权。AI Tool不直接抓封面网页或读取密钥，桌面子窗口仍不获得资料库命令权限。

图片仅用于个人记录，保留原始来源；这是缓存机制，不是获得了所有封面的再发布许可。对外分享前请确认图片使用权限。不要用旧版程序重新保存新版经历册，旧版不保证保留不认识的字段。

浏览器开发预览可检查纸卡/排行，外部封面和密钥仅Windows桌面版可用；浏览器临时图片不等于桌面版的持久素材存储。

## 美术与来源署名

纸纹、书名纸封、足迹山线和印记为本地HTML/CSS/SVG绘制，无额外远端背景素材。

本应用使用TMDB API，但不由TMDB认可或认证。`apps/desktop/public/tmdb-attribution.svg`为未修改的TMDB标志，作者Travis Bell，[来源记录](https://commons.wikimedia.org/wiki/File:Tmdb.new.logo.svg)，许可[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)。标志许可不代表影片海报许可；应用内封面来源设置同时显示标志、声明与署名。



封面网络修复（DEC-071）：桌面版跟随现有 Windows 系统代理，环境代理变量仍优先；不修改系统配置，不关闭HTTPS证书校验。首次点击查询返回空结果，再次主动「找封面」会重新请求，不继续复用半小时空结果；成功候选及小图仍短期缓存。连接错误区分来源、超时和连接失败，不输出含凭据的原错误。网络修复不保证所有作品收录；中文网文来源的密钥与作品链接要求保持不变。
