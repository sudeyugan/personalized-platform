# 情绪回望可视化方案

更新：2026-10-11 · DEC-079 · 本地候选，不是新正式版本。

用户最初反馈：“当我回看情绪的时候，怎么样能使得这个更直观一些呢，感觉现在这个条也不是这么直观”“我的意思是有什么更好的可视化方法吗”“可以都试一下，或者调研一下看看还有没有其他方案，如果有的话都实现一下我根据效果再来选择”。

后续反馈：“因为我们是一天只有3个时间段，共15各点，所以只看一天的话信息量很少，也不需要什么方式，同时一些情绪出现的频率也很少，综合这些再调整，以及堆叠图的确不合适可以删去”“一次记录里分了3点，只算出现1次，这个不需要吧，保留点数显然是有必要的”。

最终选择：“就保留气泡矩阵和色带即可”。随后要求删除“示例预览（不保存）”，现仅显示真实记录。多图试用结束，其他图表组件、入口、专用样式和辅助算法已清理；不删除或转换个人记录。

## 最终两种视图

入口：首页心情卡 → 展开「情绪回望」→「回望视图」。默认整月气泡矩阵，已有色带选择仍尊重；已移除或未知视图偏好回退气泡。周/月、历史月份和选中日期共用，单日详情默认收起，点击日期/气泡展开原始早中晚点数和备注，仍可看周期时段汇总。

| 视图 | 最适合看什么 | 读法 |
| --- | --- | --- |
| 气泡矩阵 | 整周/月各情绪在哪些日子出现、记录了多少点 | 日期为列、非零情绪为行；圆面积表示实际点数，所有日期共用0—15点刻度，不因只录一时段放大；月视图横向滚动，行名固定 |
| 色带 | 整体氛围和原始早中晚的混合情绪 | 保留渐变、周织带/月日历与周期情绪构成；全部非零情绪保留，不截断少量情绪 |

气泡的「·」表示已记录但该情绪0点，「—」及纹理表示未记录，下方标出已记录时段数。只有本段非零情绪进入矩阵，未出现情绪可展开查看；完全无记录时不声称哪些情绪未出现。名称、点数、文字提示和键盘可用的日期按钮辅助颜色，不只依赖颜色辨识。

## 统计口径

- 每个已记录时段仍五点、每日三时段共十五点；十二种情绪不合并为正负分数，不推断情绪强度或健康结论。
- 3点就是3点，不转换为出现一次；同一天同情绪跨时段累加，1点少量情绪也单独可见，不归入其他。
- 绘图0—15点是固定面积刻度，不补未记录点；色带构成按所选周期的实际累计点数计算。
- 无记录时明确显示空状态，不生成虚构点数。程序仅保存本机视图标识，存储不可用仍能切换，不保存额外图表数据或备注。

## 调研与取舍记录

参考[Observable Plot点图规范](https://observablehq.github.io/plot/marks/dot)：数量以面积编码；本实现使用平方根直径，避免将直径比例误当面积比例。由本机CSS实现，无图表依赖或运行时联网。

此前曾试用周期总览、热力图、五点记录日历、分情绪趋势、环形占比和堆叠柱。用户先排除堆叠，最终选定气泡与色带，因此其余实现不再保留。调研中的可数单元与折线语义参考[Waffle规范](https://observablehq.github.io/plot/marks/waffle)、[折线规范](https://observablehq.github.io/plot/marks/line)，仅作历史取舍记录。

未采用雷达、河流/Sankey和好坏评分折线：现有数据没有类别连续、真实情绪转移或好坏数值，不为增加方案而伪造关系。
