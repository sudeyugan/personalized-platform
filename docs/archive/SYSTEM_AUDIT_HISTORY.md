### 2026-08-21：Windows Installer 疑似孤立缓存隔离结束审查

- 触发原因：用户明确选择方案 1，并完成高风险系统缓存的受控隔离操作。
- 审查结果：合规。只移动动态复查中未被 Installer `LocalPackage` 注册引用的文件；没有迁移整个目录、创建联接或触碰已注册缓存。
- 安全流程：执行前确认 D 为 NTFS、可用空间充足、目标不存在、`msiexec` 未运行且候选集精确匹配 96 个/29,226,562,560 字节；先完整复制并逐文件 SHA-256 校验，再二次检查注册引用和源文件未变化，最后逐个删除源文件。
- 验证：C 盘空闲 27.79 GB；源目录为普通目录，保留 450 个已引用 MSI/MSP、约 4.917 GB，未引用数 0；D 盘隔离区 96 个文件、29,226,562,560 字节，清单 96 行，日志成功结束。
- 可恢复性：D 盘保留原文件、哈希、原路径、时间、属性和 ACL SDDL；隔离区未删除。一次性执行脚本已从工作区删除，避免重复运行。
- 恢复策略：优先按错误中明确的缓存文件名做单文件恢复；全量恢复前需额外释放至少 5 GB，使 C 盘能在恢复 29,226,562,560 字节后仍保留安全余量。恢复必须先校验隔离副本哈希，再复制并复核目标哈希，同时恢复清单记录的时间、属性与 ACL。
- 偏差与残余风险：无产品偏差。Windows Installer 缓存识别没有微软官方清理 API，注册表无引用仍只是强证据而非绝对保证；在常用 MSI 软件更新/修复/卸载验证完成前不得永久删除隔离区。
- 下一步：正常使用并观察软件维护行为；若出现错误，按清单恢复对应或全部文件。下一次触发为恢复、永久删除隔离区或任务恢复/结束。

### 2026-08-21：Windows Installer 迁移决策审查

- 触发原因：用户从只读诊断进入高风险系统目录迁移，并提出用目录联接保持原路径。
- 审查结果：合规，任务暂停在必要决策点；尚未修改任何系统目录。
- 事实：D 盘为 NTFS 且有约 148.70 GB 可用空间；`mklink /J` 是 Windows 支持的目录联接机制，但微软明确要求保护 Windows Installer 缓存，没有官方支持的跨卷迁移流程。
- 风险：整个 Installer 迁移会让所有 MSI 软件更新、修复和卸载依赖 D 盘和联接；D 盘不可用、盘符变化、ACL/服务访问差异或迁移过程失败都可能造成延迟暴露的安装器故障。
- 选择：推荐只把注册表未引用的约 27.2 GB 文件移到 D 盘隔离；若用户明确接受整目录联接风险，必须采用先完整复制并验证、原目录原子重命名、创建联接、验证后再删除 C 盘备份的可回滚流程，并取得交互式管理员权限。
- 偏差：无产品目标偏差；属于系统维护风险决策，不调整产品 Roadmap。
- 下一步：等待用户明确选择迁移范围；执行任何移动、删除或联接操作前再次核验文件清单、目标路径和管理员权限。
