# 桌面伙伴使用说明

更新：2026-10-12。本指南描述当前本地候选，不等同正式新版本发布；真实手表、语音和多屏体验仍需自然验证。

## 执行结果怎么看

小鱼调用工具后，由程序统一显示真实回执：先看“已完成 / 等待后续 / 部分结果 / 未找到 / 未完成 / 已取消 / 尚未确认”，再看条目或步骤；已知查询中的时间、缓存、节选和覆盖提示放在末尾。来源使用短标签链接，不展开网址或原始技术对象；未知字段不自动显示。

多步流程在结束后集中汇总，模型说明格式不合格时仍显示实际回执。模型补充文字单独标为“分析说明”，格式合格不等于分析一定正确。任务创建、接管或方法面板准备、录制开始均不表示后续执行完成；系统接收打开请求不证明网页加载，作业已交标记不向教务网站提交。后续模型失败或步数上限会保留已执行回执；主动取消/撤销授权沿用原迟到丢弃保护，停止不会自动撤销已生效动作。

普通聊天保持流式回复；主窗与桌宠共用结果渲染。长列表只显示本次返回的有限条目，完整性看覆盖提示；朗读省略代码与网址。此改动没有新增账号访问、权限、持久保存字段或外发目的地。

## 形象与显示

打开“设置 → 桌面伙伴”。名字、显示模式、桌宠造型、WebM素材、QQ音乐伴听和实时心率集中在这里；AI模型、语音服务与授权仍分别配置，不因显示角色而默认开启。

- 桌宠：Q版、像素、精细三种造型，可以左右扒边、底部趴边或自然半身放置。拖动移动，靠近边缘松手吸边；轻点头部回应，点击身体打开对白，右键选择姿态或查看设置。
- WebM/立绘：在“WebM 与立绘素材”展开原形象与动作库。上传后可预览当前动作、选基底帧并调整位置、透明度与缩放；缩放支持0.1%微调，预览可在桌面形象处播放。
- Ctrl+Alt+Q：切换桌宠和原WebM/立绘，已有素材不删除。Q专门留给形象切换，旧配置若分给显隐/安静穿透/紧急停止会提示另选；注册失败可在“桌宠与造型”点击“重新绑定”。其他程序占用仍需先释放；实际显示/隐藏和安静穿透快捷键可单独选择。
- 像素半身提供「原版 / 2.0追踪版」两个版本。Ctrl+Alt+A在已启用的像素半身中切换，不改变其他造型或摄像头许可；原版保留鼠标眼神与轻待机，2.0可另行开启本地摄像头追踪。第一次仍需明确授权，画面不保存或发给AI；切回原版停止摄像头。动作与窗口选项默认收起，原版随时可回退。
- 安静穿透：角色不挡住下方点击，不能直接拖动；用快捷键、托盘或语音恢复互动。普通窗口不强制置顶。

桌宠与WebM分别记住本机的位置和尺寸，显示器变化时校正到可见区域；这些设备位置偏好不随资料备份迁移。视觉休息不是停止语音监听，隐藏与彻底退出也不是同一件事。

## 角色旁说话

桌宠点击默认是小对白，WebM点击默认是完整聊天。通过名字唤醒时使用更轻量的语音字幕框，两种角色的样式与尺寸分别适配；窗口先尝试角色左/右/上/下方并约束到当前工作区。小屏空间不足时优先可见，不承诺所有极小工作区都完全无重叠。

- 轻量对白：显示当前回答的纯文字预览，长内容可点“展开全文 / 回复”。主动打开的文字对白不会自动消失，便于慢慢阅读。
- 语音字幕：只显示实际播放的TTS句子，不用尚未朗读的模型文字冒充字幕，也不承诺单词级同步。结束后最多约6秒回到待听提示；鼠标停留或焦点在框内时继续保留，新一轮倾听会让旧句子退场。暂停朗读保留当前句。
- 完整聊天：显示原始全文、历史与流式内容，可以输入回复，Enter发送、Shift+Enter换行，中文输入法选字的Enter不发送。展开时聚焦输入框；WebM暖纸茶棕、桌宠银蓝，气泡、输入与任务卡共用各自主题。
- 任务展示：运行、暂停待确认及失败恢复保留操作；已完成/停止不常驻聊天。点击短暂任务反馈可明确查看结果并收起详情，任务记录和产物不删除；普通重开或任务状态变化不继续挂旧完成卡。
- 流式阅读：在底部时跟随新回复；往上翻历史后保持阅读位置，点“回到最新回复”恢复跟随。
- 收起：回到刚才的对白或语音形式，未发送草稿和同一会话保留。可打断回答或结束语音，不另建聊天记录。

权限确认、隐私复核和等待确认的任务会自动使用完整形式，保留明确按钮。展示模式不代替允许操作；任务详情仍能暂停、继续或停止，不能由收起/展开自动批准。

## 程序内动作与权限

“设置 → AI伙伴 → 权限与记录 → 小鱼现在能做什么”是实时清单，列出已接入动作、可以执行/需要确认/暂不可用及原因，并区分模块关闭和未接入；电脑动作要按实际目标另行检查。完整程序权限已经包含受控写入和逐项资料授权，关闭总开关后才由分项开关控制；它不会接通所有按钮，也不解除加密、删除、密钥或独立电脑权限边界。

“完整程序权限”开放已经接入的小鱼工具，不是全部界面按钮或操作系统的万能许可。在「设置 → AI 伙伴 → 权限与记录」可关闭总权限、恢复逐项授权或选择所有写入都确认；加密、删除、密钥与电脑权限保持独立。

可以说“小鱼，帮我抽一根签”“抽一支恋爱签”“抽一根前程签”“替别人抽一根恋爱签”“帮我抽一张真心话”“翻开答案之书”。这些明确短指令从本地题库实际抽取，不调用模型生成；个人签每筒每天一支，重复返回同一签，客签不占每日签。个人签会打开对应纸签，真心话和答案之书在聊天呈现；不收集回答或自动收藏。关闭模块会提示先开启，不代替用户打开。

本地抽取结果不进入模型续写或后续模型历史；如已授权云端语音输入/朗读，语音仍可能联网。详细的全部页面、任务、音乐与尚未工具化操作见[小鱼程序能力审查](小鱼程序能力审查.md)。权限开启不意味着 QQ 播放控制、任意导入导出或主题设置等已成为小鱼工具。

一隅签参考[长崎诹访神社官方英文御神签](https://www.osuwasan.jp/omamori/)的十种签运：大吉、吉、中吉、小吉、半吉、末吉、转祸为福、半凶、凶、大凶。今日60支、恋爱/前程各36支，每筒均覆盖十类；中文签诗与解读均为一隅原创，并非神社原签或现实预测。转祸为福表示变化，不作为固定名次；每支本地签等机会抽取，不声称复刻神社未公开的概率。页面底部“签运参考”默认收起，按需查看来源和解读；不会自动联网或收集心事。

更新保留旧96支的签号、等级和文字，今天已抽的签不会改变。新追加签号在降级旧程序时可能被清除；跨电脑请使用同一新版。个人仍每筒每天一签，想再抽可使用不留存的客签。

## 打开 B 站主播直播间

可以说“小鱼，我想看b站天才美少女卡莎的直播间”，也支持“帮我打开B站主播「昵称」的直播间”“搜索昵称的B站直播间”。明确、单一目的的请求会实际调用联网搜索；结果只有一个名称匹配的官方域名房间链接时，再经过现有电脑权限与必要确认交给默认浏览器打开，不靠模型猜房间号。讨论、否定及录屏/送礼等复合请求不进入这个简短流程。

沿用现有联网搜索配置、密钥、额度、后备和外发保护；最多两次查询，不新增平台登录、Cookie、接口绕过或权限。未找到、同名多房间或权限关闭时会明确说明，不自动挑选；录播链接、摘要里的链接和非官方域名不作为自动打开目标。公开搜索中的名称匹配并非登录账号验证，打开回执也不代表页面已加载或正在直播。已经知道链接时可直接说“打开 https://live.bilibili.com/房间号”。

## 受控电脑接管（首阶段）

### 不看屏幕的公开查询

可以问“天才美少女卡莎开播了没”“帮我查一下B站某主播现在开播了吗”。小鱼先用现有搜索定位唯一名称匹配的官方房间，在已有联网授权范围内匿名读取B站房间状态和主播资料，不重复请求目标确认；核对房间号、主播标识和准确昵称，返回开播/未开播/轮播或无法确认，附北京时间。不会打开浏览器，不需要开启电脑能力；多结果、名称不一致、验证/限流或陈旧缓存均不猜测，搜索摘要不作为实时证明。

也可以要求“读取这个公开网页并概括内容”“查询这个公开JSON的/data字段”。通用工具为web.read_page、web.read_json、web.live_status，能力面板会显示实际状态。读取需已有联网授权（或完整程序权限），不逐目标重复确认；每次仍检查当前权限和URL秘密，不能绕过撤销。网页分析会进入现有对话模型并消耗原额度，沿用隐私保护；直接读取没有搜索API额度费用，前置搜索仍沿用当前提供商/后备配置。

只支持公开HTTPS GET、UTF-8静态网页/文本/JSON，最大512KB，提取最多12000字/30链接。无Cookie、认证、JS执行、文件下载或自动重定向；公共DNS校验并绑定且不使用系统代理，所以需登录、动态页面或需代理的来源可能读不到。获取时间不等于内容更新时间，缓存/截断会标注；如页面要求重定向，须将新目标按同样边界重新检查，不自动跳转。

即时查询可根据返回结果继续查链接、改字段或换来源，最多8工具/10模型轮次/4次新读取，不重复同一来源字段。外部内容进入只读隔离，不会据网页指令写入资料或控制电脑；需要保存/操作请下一轮明确提出。原先明确“打开主播直播间”的本地有界流程仍可打开唯一匹配房间，但不解释摘要指令。新读取不进入持久任务；既有任务的replan仍是暂停待调整，不是自动重新规划。没有后台监控、登录会话、DOM或视觉，取消不继续下一工具，已发出的一次有界网络调用无法撤回。

外部内容进入后也不能再调取私人章节等本机资料，避免网站诱导外发；工具原文不单独保存为任务或聊天历史，最终回答按原历史开关保存（回答可能包含引用），审计只记脱敏元数据。原对话入口的外部AI总开关仍生效；已识别的短开播查询不调用模型，但不会替用户开启任何开关。

从「设置 → AI伙伴 → 权限与记录 → 电脑能力 → 开始受控接管」打开，或告诉小鱼“接管这个窗口，帮我查找阅读报告”。小鱼只准备面板，不能替你批准开始。刷新并选定一个窗口、填写目标、确认本任务控件文字外发后开始；默认只观察，勾选后才允许普通填写与搜索。需现有电脑总开关、DeepSeek配置及外部AI授权，不自动改权限。

每轮重新识别控件，执行一项再观察，最长3分钟、最多8次操作/8次模型决定；并非截图看图或通用浏览器DOM，未提供控件的软件可能无法使用。未知按钮或非搜索输入需要单独确认；已识别的提交、发送、保存、付款、删除、密码字段，以及管理员/终端/开发工具、一隅自身不接管。关键词和密码标记不能识别全部敏感内容，开始前请避开私密页面。

主窗口面板可暂停/停止，托盘或原紧急停止快捷键同样撤销会话；暂停恢复先重新观察，不重放上一项写入。已发出的动作不能撤回，已外发模型请求可能继续到原超时并消耗现有模型额度。按钮“调用成功”不是目标完成，模型结果仍需核对；观察文字和填写内容不进持久任务/聊天或审计，仅审计操作类别、确认与成功/失败。结束清会话，原生到期自动释放控件观察，不新增文件/Shell或无限电脑权限。

这是主窗内的单窗口帮助面板，不是独立置顶桌面控制条；Playwright、截图视觉模型和批量文件整理尚未接入，后续需各自明确范围和配置。

## 情绪回望

首页心情卡展开「情绪回望」，默认按月，在「回望视图」切换「气泡矩阵」和「色带」。默认气泡矩阵，以日期为列、情绪为行；圆面积表示实际点数，每天共用0—15点刻度，只记录一个时段也不放大。3点仍是3点，不统计出现次数；本段非零情绪都保留，少量1点不并入“其他”。色带保留渐变、周织带/月日历与情绪构成。其他试用图已移除，不删除心情记录。

周/月、历史月份和选中日期共用；单日详情默认收起，点日期或气泡展开早中晚点数与备注，仍可看周期时段汇总。气泡中「·」是已记录但该情绪0点，「—」是未记录，下方显示已记录时段数；不补点、不推断强度或好坏评分。本机记住有效视图选择，原色带选择继续保留，旧的已移除视图选择回退气泡矩阵；偏好不随资料备份。

「示例预览」已移除，两种视图只展示真实记录；无记录时不生成虚构气泡。最终方案与此前调研见[可视化方案](情绪回望可视化方案.md)。

## 本机搜索与经历草稿

### 作业截止

「待办清单」分为「待办 / 作业」。添加周作业只填哪门课、周几交；单次作业只填课程、截止日期。名称、时间、备注及周作业起止在「更多设置 · 可选」中，旧的多星期设置继续保留；不填时间按本机日期当天结束截止，不受待办的「今天休假」影响。

主列表仅显示本周（周一至周日）尚未交的周作业，以及所有尚未交的单次截止（包括逾期和较远日期），不重复列未来几周。新周作业默认从本周周一起；本周前已过的指定星期仍可补交。标记已交后从主列表移至「已交与往期记录」，旧的未交周记录和停交记录也保留在这里，可展开撤销或补交；改期按实际截止日期分组。

每张纸卡对应一期：提前交、补交都在对应那一期「标记已交」，可撤销。本期设置可单独改期、停交或重置；重置会一并撤销本期提交与改期，其他期不变。「编辑课程与截止」修改课程/备注不改提交历史，单次日期修改仍保留原期次和提交记录；周规则调整显示新的生效日期，不能覆盖已修改或提交的未来期次。收起整份作业可从下方「收起的课程」恢复，不永久删除记录。

首页从本周未交周作业及所有未交单次截止显示最近三期，不把往期周作业重复堆在首页；日历在实际截止日期显示标记，打开范围外一期时作业页单独展示「定位的记录」。本机搜索可按名称、课程、备注和已存规则/改期日期找到作业，无本周记录的课程可打开设置。小鱼经已有待办授权读取、添加、标记指定一期提交或单期改期/停交；本期修改沿用写入确认，不替你向教务系统提交，也不开放删除作业。

系统提醒仍需开启已有电脑能力与后台提醒，仅在一隅运行时检查；完整退出后不会提醒。资料库及完整/共享素材备份保留作业规则和提交历史，旧程序可能忽略新增集合，降级前先在新版完整备份。

Ctrl+K（或侧栏“搜索整个程序”）查询作品/正文、日记/朝问、经历/足迹、待办、日历/课表、人物/地点/时间线、素材元数据、本地音乐、心情备注、答案收藏和功能/设置入口。只查本机，空格分词、每类最多八项；锁定作品、回收站、关闭模块、密钥、私密词典、聊天/记忆和未保存草稿不参与。结果打开对应目标；音乐只高亮不播放，素材不读取文件正文，历史朝问仅作为只读参考。

经历编辑页可勾选“退出后保留文字草稿”，默认关闭。启用后最多保留六份本机明文文字，按当前资料库隔离；不随备份迁移、不上传或进AI，未保存的封面需重新选。重开可从经历册“本机待恢复文字草稿”查看，明确恢复或丢弃，不自动成为正式卡片；原卡片已变更会提示核对。保存成功/确认放下/删除清该卡草稿，关闭恢复清当前资料库全部草稿。存储失败请先正式保存；本机清理、迁移或第七份覆盖最旧草稿时，不保证仍可恢复。

## 名字和语音


- 语音交谈完整朗读，不受文字聊天「只读前段」的220字符或段落限制；15秒是等待下一次发言的空闲窗口，不是回答播放上限。随时主动停止/打断仍可用。
- 唤醒及可选声纹通过后才接入识别。复用本地麦克风，只缓存验证通过后的未来样本等待连接，唤醒前音频不外发、不保存；不要把这理解为可以还原唤醒前已说完的句子。
- 开头漏识别或必须贴近时，到语音交互查看音量；唤醒开启时复用当前监听，不另开麦克风，关闭唤醒时为本地15秒检测，不录音/不联网。设备、增益、灵敏度和声纹开关现在可直接调整，修改后安全重启监听并结束旧语音会话；唤醒名可在这里输入2～6个汉字，失焦保存并同步伙伴名字。原始名字前后静音会裁除，短语音仍需声纹模型核验。提示“已识别唤醒词，但声纹未通过”时按录入距离说话或重新录入；提示有效声音过短时名字后接一句话。重录/删除声纹自动暂停唤醒，完成后明确重新开启。过高增益放大噪声，不替代硬件排查，不保证所有口音/距离；手动语音输入用所选设备，增益只用于本地唤醒及唤醒交谈。

聊天窗口显示既有最多100条保存历史；隐私设置关闭保存时，新对话不留存。私人浏览器查询的原问句和网页结果只在当前窗口临时显示，不保存查询占位记录；重开后不出现“隐私摘要”或结束提示，旧版已保存的这类固定摘要也不再显示，普通聊天和本地仪式历史不受影响。不能恢复以前没有保存的正文；清空会删除当前记录，不清旧完整备份。

默认“小鱼”；设置里的伙伴名字同时是AI身份与唤醒名字，不再维护另一份独立称呼。在线STT/TTS需配置并开启服务，本地待机唤醒不上传音频；通过唤醒后才连接在线识别。程序彻底退出后不能继续唤醒，也不自动注册开机启动。

## QQ音乐伴听

设置中的伴听默认关闭。开启后，角色旁显示QQ音乐的系统歌曲信息，点击可展开；桌宠与WebM分别适配。播放控制需另行开启，本地LRC可按当前歌曲校准，联网歌词尚待具体外发授权。歌曲与歌词不进资料、备份或AI；偶尔看歌曲标记只用于空闲桌宠，不改变WebM动作。详见[伴听与空间设置](伴听与空间设置.md)。

## 实时心率

“设置 → 桌面伙伴 → 实时心率”首次默认关闭。手表端需开启广播，然后扫描并选择设备；成功连接后记住本机设备，后续启用会自动查找，可显式开启启动自动连接。停止取消本轮连接，忘记设备清除本机偏好；广播标识变更可能仍需重新选择，不按同名静默替换设备。

设置使用环形读数；桌宠使用适配画风与姿态的小心形/数字，WebM使用轻量旁注。无有效数据显示横线，不延续过期值；脉动只是装饰，不是ECG或逐次真实心跳。仅桌宠在心率持续明显变化时偶尔看标记再回正，交谈、鼠标关注、摸头、拖动和休息优先，至少间隔两分钟，不会每跳一个数值都回应。

读数不保存历史、不写资料/备份、不交给AI或外发，不解释为情绪或健康结论。广播并非私密加密连接且会增加手表耗电；菜单与广播限制见[产品专项说明](product/06-动态伙伴与隐私安全层.md)中的佳明官方链接。

## 操作记忆：已学会的操作

入口：「设置 → AI伙伴 → 记忆与性格 → 已学会的操作」。成功完成适用工具流程后自动整理并保存方法，不用手填；方法册可关闭自动学习或手动补充。自动方法只记录程序定义的步骤/判据及网站域名，不复制首次参数、账号、页面/邮件正文或结果，也不额外调用模型。失败、未知与加载/截断页面不学习；B站明确查到开播可学习查询流程，但覆盖不完整时仍不能冒称全查完。

明确同类聊天请求可参考唯一匹配的方法直接重新执行，变化目标从本次请求取得，不用打开表单；多个账号/候选先明确目标。高级手动方法仍可用 `{{关键词}}` 参数并从方法册运行。公开查询使用已有联网授权，不重复目标确认；UIA窗口保持选窗和本次外发同意；已登录Edge另走下方只读连接，不依靠图像识别。

方法可以编辑、停用和删除，变更会使正在执行的旧版本停止；不会撤回已经发出的动作。遇到登录失效/歧义/控件变更/权限不足交还，不重试可能已经发出的写入。执行结果仅面板显示，不进聊天或方法库；运行只记版本/时间/状态/工具次数，工具返回后仍待你核对，确认完成才标记为你已验收。

保存本地方法随资料备份，停用/手改不被自动覆盖，删除的流程不自动学回。认证文本检查不能识别所有私人内容，请不要手写邮件正文、凭据或私密原文。删除不清旧备份，新字段降级旧程序可能丢失。复用仍使用原模型/额度/隐私策略，不自动授予权限。

## Edge已登录浏览器连接

推荐在此设置上方选择「小鱼专用浏览器」：使用已安装Edge的独立本机资料，首次点网站旁「登录」并手动登录，回来点「结束登录 · 转为后台」。之后查询使用真正headless模式，不弹出或最小化普通窗口，也不向日常Edge添加标签页；不需要安装扩展或Node。原Edge扩展方式仍保留，旧设置不会自动切换。

网页示范录制目前仍在Edge扩展兼容页。专用浏览器不自动录制你其他浏览行为；已有方法执行仍需本次目标、实时授权和新页面证据，不重放历史账号内容。

网站在一隅同一清单添加，可粘贴HTTPS入口；专用模式「添加并授权浏览」同时允许低风险导航/检索，可在网站选项关闭。输入/筛选内容须来自本次用户请求，使用当前DOM控件并动作后重观测和证据核验；发送/删除/支付/凭据不开放。登录过期、验证码、跨域SSO或企业策略可能仍需手动处理；不会为查询自动打开登录窗口。专用资料会保存敏感登录会话，不复制日常Edge密码、不把Cookie导出给模型或资料备份，不能保证所有网站接受headless。「本机会话管理」可显式清除全部专用登录/网页缓存（不可恢复，不影响日常Edge/资料库）。以下说明专指原Edge扩展兼容方式。

日常查询优先只读复用唯一已打开的授权非登录页，不激活、不导航、不登录或点击日常页面。没有可安全复用的页面或需要登录/导航时，在同一已连接Edge资料的独立最小化、不聚焦工作区执行，不向日常窗口新增或切换活动标签；共享浏览器自身登录态，不复制Cookie、密码或资料目录。新工作区完成初始化后才开始读取，创建阶段失败清理本次空工作区，不误报用户切页。重复查询复用专用页面，撤销、取消或闲置五分钟后仅清理可证明属于小鱼且仍最小化的窗口；你恢复或使用后的窗口不自动关闭。已授权网站的明确查询默认自动脱敏后交给当前配置模型分析，无需每轮点「发送脱敏内容」。设置中的「查询体验」可改为前台查询或恢复逐次确认。首次连接/站点授权、身份歧义、验证码与高风险操作仍需你参与；普通聊天的严格隐私设置不被更改。

最小化不等于完全隐藏：可能仍有任务栏标记、浏览器认证/调试提示；有些网站限制后台运行或自动填充，需要切前台处理。Edge未连接时不会猜测并启动别的账号资料。专用页面无法复用只存在于单个标签页里的临时状态；不保证所有网站都能无感登录。

入口：「设置 → AI伙伴 → 权限与记录 → Edge浏览器连接」。开启后自动准备并维护下方一隅扩展目录。首次安装仍需在日常已登录的Edge配置打开 `edge://extensions`，开启开发人员模式、加载这个目录，再将一隅生成的连接码粘贴到扩展弹窗。同一配置无需重复配对；浏览器已登录不等于扩展已连接，未连接、未授权或登录失效会分别说明。

网站只在一隅填写一次，点击「添加并连接」会自动打开扩展确认页，网站已预填；点击「确认Edge授权」完成浏览器实际授权，不再到扩展重复输入域名。「连接后打开目标网站」可取消，只有本次连接成功才打开选定网站。扩展不后台索取权限、不全站授权；Edge要求的真实用户确认不能替代。扩展仍可独立撤销权限，不会自动重新授予。撤销一隅网站立即停止读取，扩展下次同步释放对应权限。连接期间更改清单、取消或超时会使旧确认失效；迟到的授权会释放本次所选网站权限（包括原先已有的这些权限），需要时重新连接。

可说「看一下现在B站我关注的up主有谁在开播」，或「现在B站有UP主开播了吗」。群体开播默认查询当前账号的关注列表，不转新闻搜索；具名主播、全站热门与视频更新是不同用途。固定官方只读GET需授权 https://live.bilibili.com、https://api.bilibili.com、https://api.live.bilibili.com；没有可核验总量不把空列表认作全部未开播。查看关注动态另需添加 https://t.bilibili.com 或相应动态页面网站。设置不再提供B站专属按钮，「连接已添加网站」只确认你已经添加的精确域，不自动补域或扩大授权。

可说「查看一下我的邮箱里有未读邮件吗」，也可直接附网址或 mails.tsinghua.edu.cn 这样的域名。唯一可识别邮箱直接匹配；多个账号先明确目标，不任选或遍历。缺页会在已连接Edge打开本次授权入口并等待同站导航提交/加载；本次完整链接优先旧配置入口，网页打不开、仍加载、浏览器拒读分别提示，不代表没有邮件。正文读取兼容同源且可见的内嵌页面，总共最多4份文档、共享12000字/40链接/10000文本节点；跨站、隐藏或隔离内页不读。没有上次快照，「未读」不等于「上次检查后新增」；只按页面明确提示作答，不能保证任意网站完整可读。

每个网站的「网站选项」中可开启「自动登录」，默认关闭。与导航许可分开，不需要另填密码或在扩展重复配置。查询遇到顶层登录页时，只对唯一可见、同站HTTPS POST表单、浏览器确实已自动填好的凭据尝试提交一次，最多等8秒；不读取保存外发密码、不提取密码库，提交不等于登录或业务完成。未填、验证码/二次验证、多账号、跨站SSO或不支持的表单仍交给你处理；撤销会停止后续步骤，但不能撤回已经发出的请求。

如果密码已显示但脚本登录提示「密码未输入」，浏览器可能要求一次真实手势。Chrome/Edge不能动态授予可选debugger权限，所以原只读扩展0.4.3没有这项强权限。你可以在设置「可信登录点击 · 可选组件」准备独立组件文件，在Edge首次加载它并知情确认调试权限，再在原扩展弹窗点「连接可信点击组件」，在组件页面确认；以后可用「使用可信登录点击」开关。组件只对当前逐站允许的登录按钮短暂派发一次Input并重新检查，不读取密码/Cookie、网页DOM、网络或截图，不向模型开放CDP。权限本身很强，并非浏览器原生逐站沙箱；关闭开关仅停止使用，撤销浏览器强权限需停用/删除独立组件。挑战/账号歧义仍交人；不愿安装时手动点一次登录后继续查询。

旧0.1扩展没有自动维护代码，仍需到 `edge://extensions` 手动重新加载一次；应用启动启用连接后已自动更新一隅目录，不必每次点击「准备扩展文件」。已迁移0.2以上的原目录扩展会按内容指纹自动更新到0.4.3并保留配对，最多同一目标尝试一次，失败明确提示修复而不循环重载。独立点击组件首次加载/授权/连接由用户完成，只维护已经准备的固定组件目录，不静默安装或向只读端加调试权限。仅维护内置固定目录，不下载远程代码、不改浏览器策略或用户配置；其他目录副本需改用一隅显示的目录，切换目录可能需重新配对。首次安装、Edge权限提示、缓存凭据及真实网站结果需实际使用确认。

设置中「教小鱼做一次」可示范已授权网页的DOM操作：明确选择页、开始、暂停/停止/取消，停止后核对编辑并保存到方法册。只RAM固定语义步骤，不录屏、密码、输入正文或坐标；未知控件补充目的，复现重新观察且不授予写入权限。详见[非视觉示范说明](非视觉示范录制方案.md)。

### 通用网页任务（DEC-090）

日常只看紧凑网站列表的名称、域名与连接状态。需要时展开「网站选项」，独立开启自动登录/导航检索，用途和名称放在同一行；可识别的唯一邮箱不必再填写用途。多个邮箱才需指定默认目标，已有默认也可取消。查询入口收在「指定查询入口」，通常无需设置；扩展安装、更新、重新配对统一收在「扩展管理」。撤销网站同时撤销用途、默认目标和独立许可，不改查其他账号。

查询目标已明确但没有页面时，小鱼会在已连接Edge准备该站的授权入口。需要继续翻页、查看未读或站内搜索时，单独开启该站的「允许页面内导航与检索」；这不包含登录许可。小鱼只使用本次页面的短期控件引用，执行后重新观察，最后用当前页面的逐字证据核验结论；点击提交或读到页面本身都不是任务完成。未知按钮、发送/删除/支付、验证码、账号选择、跨站SSO或不支持的页面会停止并交给你，不运行模型提供的脚本或任意选择器。

刚刚问完可补充「就是 https://…」或说「继续」，五分钟内接续本聊天入口的临时目标；主窗与桌宠分开，取消/配置变化会清理。页面正文、控件引用及临时任务不写入历史、方法或备份；开启操作学习时，成功核验的明确邮箱/门户绑定可以记住为可取消的默认目标，不自动授予权限。既有隐私外发检查仍生效：必要页面文字可能交给你配置的模型分析，并非“登录网站后所有内容绝不外发”。

核验只代表当前页面证据，不能保证模型每句话的语义、所有分页或“上次检查后新增”。实际隔离Edge已覆盖虚构门户/邮箱、缺页准备、导航、GET搜索、模拟自动填充登录及旧引用/跨站拒绝；未因此宣称真实密码库、任意网站、Canvas或跨应用写入都已兼容。

不导出Cookie/密码，不读取无痕窗口，扩展使用当前Edge配置会话；必要网页文字经脱敏后可能送到现有配置模型，并非全部本机处理。明确授权查询免重复复核，但始终脱敏、硬阻断识别到的秘密，每轮发送前重新检查授权/目标/模型/取消；自动识别不能覆盖所有个人信息。勾选「每次查询前确认脱敏发送」可恢复逐次复核，非浏览器聊天的严格策略不变。私密查询不保存聊天正文，审计不存tabId/网站参数，方法只存流程。撤销任一侧网站、关闭连接/外部AI或停止读取后，后续请求和迟到结果失效；已发请求不能撤回。扩展有读取徽标，可在一隅断开配对撤销令牌；配对密钥不入资料备份，跨电脑需重新连接。
