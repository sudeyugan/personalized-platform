# 桌面伙伴使用说明

更新：2026-10-06。本指南描述当前本地候选，不等同正式新版本发布；真实手表、语音和多屏体验仍需自然验证。

## 形象与显示

打开“设置 → 桌面伙伴”。名字、显示模式、桌宠造型、WebM素材、QQ音乐伴听和实时心率集中在这里；AI模型、语音服务与授权仍分别配置，不因显示角色而默认开启。

- 桌宠：Q版、像素、精细三种造型，可以左右扒边、底部趴边或自然半身放置。拖动移动，靠近边缘松手吸边；轻点头部回应，点击身体打开对白，右键选择姿态或查看设置。
- WebM/立绘：在“WebM 与立绘素材”展开原形象与动作库。上传后可预览当前动作、选基底帧并调整位置、透明度与缩放；缩放支持0.1%微调，预览可在桌面形象处播放。
- Ctrl+Alt+Q：切换桌宠和原WebM/立绘，已有素材不删除。Q专门留给形象切换，旧配置若分给显隐/安静穿透/紧急停止会提示另选；注册失败可在“桌宠与造型”点击“重新绑定”。其他程序占用仍需先释放；实际显示/隐藏和安静穿透快捷键可单独选择。
- 安静穿透：角色不挡住下方点击，不能直接拖动；用快捷键、托盘或语音恢复互动。普通窗口不强制置顶。

桌宠与WebM分别记住本机的位置和尺寸，显示器变化时校正到可见区域；这些设备位置偏好不随资料备份迁移。视觉休息不是停止语音监听，隐藏与彻底退出也不是同一件事。

## 角色旁说话

桌宠点击默认是小对白，WebM点击默认是完整聊天。通过名字唤醒时使用更轻量的语音字幕框，两种角色的样式与尺寸分别适配；窗口先尝试角色左/右/上/下方并约束到当前工作区。小屏空间不足时优先可见，不承诺所有极小工作区都完全无重叠。

- 轻量对白：显示当前回答的纯文字预览，长内容可点“展开全文 / 回复”。主动打开的文字对白不会自动消失，便于慢慢阅读。
- 语音字幕：只显示实际播放的TTS句子，不用尚未朗读的模型文字冒充字幕，也不承诺单词级同步。结束后最多约6秒回到待听提示；鼠标停留或焦点在框内时继续保留，新一轮倾听会让旧句子退场。暂停朗读保留当前句。
- 完整聊天：显示原始全文、历史与流式内容，可以输入回复，Enter发送、Shift+Enter换行，中文输入法选字的Enter不发送。展开时聚焦输入框；WebM暖纸茶棕、桌宠银蓝，气泡、输入与任务卡共用各自主题。
- 任务展示：运行、暂停待确认及失败恢复保留操作；已完成/停止不常驻聊天。点击短暂任务反馈可明确查看结果并收起详情，任务记录和产物不删除；普通重开或任务状态变化不继续挂旧完成卡。
- 流式阅读：在底部时跟随新回复；往上翻历史后保持阅读位置，点“回到最新回复”恢复跟随。
- 收起：回到刚才的对白或语音形式，未发送草稿和同一会话保留。可打断回答或结束语音，不另建聊天记录。

权限确认、隐私复核和等待确认的任务会自动使用完整形式，保留明确按钮。展示模式不代替允许操作；任务详情仍能暂停、继续或停止，不能由收起/展开自动批准。

## 程序内动作与权限

“完整程序权限”开放已经接入的小鱼工具，不是全部界面按钮或操作系统的万能许可。在「设置 → AI 伙伴 → 权限与记录」可关闭总权限、恢复逐项授权或选择所有写入都确认；加密、删除、密钥与电脑权限保持独立。

可以说“小鱼，帮我抽一根签”“抽一支恋爱签”“抽一根前程签”“替别人抽一根恋爱签”“帮我抽一张真心话”“翻开答案之书”。这些明确短指令从本地题库实际抽取，不调用模型生成；个人签每筒每天一支，重复返回同一签，客签不占每日签。个人签会打开对应纸签，真心话和答案之书在聊天呈现；不收集回答或自动收藏。关闭模块会提示先开启，不代替用户打开。

本地抽取结果不进入模型续写或后续模型历史；如已授权云端语音输入/朗读，语音仍可能联网。详细的全部页面、任务、音乐与尚未工具化操作见[小鱼程序能力审查](小鱼程序能力审查.md)。权限开启不意味着 QQ 播放控制、任意导入导出或主题设置等已成为小鱼工具。

## 名字和语音

- 语音交谈完整朗读，不受文字聊天「只读前段」的220字符或段落限制；15秒是等待下一次发言的空闲窗口，不是回答播放上限。随时主动停止/打断仍可用。
- 唤醒及可选声纹通过后才接入识别。复用本地麦克风，只缓存验证通过后的未来样本等待连接，唤醒前音频不外发、不保存；不要把这理解为可以还原唤醒前已说完的句子。
- 开头漏识别或必须贴近时，先关闭唤醒，到语音交互「检测麦克风」按平常距离说话；本地15秒音量条不录音/不联网。选择正确设备后重新打开唤醒；可小幅增加「唤醒收音增益」，过高会放大噪声，不替代重新录入声纹或硬件排查。手动语音输入使用所选设备，增益仅用于本地唤醒及唤醒交谈。真实拾音距离和回声需当前麦克风体验。

默认“小鱼”；设置里的伙伴名字同时是AI身份与唤醒名字，不再维护另一份独立称呼。在线STT/TTS需配置并开启服务，本地待机唤醒不上传音频；通过唤醒后才连接在线识别。程序彻底退出后不能继续唤醒，也不自动注册开机启动。

## QQ音乐伴听

设置中的伴听默认关闭。开启后，角色旁显示QQ音乐的系统歌曲信息，点击可展开；桌宠与WebM分别适配。播放控制需另行开启，本地LRC可按当前歌曲校准，联网歌词尚待具体外发授权。歌曲与歌词不进资料、备份或AI；偶尔看歌曲标记只用于空闲桌宠，不改变WebM动作。详见[伴听与空间设置](伴听与空间设置.md)。

## 实时心率

“设置 → 桌面伙伴 → 实时心率”首次默认关闭。手表端需开启广播，然后扫描并选择设备；成功连接后记住本机设备，后续启用会自动查找，可显式开启启动自动连接。停止取消本轮连接，忘记设备清除本机偏好；广播标识变更可能仍需重新选择，不按同名静默替换设备。

设置使用环形读数；桌宠使用适配画风与姿态的小心形/数字，WebM使用轻量旁注。无有效数据显示横线，不延续过期值；脉动只是装饰，不是ECG或逐次真实心跳。仅桌宠在心率持续明显变化时偶尔看标记再回正，交谈、鼠标关注、摸头、拖动和休息优先，至少间隔两分钟，不会每跳一个数值都回应。

读数不保存历史、不写资料/备份、不交给AI或外发，不解释为情绪或健康结论。广播并非私密加密连接且会增加手表耗电；菜单与广播限制见[产品专项说明](product/06-动态伙伴与隐私安全层.md)中的佳明官方链接。

## 更新和排查

- 当前直接运行版为Windows桌面的“一隅_直接运行.exe”。更新后先从托盘退出旧实例再打开，避免单实例机制把你带回仍在运行的旧程序。
- 安装包仅放项目 `apps/desktop/src-tauri/target/release/bundle/nsis/`，不放桌面；本地候选不会自动提交或推送。
- 快捷键、语音和设备问题先确认应用仍在运行、模式是否穿透、服务是否启用、手表是否广播。浏览器预览不能验证真实麦克风、BLE、WebView2或Windows多屏行为。
