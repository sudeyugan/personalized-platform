# 一隅多端预览

本功能在 `feature/multi-device` 独立开发，已推送，尚未合并 main。Windows 候选和 Android 调试 APK 已构建，不是正式新版本，真机/实际跨电脑网络尚未验收。

## 组成

- Windows：原应用独立保存，在「设置 → 数据管理 → 让一隅随你同行」连接云端服务。
- 中枢：独立 Node24 进程，只保存加密操作、设备名称和传输元信息。不需要常开一隅窗口；关闭中枢进程会暂时停止交换，客户端继续离线使用。
- Android：移动工作区、离线编辑和手动/前台恢复同步；仅保留七组已选手机模块，三入口纸墨布局、独立全身伙伴与显式语音；旧PC模块数据保留但不露手机入口。详见[安卓版使用与能力对照](安卓版使用与能力对照.md)。悬浮/通知仍另行授权，系统限制、耗电和锁屏兼容仍需真机确认，不保证后台永久保活。

## 默认：连接自己的云端

2026-10-21用户已确认购买云服务器，当前尚未实际部署。中枢是运行在云服务器上的一隅服务，不是另需准备的一台常开电脑。部署步骤见[云端部署与迁址](M13_云中枢部署与迁址.md)。

1. 首台 Windows 默认选择「首次连接云端」，填写设备名称、部署后的「云端服务地址」和初始化一隅服务时生成的「连接凭证」。地址默认留空；连接凭证不是云服务器登录密码，也不是模型 API Key。
2. 已有设备连接后生成「邀请另一台设备」；新 Windows 选择「使用设备邀请」，手机在连接页粘贴邀请，即可加入同一个服务，无需重复填写服务地址或管理凭证。
3. 自托管、本机测试与恢复包收在「高级连接选项」。已有连接不会因界面默认方式改变而自动迁移；换到云端前必须保留原空间和密钥，不能重新初始化空库。

## 可选：常开电脑准备中枢

先在你选定的常开电脑准备 Node24 和项目依赖。不要把仍在使用的 SQLite 文件放进网盘同步，也不要映射整个资料库为网络共享。

```powershell
# 首次运行，选择独立数据目录，只显示一次管理凭证，请私下保存。
node apps/sync-hub/src/main.mjs --init --data D:\YiyuHub
# 本机测试。不会自行修改防火墙、设置自启动或注册 Windows 服务。
node apps/sync-hub/src/main.mjs --data D:\YiyuHub
```

默认仅监听 `127.0.0.1:17839`，其他电脑和手机无法直接连接。跨设备必须明确配置可达的受信任 HTTPS 地址：可以由你管理的 TLS 反向代理转发到本机中枢，或者给中枢指定 `--host`、`--cert`、`--key`、`--port`。不关闭证书验证、不默认公网暴露、不自动安装网络服务。当前开发环境没有据此部署你的常开电脑。

证书域名/信任和网络路径要由所有设备认可。手机禁止明文 HTTP；开发机的 `localhost` 不能拿去当手机的中枢地址。下述Tailscale仅保留此前的可选测试路径，不是云端连接的前置要求。

## 可选测试路径：Tailscale 私人网络＋HTTPS

2026-10-19后续已暂定采用云服务器中枢，归入[M13规划](../.agent/M13_PLAN.md)；2026-10-21确认已购、尚未部署。下文是此前实施的测试路径，不表示用户必须安装Tailscale。更换地址必须保全原空间与密钥，不自动重置连接。

不要求设备在同一Wi-Fi。Tailscale负责让授权网络中的设备互通，Serve把HTTPS请求转发到电脑的`127.0.0.1:17839`；一隅仍检查自己的设备凭证，正文仍按前述协议加密。此处使用私人 **Serve**，不是面向公网的 **Funnel**。[官方Serve说明](https://tailscale.com/docs/features/tailscale-serve)

1. 电脑安装官方Tailscale并登录你准备用于自己设备的账号；手机安装[官方Android客户端](https://tailscale.com/docs/install/android)，登录同一私人网络账号并由你确认VPN。不要使用不受你管理的公共/组织网络来测试私人资料。安装会新增系统网络组件；不等于把中枢设为开机服务。
2. 签发证书前，将电脑在Tailscale中的名称设为不含个人信息的名称，例如`yiyu-hub-test`。按官方流程启用MagicDNS/HTTPS；证书的设备域名会进入公开CT记录，但服务本身仍由私人网络的访问规则限制。[证书说明](https://tailscale.com/docs/how-to/set-up-https-certificates)
3. 保持中枢终端运行。在另一个PowerShell终端先检查现有Serve配置，不覆盖已有服务；确认443未被占用后，用以下命令仅代理中枢，不代理文件夹或整盘。

   ```powershell
   & "C:\Program Files\Tailscale\tailscale.exe" serve status
   & "C:\Program Files\Tailscale\tailscale.exe" serve --https=443 http://127.0.0.1:17839
   ```

   首次可能需要在浏览器确认启用HTTPS。测试保持前台，不加`--bg`，不运行`funnel`、出口节点、子网路由或SSH命令；已有配置冲突先停下核对，不运行全局`serve reset`。前台测试按Ctrl+C停止；[官方CLI说明](https://tailscale.com/docs/reference/tailscale-cli/serve)区分了前台与持久后台行为。
4. Serve成功后会显示实际`https://设备名.网络名.ts.net`地址，不要照抄示例域名。**尚未首次连接**时，在一隅「高级连接选项 → 自托管与本机测试」填此HTTPS地址和原中枢管理凭证，再生成手机邀请；不能使用`127.0.0.1`生成的邀请，也不能通过换地址重新初始化已有中枢。
5. **已用本机地址连接**时，先私下保存管理恢复包，并确认待发送项已同步。不要直接断开/重新初始化、删除连接数据或丢弃同步密钥。当前候选已提供设置内迁址入口，只读核验原空间/游标与原密钥后保留身份切换，具体看[云中枢迁址](M13_云中枢部署与迁址.md)；不要把一次性邀请或恢复包粘贴到聊天。实际迁移须保留同一个中枢空间和原同步密钥。
6. 手机安装一隅APK，在「连接」粘贴新邀请。基础验证可先用同一Wi-Fi；要证明跨网，关闭手机Wi-Fi、保持移动数据和Tailscale连接，新增虚构待办，再在电脑核对，反向修改也核对一次。手机断网新增后恢复网络补同步，才覆盖离线恢复；只看Tailscale在线不代表一隅配对或数据同步已成功。

Android同一用户/工作资料中一次只能运行一个VPN服务，可能与现有VPN冲突；若切换影响正常上网，先停下核对，不擅自启用出口节点解决。[Android VPN说明](https://developer.android.com/develop/connectivity/vpn) Tailscale还涉及第三方账号与设备/网络元信息；不把它描述为无第三方或零元信息方案。其网络访问规则可能允许同一私人网络中的其他设备访问中枢端口，一隅的设备认证仍是独立保护。

当前电脑只是测试机。以后迁到常开电脑时应保全中枢数据与管理恢复材料，另行核对地址迁移，不把新主机上的空库当作原空间继续同步。主机睡眠/中枢或Serve停止时，交换暂停；客户端仍可本地使用，不保证手机后台永久同步。

## 配对和恢复

1. 首台 Windows 在数据管理选择「首次连接云端」，填服务地址和初始化的连接凭证；自托管在高级选项中设置。连接会合并这台设备的可同步文本资料。
2. 在「高级连接选项 → 恢复与连接管理」把恢复包私下离线保存。它含同步密钥和管理凭证，拥有者可以恢复管理设备；不要放进聊天、代码仓库、公开截图或普通共享备份。
3. 用「邀请另一台设备」生成十分钟一次邀请；在另一个 Windows 或手机的连接页粘贴。邀请包含同步密钥，不包含电脑 API Key/浏览器权限。
4. 邀请过期时重新生成。网络中断后可用相同邀请重试同一台尚未完成的连接；设备身份和密钥在消费邀请前先保存。不要清除本机连接数据后期望再次消费旧邀请。
5. 管理设备丢失后，在新 Windows 的「高级连接选项 → 使用恢复包连接」粘贴恢复包；再撤销丢失的设备。**没有恢复包/仍可用管理设备，中枢不能替你找回解密密钥。**

普通设备不能邀请、查看设备管理列表或撤销其他设备。撤销只阻止后续请求，不擦除其已下载资料和密钥；首版没有密钥轮换/历史重新加密，所以设备真正失陷时应停用该同步空间并重新建立，而不是把撤销当作抹除。

## 同步与冲突

- 本地资料保存和同步队列分开；上传前先持久化队列。中断可重试，操作标识去重。Windows 定期/联网/回到前台尝试；手机在前台、恢复和手动操作时尝试，不提供远程控制。
- 同一记录离线产生不同修改，保留两条分支，不按设备时钟强行覆盖。设置中的核对项可选择继续用哪版；旧操作仍留在本机同步历史和中枢密文日志，并非被物理删除。
- 想法手稿核对时，其他非删除版本另存为「另一条思路」分支，不把两边的对话轮次拼在一起。
- 删除使用墓碑；与另一端的修改并发时也需要核对。同步删除会影响其他设备，**不是备份/回收站的替代品**。
- 编辑器聚焦或本机正在保存时，先保留远端修改、稍后应用；不在输入中途换掉稿件。Windows 连续本地保存先短暂归并采集；本机已保存但尚未入队的最新内容，下次启动会重新比较。
- 心情按日期＋早中晚识别同一个五点格，避免两端分别生成随机 ID 造成重复统计。

## 首版资料范围

同步普通写作正文/作品/卷、人物/地点/事件和关系、待办/作业/日记/心情/课程/日程/朝问、经历册文字、想法手稿。手机实际提供的入口已按用户清单收敛，不再提供小说写作/人物地点/经历或仪式；具体已支持与未迁移项见[能力对照](安卓版使用与能力对照.md)，不冒称PC浏览器、相机追踪或Windows工具已移植。

不传附件文件/封面原图、章节版本快照、作品加密容器、音乐、API 密钥、浏览器资料/密码/Cookie、私密聊天/工具回合/任务/审计、设备权限与本机配置。正文中的图片引用可能在另一端缺图；本端已有附件元信息保留。未配置真实附件迁移前，不把首版用于“完整资料库搬家”。

加密作品即使当前解锁也排除正文及所属章节。已在过去同步过的内容不会因后来启用作品加密自动从其他设备和历史消失。同步操作按单记录保留分支，不是跨多个作品/章节的分布式事务或富文本 CRDT；复杂跨记录并发需先备份、核对，暂不视作多人实时协作。

单条操作限512KB UTF-8，中枢约256MB/十万操作安全上限；首版未做历史压缩/密钥轮换/防恶意中枢回滚的完整密码学证明。超限/游标回退/缺祖先/密文篡改会停止而非跳过。不要直接恢复旧中枢库并宣称客户端会自动接受回退。

新增普通纯聊天作为chat集合端到端同步；普通/仅本机会话上下文分开，旧历史不追溯上传，PC工具与私人网页结果不共享。所有配对客户端须一同更新；普通删除会同步，私密删除仅本机。语音外发与隐私边界以[手机说明](安卓版使用与能力对照.md)为准。

## 隐私和手机伙伴

正文以 AES-256-GCM 端到端加密，中枢不持有解密密钥；仍可看到设备标签、IP/时间、操作数量/大小等元信息。已配对设备能读同步资料；本机同步状态/密钥在应用的本地 IndexedDB 内，依赖操作系统账户保护，不是另一个加密保险箱，也不抵御本机恶意代码。不要与他人共享同一系统账户。

手机模型/语音Key可手填，也可经旧设备按目标批准后走[独立加密配置交接](多端配置交接.md)，不进入普通资料同步/邀请/聊天。Android Keystore保护本机密文。应用关闭系统备份，并排除 Android 12+ 云备份/换机复制中的本机文件、数据库和偏好，避免克隆设备身份；厂商行为仍需真机确认。换手机请重新邀请配对，不复制 WebView 数据。规则依据 [Android 备份说明](https://developer.android.com/identity/data/autobackup)。模型仅接收必要会话，不自动附带其他资料；普通聊天接续，私密与工具/私人查询不进中枢。没有其他App读取、录屏或电脑命令工具，不是桌面代理远程转发器；语音明确启停见手机说明。

## Android 构建状态与步骤

2026-10-19：按用户明确授权安装 SDK 并接受本次标准 Android SDK 许可；没有代替用户授予手机悬浮层/通知权限。已通过手机 Web 构建、原生 `assembleDebug` / `lintDebug`、项目 wrapper 重复构建及 APK v2 签名、清单/资源检查。最低 Android 8（API26），目标 API35。

APK：`apps/mobile/android/app/build/outputs/apk/debug/app-debug.apk`。这是**调试签名预览**，不是商店发布包。把它传到自己的手机后自行确认安装；程序不会自动安装或绕过系统提示。首次开启小鱼需在系统里同意悬浮层及通知权限；可以先只体验资料页，不开启悬浮层。

构建需要 JDK17、Android SDK35/Build Tools35，按本机位置设置 `JAVA_HOME` / `ANDROID_HOME`。项目已带 Gradle8.11.1 wrapper，分发包固定官方 SHA-256，wrapper JAR 也已核对官方校验值。首次构建会下载官方依赖。

```powershell
pnpm mobile:build
.\apps\mobile\android\gradlew.bat -p apps/mobile/android :app:assembleDebug :app:lintDebug
```

WSL/Linux 使用 `./apps/mobile/android/gradlew` 替换上述 `.bat`。产物、SDK/缓存和签名私钥均不进入 Git。本次本机调试签名在 `.inputs/android-build-tools/android-user/debug.keystore`，不应上传；删除或更换它会改变后续包的签名，可能无法直接覆盖旧安装。正式长期分发前仍需另行管理发布签名。

本批最终原生 lint 为 0 错误、10 警告，主要是本地 WebView 必需的 JavaScript、复用图标的密度/单色适配、原生视图布局工具/中文文案及绝对拖动坐标的 RTL 提示；没有禁用规则。保留 AGP 与新版 SDK 元数据兼容提示、原生旧 API 提示。尚未验证真机 WebView/Keystore、悬浮层/键盘/锁屏/耗电、真实模型/语音和跨设备受信任 HTTPS；不把编译或浏览器模拟当作这些项目已通过。[AGP兼容表](https://developer.android.com/build/releases/agp-8-9-0-release-notes)、[本地WebView内容](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)及[前台服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types)是当前适配依据，不代表应用已获得系统或商店批准。
