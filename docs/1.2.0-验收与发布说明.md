# 一隅 1.2.0：验收与发布说明

## 本版实现

- 本地导入 MP3、WAV、OGG、M4A、FLAC；文件复制进资料库，可编辑标题/艺术家、移入回收站或永久删除。
- 全局、作品、章节、专注四层队列，可调整顺序；支持音量、停止/列表循环/单曲循环和 `Ctrl+Alt+空格/方向键`。
- 播放跨页面持续；隐藏播放器或停用音乐模块不会主动停止已经允许的声音。自动按上下文切歌默认关闭。
- 写作右侧栏加入伙伴；默认本地 Mock 不联网，自定义服务在未选择兼容协议前不会发送任何文稿。
- 权限中心逐项授权作品、章节、资料数量和音乐上下文。加密作品即使已解锁，仍需单独授予“仅本次解锁会话”权限，锁定或撤销即失效。
- 完整备份现在包含资料库内的音频副本；旧版本资料打开后会自动补齐 M7 配置。
- 同版本 UI 补丁统一“智能创作”的字号、控件和信息层级，伙伴权限改为折叠范围列表；窄窗口可通过伙伴抽屉继续对话，音乐队列在小屏按明确区域重排。
- 同版本写作补丁把正文工具栏分为历史、段落、文字、结构和插入五组；支持正文/三级标题、高亮、左/中/右/两端对齐、待办列表、链接编辑与移除、清除格式、列表缩进和查找替换。代码类工具入口已按反馈移除；旧内容仍兼容显示，不破坏历史文稿。
- 后续写作体验补丁最终取消正文最大宽度，整个编辑画布均可写入，并移除编辑节点轮廓及左右栏分隔边线；工具栏仍按自身宽度把次要操作折叠到“更多工具”，当前章节行持续显示删除入口并沿用可恢复回收站。
- 帮助中心把 GPT Image 2 背景工作流作为“常用指南”折叠小项：先生成 4 张候选、再基于母版做 2 次单变量微调，最终导入 1 张全局背景；完整可复制模板也保留在同一小项，不设置独立页面或文档。
- 未选音乐时，“声音会在页面间继续”只在音乐页作为可关闭提示出现；关闭后本次应用会话不再显示。实际播放器仍会在选中曲目后跨页面持续。
- 正文“更多工具”提供默认、1.25、1.5、1.75、2.0 五档行间距，作用于当前段落或标题并随文稿保存；旧文稿默认排版不变。

当前安装包：`apps/desktop/src-tauri/target/release/bundle/nsis/一隅_1.2.0_x64-setup.exe`；SHA-256 `A54786CB820D2838AEA63F6E14AC1908D9AB35AF59CE2ABDD3FFF28E83AAA7F6`。

## 自然体验

无需执行固定清单或连续试用。安装后按自己的方式听音乐、写作和使用伙伴；发现不符合预期的地方，直接填写 `体验反馈与需求补充.md` 的 `1.2.0` 章节即可。

## 已知边界

- 音频是否能解码还受 Windows WebView2 与具体文件编码影响；通过扩展名/MIME 白名单不等于所有损坏或特殊编码文件都能播放。
- 自定义伙伴 provider 目前是可替换接口和安全配置边界，尚未绑定某个在线服务协议；界面中的“检查 Provider 配置”只验证 HTTPS 格式且明确不会联网，本地 Mock 可完整体验权限和对话流程。
- 桌面悬浮伙伴、长期记忆、换装/形象生成和成长系统属于 M8，不在本版提前实现。
- 本版不提供在线音乐服务，也不会修改或删除导入前的原始音乐文件。
- 当前只支持一张全局背景，不会自动为温暖/明亮/深色主题切换不同图片；生成图的文字可读性与裁切效果仍需在实际窗口中预览。
