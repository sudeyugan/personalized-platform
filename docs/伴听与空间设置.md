# 伴听与空间设置

这一批是本地候选体验调整，正式版本号仍为2.0.0；没有删除原曲库、图片或资料。

## QQ音乐伴听

入口：设置 → 桌面伙伴 →「你的伙伴名字」伴听。默认关闭，只读取QQMusic.exe提供的Windows系统媒体会话，不读取账号、私人数据库或音频。

- 开启后，在QQ音乐中播放一首歌。暂停时仍保留歌曲；退出播放器、关闭功能或读取过期后不继续显示旧信息。
- 桌宠用银蓝小标记，左右扒边镜像摆放、底部放上方；WebM用暖白旁注。点击按需展开；安静穿透不拦点击，拖动、倾听、回答和任务优先。
- 歌词已移到独立透明窗口，不挤占角色画布。默认显示角色外侧当前句（最多两行）：桌宠银蓝、WebM暖白，不做逐字高亮或反复换句翻动；前奏/长间奏留空，交谈时默认让位。点击歌曲标记或字幕展开整曲阅读，自动跟随当前句；手动滚动暂停跟随，点「回到当前句」恢复。阅读底部可按0.1秒提前/延后本曲或归零，复用已有本地校准。
-「歌词呈现」可选独立摆放，拖动歌词顶部移动，调整12～28px字号、35%～100%不透明度及鼠标穿透；仅本机保存，不随资料备份。穿透后在设置关闭即可恢复点击，也可重置位置/重新启用已隐藏窗口。角色模式改变时各自适配；显示器变化时约束工作区，极小工作区仍需自然验收。独立阅读只接收当前歌曲，词变化才传整曲，不接收整份歌词库/账号/密钥或音频。歌词来源和网络授权没有变化。
- 桌宠持续播放约45秒后，空闲时偶尔看一下歌曲标记再回正，至少间隔2分钟。鼠标关注、摸头、菜单、休息、心率回应及减少动态效果优先；不做节拍识别或情绪判断，WebM动作调度不变。
-「允许手动播放控制」单独开启后才有暂停/播放、上一首/下一首；只有系统报告可用的按钮才允许执行。不提供QQ音乐未支持的进度拖动。
-「个人歌词库」支持UTF-8 LRC，最多200KB，按标题/歌手/专辑/时长区分录音版本。导入歌词及每首的±10秒校准保存在本地，再次播放、重启或离线可复用，随完整/共享素材备份。导入优先，不支持无时间戳文件，也不会自行编造歌词或自动朗读。
- 实时歌曲和系统封面仍仅会话；个人歌词库只存歌词、必要的歌曲标识与校准，不记录收听次数或自动进入AI。偏好开关仅在本机，跨机恢复不会自动打开联网。系统封面最多512KB且只变化时传输，失败仍显示文字。

自动收集默认关闭，在「个人歌词库」打开：向[LRCLIB接口](https://lrclib.net/docs)固定接口仅发送当前标题、歌手、专辑、时长，不需要额外API Key。当前歌曲信息稳定3秒后单项查询（暂停时也可），先精确查询，必要时同源搜索一次（最多20候选），核对歌名、歌手和±2秒时长。兼容全半角括号、Live大小写和常见艺人分隔符，专辑名作为优先项，不因为精选专辑改名一概拒绝；现场/混音等版本字样仍保留，多个不同时间轴不自动套用。不把普通网页文字当作同步歌词。没匹配到会暂停本曲6小时、临时网络失败暂停本曲5分钟；不会让一首失败阻塞所有歌曲。来源429按Retry-After单独退避，只有全部已启用来源均受限时才整体等待，仍保持15秒请求间隔。关闭或换歌不接收旧结果；私密词命中不自动外发。最多200项、800万歌词字符，手动导入项不自动淘汰；「移除此曲歌词」需要确认并暂停本曲自动查找6小时。「重新查找此曲歌词」可跳过本曲旧失败缓存（暂停播放也可），仍遵守联网开关、隐私和来源限流，不覆盖手动导入；失败不会清除已有同步歌词与校准。无收录、无时间轴、版本歧义、超时和连接失败会分别提示。来源覆盖及同步准确度不保证，不扫描收藏，也不承诺公开接口长期有效。

新增「优先使用QQ音乐歌词」是另一个默认关闭的开关：显式开启该项时会同时开启自动收集（界面有说明）；先向 `u.y.qq.com` 发送当前歌名和歌手查询，核对完整版本、歌手、专辑优先项与±2秒时长，再向 `c.y.qq.com` 发送匹配歌曲的标识取得普通LRC；无需API Key、账号或Cookie，不读取或解密播放器缓存/QRC。未找到或来源暂不可用时尝试LRCLIB；最多QQ两次＋LRCLIB两次请求，总时限25秒，每次最多12秒/1MB，固定HTTPS且无重定向。多个无法区分的版本不自动选择，保留手动LRC。关闭并重新打开也丢弃旧请求；来源正在释放旧请求时短暂等候，不把它缓存成歌曲失败。QQ歌词与校准仍在原个人歌词库，界面显示「QQ音乐 · 本地歌词库」，下次播放或离线直接复用。启用新增来源会重新查询旧来源的失败结果；此修复也只对旧版失败缓存重新核查一次，新版失败仍逐曲冷却。缓存保留有限失败原因，重启或换歌回来不再把连接失败/超时说成未收录。但不会覆盖已有本地歌词或绕过主动移除后的6小时暂停。公开接口可能变化，不保证全部歌词；川川南《河流（Live）》320秒原录音已取得45个时间戳的公开LRC，实际播放器同步仍需体验。

「辅助搜索公开线索」点击才复用设置中的腾讯云/博查/Bing搜索；可额外勾选DeepSeek整理歌名、歌手或版本线索，使用现有对话密钥与外部AI总开关，并经过隐私过滤/必要确认。只发送当前搜索词和最多6条公开摘要，不发送缓存歌词正文或收听列表；它帮助寻找来源，但不会自动抓取不明网页歌词。可自行取得UTF-8 LRC后导入。

旧本地曲库：设置 → 数据管理 → 打开曲库。原音频、队列和四层上下文仍可用，不因启动/打开设置自动播放。

## 资料

创作空间只保留写作、日记、资料。资料内部切换人物／地点／时间线；既能记录现实，也能保存虚构作品设定。

编辑时选择用途、可选归属作品；上方按用途和作品筛选。归属作品只是组织方式，不替代或改变正文引用。旧记录保持「未分类」，不猜测它是否真实；原ID、关系、章节链接、回收站和旧深链接保留。

图片管理移到设置 → 数据管理；正文插图、导入和导出保持可用。

## 背景

入口：设置 → 外观与写作。

- 壁纸：一张图连续铺在侧栏与正文后，比例铺满时会裁切；水平／垂直位置用于调整可见主体。
- 插画：保留完整比例，适合竖版人物或边角装饰；大小和位置可调，不强行裁成横向背景。
- 纸张保护：只调整前景纸张，不降低文字或整张图的透明度；范围80%～100%，写作正文继续保持不透明纸张。
- 默认只选一张通用图，场景覆盖在高级选项里。更换或移除不删除素材文件，可到图片管理检查引用。

图片通过本地素材仓储引用，不在设置中重复存Base64。首次打开外观设置时，旧内嵌图片按相同来源去重迁移，保存成功且该槽仍未被用户改动才替换；失败保留原图并提示。完整备份及共享素材快照均包含背景图片，迁移自动快照仍须复制整个备份目录。
