# DEC-102：摄像头版对视深化（2026-10-16）

用户批准前四项：实际屏幕位置映射、稳定采样校准及可选左右范围、眼睛与头部分层、聊天/动作保持轻对视。原版鼠标眼神保留，2.0不混入鼠标。

## 实现边界和验收

- 复用已有允许的自身窗口/显示器几何API，事件触发刷新、不查询鼠标/其他窗口。以桌宠所在显示器上方中央为摄像头参考，物理坐标消除DPI/负坐标差异；仅粗略相对距离，不冒称多屏物理摄像头定位或精确眼球视线。缺失/异常回退原摆放基准。
- 居中校准采多帧稳定数据，可选左右轻移范围。取消、失脸、超时、换设备不覆盖旧校准；只保存本机小参数，旧格式兼容，不保存画面/轨迹/身份，不改变摄像头开关和Worker几何协议。
- 小幅偏移眼睛先动，持续大偏移才让头跟随；眼睛根据实际头部响应作有限补偿，身体/头部不超原上限，无鼠标回退。减少动态幅度，不扩大画布或重绘素材。
- 聊天、点头/招手中保留轻眼神，拖动/菜单/摸头仍优先；睡眠/闭眼素材不强行重画。相机丢失平滑回静息。
