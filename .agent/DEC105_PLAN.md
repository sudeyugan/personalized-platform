# DEC-105：水墨思考长卷

用户批准探索美术上限：水墨构图与手稿思考融合，常驻三栏改中央推敲/手稿册抽屉/同卷成稿；文字落墨、构图演变、修订痕迹与收束转场为重点。

## 实现

1. 保留API、隐私、领域/Store；按画景、文字、历史、当前推敲、成稿及页面编排拆分呈现。
2. 本地有限构图、浓淡干湿墨、纸纤维/远近山层、题签方向与留白；真实可选文本，动画仅新轮次，立即读完和减弱动态优先。
3. 手稿册默认关闭、焦点约束/ESC/返回；推敲与成稿互斥，编辑稿切换保存，历史可展开/分支保留原文，不制造用户未表达的确认。
