# DEC-080 作业截止与纸感 UI

2026-10-11：用户确认待办内作业分组，特别要求注意美术和UI。保持正式2.0.0/M12，本地候选，不提交推送。

## 范围与验收

- 在待办页提供「待办 / 作业」两个轻量页签，沿用主题纸面、留白与字级，不新增顶层导航或密集表格。后续用户确认更简：主列表只看本周未交周作业及全部未交单次截止，按实际截止日期归组，删除21天预览和重复状态/计数。
- 新建周作业只填课程与星期，单次只填课程与日期；名称、时间、备注和周起止收进可选设置，既有多星期兼容。新周作业从本周周一起，不造更早欠交。已交/停交及往期折叠保存，单次逾期不隐藏；按期提交/撤销、改期/停交及规则分段保护保持。
- 作业独立planner.assignments可选集合与slice，不影响普通待办的休假/打卡/完成记录；归一化旧库为空，资料/两类备份往返保留。
- 首页从本周未交周作业与全部未交单次取最近三项；日历日期标记/侧栏、本机搜索定位不变，显式定位范围外一期单独展示，不扩回未来列表。小鱼经已有todos授权访问作业、受控创建/提交/本期改期，不复用旧todo完成接口。无删除工具、外部教务接入/提交、附件/成绩管理或新网络/依赖。
- 本机日期日终语义、每期稳定身份、只改本期不改后续；未来规则变化保留旧段与已触碰期次，不清历史。

2. 作业页签/纸卡/表单与本期面板；首页/日历/搜索定位和小鱼真实工具接线。
