# DEC-082：公开网页与结构化查询

用户批准“通用网页读取＋结构化数据查询＋有界动态执行”。本阶段不接登录会话、浏览器DOM、视觉、后台监控或无限制HTTP/电脑权限。

1. 独立public_web原生模块：公开HTTPS GET、DNS解析后公共地址校验并绑定、禁代理/自动重定向/Cookie/认证；限时限体积，静态HTML与JSON选择路径，来源/获取时间/截断标记。
2. 三个全局工具：web.read_page、web.read_json、web.live_status。沿用联网/外发策略，每次新读取明确确认目标；服务在确认/隐私审核后复核实时权限。搜索提供商及后备不变，直接读取不消耗搜索API配额。
3. 复用即时Agent循环，最多8次工具/10次模型轮次；根据结果改查或换来源，重复读取拒绝。外部内容进入只读隔离，不得据其指令发起写入、任务或电脑动作；持久任务暂不接新读取工具，避免网页原文落盘。既有持久任务replan仍是暂停，不冒充已自动重规划。
4. B站开播问题：独立意图/身份检索/公开接口适配；最多两次搜索、不猜房间号、不打开浏览器。状态只能依据本次公开接口明确字段；验证/限流/缓存/歧义均为未知，不能用摘要推断未开播。无生产主播名称或房间号映射。
5. 边界回归、Windows完整门禁、匿名公开探针和Release/桌面交付，文档同步实际证据。真实DeepSeek与用户搜索配置集中自然验收，不读取私人内容/密钥、不自动启用授权、不提交推送。
