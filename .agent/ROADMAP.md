# Roadmap

更新：2026-10-18。这里只区分正式阶段、当前增量、剩余验收和未来方向，不再混排历次“正在实施”的旧日志。

## 正式里程碑

当前正式阶段是 **M12：通用自主任务系统**，版本 `2.0.0`，已交付待人工验收。下一阶段 **M13：多端一隅与加密云中枢** 已于2026-10-19确认规划，未越过M12验收正式启动。当前先在功能分支补齐Android体验，详见[M13计划](M13_PLAN.md)。DEC-xxx是决定/批次编号，不代表阶段推进。

2026-10-19用户纠偏后，当前优先项改为M13.0范围确认：已有手机候选扩入未要求模块，暂不继续代码实现。先确认保留/撤去清单、手机布局与伙伴方案、远端中枢及远程任务边界；后续阶段草案见M13计划，不把上一批自动验证当作产品范围验收。

## 尚未结束的验收

- M12：真实Provider/语音/复合任务自然体验，正式状态仍为待人工验收。
- DEC095：五阶段总体完成条件与真实摄像头/原生附着/艺术体验不能由局部候选通过替代。
- 浏览器：真实账号、会话、网站兼容及模型理解；不把隔离fixture等同通用接管能力。
- 想法工坊：真实模型启发质量和原生艺术/性能；当前自动检查只支持已记录范围。

细节和风险不重复抄到路线图，见[当前状态](PROJECT_STATE.md)和[风险](RISKS.md)。

## 尚未批准的后续方向

M13已确认总体方向，具体云资源/费用/部署、远程任务和推广验收按[M13计划](M13_PLAN.md)分阶段收口；当前不购买或部署。正式版本号与启动仍须遵守前阶段验收门禁。

Live2D、MCP、OpenRouter正式生图及任意全电脑无人值守不因出现在历史设想中就被视为当前已接入或待执行任务。
