## 当前开发周期

- M8 `2.0.0` 已交付待自然体验；用户暂时搁置虚拟形象素材路线，当前进入 M9“日常记录与规划”。
- 当前实现日记与周课表联动、独立待办清单，全部沿用本地资料库持久化与既有备份。
- 本阶段不接学校教务系统，不预置截图中的个人信息或课程；先提供手动录入、编辑和自然体验。

## M9 实现记录

1. 日记页面按日期保存标题与正文，并显示该星期当天的课程。
2. 周课表使用星期一至星期日、六个节次的网格；同一格允许多门课程，支持教师、地点、周次、备注及编辑删除。
3. 独立待办页面支持未完成/全部/已完成筛选、备注、截止日期、优先级、完成与删除。
4. 日记、课程和待办进入现有资料库 JSON、备份与恢复链路；旧资料库归一化为空规划数据。

## M8 实现记录

1. 新增透明置顶桌面伙伴窗口，支持拖动、隐藏、唤回主窗口，以及写作/音乐/思考/待机动作状态。
2. 主窗口与桌面窗口使用独立 capability；Rust 所有资料库 command 额外强制调用窗口为 `main`，桌面窗口只接收裁剪显示快照。
3. 记忆支持来源、时间、置信度、显式授权、编辑、删除与 JSON 导出；上下文实时裁剪，无授权或删除后立即停止注入。
4. 加密作品继续要求本次内存许可，且相关对话不能写入普通长期记忆；桌面快照不含消息、记忆、权限或文稿。
5. 发型/服装使用组合渲染；AI 形象采用草稿—确认—正式素材流程。
6. 性格权重变化默认关闭，开启后仅使用已授权对话/音乐，日志保存完整前后快照并支持回退和重置。
7. 完整门禁前端 64/64、Rust 24/24、TypeScript、生产双窗口 Tauri/NSIS 通过；最终无警告 UI 收口再次通过前端 64/64 和安装包校验。SHA-256 `77A22789B789A72B362BA2EFA9B5E92ECD00810F2617C888FE9C69D71E2CE672`。
8. 同版本反馈补丁修复主窗口关闭后 companion 窗口仍存活；Tauri 主窗口关闭事件现在统一退出应用，伙伴单独隐藏仍不影响主窗口。
9. 同版本反馈补丁增加标准角色文件夹导入和差分/序列帧 Runtime：校验 `character.json`、同画布 PNG、FPS 和自然帧序，支持表情、眨眼、说话、待机及 wave/nod/surprise/sleep；帮助中心提供 GPT Image 2 的 35–54 张素材清单和提示词。
10. 桌面角色图片通过当前包逻辑 ID 的 Rust 内存白名单读取，未向 companion 窗口开放通用素材命令；完整补丁门禁前端 69/69、Rust 26/26 与 NSIS 通过，SHA-256 `8DFE0EC15E97ADFC021B6BB77CCC140E0B4111BE876FB47A6F64073D639B5696`。

## M7 完成记录

1. 音频经 Rust 受控仓储复制到资料库，支持 MP3/WAV/OGG/M4A/FLAC、200 MB 限制、哈希、回收站与完整备份恢复。
2. 播放器支持可排序队列、音量、停止/列表循环/单曲循环、全局快捷键和跨页面持续播放；隐藏控件或停用模块不主动中断已播放音频。
3. 全局、作品、章节、专注按具体程度回退；自动切换默认关闭，手动播放使用用户当前编辑的上下文队列。
4. 写作右侧栏加入伙伴对话、名称和静态表情；本地 Mock 无网络，自定义 provider 在未确认协议前拒绝发送。
5. 权限中心可逐项授权作品、章节、资料数量和音乐上下文；默认拒绝，加密作品另需只驻留内存的本次解锁许可，锁定/撤销立即清除。

## M6 完成记录

1. 可在首次创建资料库前选择默认/自定义/已有资料库目录、备份目录和主题；错误目录保持向导可重试。
2. 帮助页覆盖自动保存、字数、恢复、备份、加密、开放格式和忘记密码，不设置固定场景或连续天数打卡。
3. 正文支持把选中文字标记为人物、地点或事件，关联已有资料或直接建档；AI 印象图默认对标记资料做稳定占位符替换并展示发送预览。
4. 可删除内容统一使用主题化确认框，回收站与永久删除分别说明对象、引用/影响、恢复方式，并优先聚焦安全操作。
5. 诊断包只含版本、平台、数量、大小、默认/自定义位置类型和代码崩溃位置，不含文稿、标题、完整路径或秘密。
6. 自动基线覆盖 10 万字和 10,000 条搜索；本补丁前端 43/43、Rust 22/22、静态检查、生产 Vite/Tauri 和 NSIS 门禁通过。
7. Windows/IME/缩放等体验不再组成固定发布阻断项；安装后自然使用，实际出现问题时再做针对性回归。

## M4–M5 完成记录

1. 图片从原路径安全复制到应用素材库，支持缩略图、正文块、元数据、引用/孤儿扫描和回收站。
2. AI 采用可替换 provider 和本地 Mock；API Key 用 DPAPI 保存，候选图确认前不进入正式素材库。
3. `.yiyu-backup` 覆盖资料、图片和加密 vault，具备哈希、恢复预览、路径防护、恢复前安全备份和每日保留策略。
4. 开放格式支持 Markdown＋图片、DOCX、PDF 导出，以及 DOCX/Markdown/TXT 预览导入。
5. 作品级 vault 使用 Argon2id + XChaCha20-Poly1305，锁定态移除正文、版本、关系、图片、AI 记录、会话和索引明文。
6. 主视图已动态加载，主入口由约 669.31 kB 降至约 212.32 kB；前端 27 项、Rust 19 项和 Windows NSIS 构建通过。

## M3 完成记录

2. M3 共用资料文案已进入类型化中文词典；旧页面剩余文案按模块渐进提取。

## M4–M5 执行顺序

1. 先对主视图做动态加载，控制当前 669.31 kB 主包体。
2. 实现图片库、本地素材复制/缩略图、正文图片节点、引用与孤儿扫描。
3. 接入可关闭、可替换 provider、安全密钥和 AI 印象图候选确认流程。
4. 按“备份 → 开放格式导出 → 导入 → 加密”实现数据安全闭环。
5. 对图片、关系、版本、备份和导出重新执行加密场景，交付 `0.5.0`。

## 后续工作量规划规则

- 一个公开版本应形成完整用户闭环，通常覆盖至少两个互相关联的中型能力，或一个足够大的高风险能力。
- 预计工作量低于当前 M3 的阶段优先与相邻阶段合并；不再仅因原文档编号不同就单独发布。
- M6 保持独立，因为它包含跨版本迁移、性能、首次建库、诊断与发布质量门；固定 Windows 矩阵、灾难恢复和连续试用已按用户反馈取消。
- M7 把完整本地音乐与伙伴侧栏/权限基础合并为“氛围与陪伴基础”，避免只交付孤立播放器；M8 的桌面窗口、可治理记忆和成长系统本身工作量足够，保持独立。

## 后续版本 Roadmap

### M6：首个长期可用版（建议版本 `1.0.0`）

目标：把现有写作、资料、图片和数据安全能力从“功能完整”推进到“可以长期存放副本文稿”。

1. 升级与迁移：覆盖 `0.2.0 → 0.5.0 → 1.0.0`，验证旧资料、关系、版本、素材和 vault。
2. Windows 质量矩阵：Windows 10/11、100%/125%/150% 缩放、常见中文 IME、锁屏/休眠、双实例和异常退出。
3. 性能与容量：冷启动、10 万字章节、大资料库、批量素材与备份耗时基线，修复可感知卡顿。
4. 首次向导与内置帮助：资料库/备份目录、默认主题，以及自动保存、恢复、加密、导出、忘记密码说明。
5. 诊断与发布：脱敏诊断包、变更日志、已知问题、安装/升级/卸载验证和校验值。
6. 发布门槛：自动质量门禁全部通过；安装后自然体验核心写作，不要求固定场景、连续天数或跨设备演练。

### M7：氛围与陪伴基础（建议版本 `1.2.0`）

目标：交付一个能持续陪伴写作、但权限边界清楚的完整氛围层，而不是单独增加音乐页面。

1. 本地音频导入/引用、播放队列、音量、循环、快捷键和跨页面持续播放。
2. 全局、作品、章节、专注四层播放上下文，明确回退规则，自动切歌默认关闭。
3. 伙伴编辑器侧栏、基础静态形象/表情和可替换对话 provider；暂不创建桌面悬浮窗口。
4. 权限中心：逐项授权作品/章节/资料/音乐上下文，加密作品必须临时授权，撤销后清理上下文缓存。
5. 退出条件：播放器隐藏不打断允许的播放；伙伴无授权时读不到文稿；离线/AI 失败不影响写作与音乐。

### M8：伙伴成长与桌面形态（建议版本 `2.0.0`）

目标：把伙伴从应用侧栏扩展为可解释、可撤销、跨窗口一致的长期系统。

1. 透明置顶桌面窗口、拖动/隐藏、多屏与缩放、主窗口/桌面窗口 capability 隔离。
2. 记忆条目保存来源、时间、置信度与授权，支持查看、编辑、删除、导出和彻底撤销。
3. 服装/发型/表情组合、动作状态机，以及 AI 形象“草稿—确认—正式素材”流程。
4. 性格权重变化日志、重置/回退和明确授权下的音乐/使用习惯互动。
5. 退出条件：删除记忆后不再注入；桌面窗口不扩大权限；加密内容无临时授权时不可进入任何伙伴上下文。

M8 之后的云同步、第三方插件市场和在线音乐只保留候选池；在完成单独威胁模型、冲突策略和成本选择前不进入承诺 Roadmap。
