# Project Brief

> 本文件是项目目标基线。目标、范围、非目标和验收标准的变更必须由用户确认，并记录到 `DECISIONS.md`。

最后确认日期：2026-09-15
确认人：用户（依据产品文档包、开发请求、体验反馈与日常规划功能确认）
基线版本：0.3

## 问题与目标

- 要解决的问题：现有写作、资料、图片与个人空间工具割裂，长篇中文写作缺少兼具可靠性、私密性和个人化的本地桌面环境。
- 期望结果：从零构建 Windows 桌面应用「一隅」，形成可日常使用的本地写作、记录与个人规划空间，并按需扩展音乐与虚拟伙伴。
- 目标用户：单个 Windows 10/11 本地用户。
- 为什么现在做：产品与开发规格已形成 0.1 基线，可以进入分阶段实现与验证。

## 成功标准

- [ ] 可安装的 Windows 桌面应用具备模块化外壳、主题与布局持久化。
- [ ] 写作、资料、图片、版本、导入导出、备份和作品级加密通过自动质量门禁；仅对自动化无法判断且确有必要的体验风险做少量集中人工检查。
- [ ] 核心写作离线可用，异常情况下不静默丢失正文，数据可通过开放格式带走。

## 范围

包含：

- M0–M6：技术验证、应用外壳、写作核心、创作资料、图片、数据安全与首个可用版。
- 内置音乐与虚拟伙伴模块契约，默认关闭且不展示空功能。
- M7–M8：音乐、伙伴侧栏、桌面伙伴、记忆与成长基础；M9：日记、周课表与待办清单。

不包含：

- 多人协作、社交发布、移动端、真实云同步和不受信任的第三方插件执行。

## 核心用户路径

1. 创建作品、卷和章节，持续编辑并由自动保存与历史版本保护内容。
2. 建立人物、地点和事件，与章节形成双向关联并在时间线浏览。
3. 个性化主题与布局，导出或备份数据，并按需锁定私密作品。

## 约束

- 技术：Tauri 2、Rust、React、TypeScript、Tiptap、SQLite；前端不直接访问数据库和资料库文件。
- 兼容性：Windows 10/11，默认简体中文，保留 i18n 键值。
- 性能：冷启动目标小于 3 秒；普通章节打开小于 500ms；10 万中文字符可流畅编辑。
- 安全与隐私：本地优先；密钥不进入数据库、日志与备份；锁定作品不得泄露明文元数据。
- 时间或资源：AI 辅助单人分里程碑交付，不将原型等同于完整第一阶段。
- 依赖和授权：使用可审查的开源依赖；AI、云服务和插件遵循最小权限。

## 验收方式

- 自动检查：前端单元/组件测试、类型检查、lint、生产构建、Rust 测试。
- 人工检查：不设固定场景或连续天数；安装后自然体验核心写作，只有自动化无法判断或实际发现问题时再做针对性回归。
- 浏览器或设备：Tauri WebView2，Windows 10/11 常见缩放比例与中文输入法。
- 数据或性能指标：10 万字章节、匿名大资料库 fixture、备份恢复校验和锁定态明文扫描。

## 关键假设

| 假设 | 验证方式 | 状态 |
|---|---|---|
| Tauri 2 + Tiptap 可满足中文长文编辑体验 | M0 自动基线 + 阶段末人工 IME | 自动基线通过，人工待验收 |
| 独立 vault 可实现作品级明文隔离 | M0 加密 spike | 算法验证通过；全路径隔离留在 M5 |
| 开源转换链可满足基础 DOCX/PDF 质量 | M0 文档转换 spike | 基础 fixture 通过；复杂往返结论为调整 |
