## 问题与目标

已确认增量（DEC-070，2026-10-07）：用户批准多来源歌词与本地复用改造。新增独立默认关闭的 QQ 音乐匿名普通 LRC 来源，明确 u.y.qq.com 当前歌名/歌手搜索与 c.y.qq.com 匹配歌曲标识查询；不读取账号、收藏或解密播放器缓存。LRCLIB 仍兜底，已有本地歌词/手动导入优先，严格核对录音版本和时长，不保证全部歌曲或来源长期稳定。酷狗本批不接入，正式2.0.0/M12不变。

已确认增量（DEC-068，2026-10-06）：用户批准个人歌词库与默认关闭的LRCLIB自动收集，只发送当前歌曲标题/歌手/专辑/时长；保存匹配歌词及逐曲校准，随资料备份、离线复用，不保存收听次数或扫描QQ收藏。替代DEC-067仅会话歌词边界。封面增加作者/年份提示、候选复用与单卡确认（DEC-069将批次补图改为缺图筛选、整页编辑）；显式辅助搜索可复用已配置腾讯搜索与DeepSeek，仅名称/版本及公开摘要经隐私审核，不发送感想、聊天或整库、不生成歌词或直接下载模型图片地址。

已确认增量（DEC-067，2026-10-06）：以QQ音乐系统会话伴听取代第一导航音乐页，旧本地曲库保留在数据管理；创作空间仅写作、日记、资料，资料兼容现实记录与作品设定，不猜测旧记录类别；背景默认单图，统一壁纸或完整比例插画、可读纸张保护和素材引用，旧图成功迁移才替换。系统歌曲/本地歌词仅会话内呈现，不自动进AI或备份；联网歌词具体来源与字段待独立确认，未承诺QQ原生歌词接口。

- 要解决的问题：现有写作、资料、图片与个人空间工具割裂，长篇中文写作缺少兼具可靠性、私密性和个人化的本地桌面环境。
- 期望结果：从零构建 Windows 桌面应用「一隅」，形成可日常使用的本地写作、记录与个人规划空间，并按需扩展音乐与虚拟伙伴。
- 产品原则：只为用户本人长期使用；能力可以丰富，但默认界面与操作必须简单，不为商业化、团队流程或功能数量增加负担。
- 目标用户：单个 Windows 10/11 本地用户。
- 为什么现在做：产品与开发规格已形成 0.1 基线，可以进入分阶段实现与验证。

## 成功标准

用户确认的当前体验增量（DEC-072，2026-10-07）：QQ伴听提供独立角色旁字幕、整曲阅读及可选固定桌面；语音交谈完整朗读与唤醒后连续采集衔接、本机麦克风检测。不得将唤醒前音频外发或以硬件远距离保证替代真实验收；原来源/声纹/默认关闭、非商业个人使用和丰富但简单原则保持。

- [ ] 可安装的 Windows 桌面应用具备模块化外壳、主题与布局持久化。
- [ ] 写作、资料、图片、版本、导入导出、备份和作品级加密通过自动质量门禁；仅对自动化无法判断且确有必要的体验风险做少量集中人工检查。
- [ ] 核心写作离线可用，异常情况下不静默丢失正文，数据可通过开放格式带走。

## 核心用户路径

1. 创建作品、卷和章节，持续编辑并由自动保存与历史版本保护内容。
2. 建立人物、地点和事件，与章节形成双向关联并在时间线浏览。
3. 个性化主题与布局，导出或备份数据，并按需锁定私密作品。

## 约束

- 技术：Tauri 2、Rust、React、TypeScript、Tiptap、SQLite；前端不直接访问数据库和资料库文件。
- 兼容性：Windows 10/11，默认简体中文，保留 i18n 键值。
- 性能：冷启动目标小于 3 秒；普通章节打开小于 500ms；10 万中文字符可流畅编辑。
- 安全与隐私：本地优先；密钥不进入数据库、日志与备份；锁定作品不得泄露明文元数据。
- 时间或资源：AI 辅助单人分里程碑交付，不将原型等同于完整第一阶段。
- 依赖和授权：使用可审查的开源依赖；AI、云服务和插件遵循最小权限。

## 验收方式

- 自动检查：前端单元/组件测试、类型检查、lint、生产构建、Rust 测试。
- 人工检查：不设固定场景或连续天数；安装后自然体验核心写作，只有自动化无法判断或实际发现问题时再做针对性回归。
- 浏览器或设备：Tauri WebView2，Windows 10/11 常见缩放比例与中文输入法。
- 数据或性能指标：10 万字章节、匿名大资料库 fixture、备份恢复校验和锁定态明文扫描。
