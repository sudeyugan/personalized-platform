# DEC-104：水墨手稿想法工坊

用户2026-10-18批准：模糊念头、多轮选项与自由补充、主动澄清/质疑、返回改选、阶段收束；暖纸水墨、文字浮现/克制晕染；复用既有API和隐私保护。

## 实现与边界

- 独立ideas领域/Store slice/模型服务/页面；可选资料集合兼容旧库，随既有完整及共享备份保存，无新表/密钥/依赖。
- 只送本份seed、有限近期轮次及当前手稿；不接Tool，不读其他聊天/作品/邮箱。复用Provider、外部AI总开关、脱敏审查；请求前后检查session revision、配置、模块和取消状态。
- 有界JSON；原话、模型整理与用户编辑分开。模型建议不擅自覆盖编辑稿；返回创建分支保留原稿，失败/暂停可继续。
- 手稿册/当前问题/3–4方向/自由补充及可编辑手稿；CSS代码原生水墨、浅深窄屏/reduced-motion。导航/模块/本机搜索/能力透明同步，不默认让小鱼读取想法。

## 验收

1. 归一化/旧库、重载/分支/回收恢复、编辑稿保护、过期响应不写入。
2. 模拟Provider闭环、选择/自由输入/收束/继续、无工具/其他私密数据、撤销/取消/超时/秘密与审查失败路径。
3. 实际隔离浏览器浅深宽窄/交互/reduced-motion，不操作真实账号或调用真实密钥。
4. 定向先行，冻结后一次按存储风险完整批次；失败仅定向处理。Windows运行双检保护候选、hash/源核对、正常main推送。

正式2.0.0/M12不变，真实模型和艺术观感自然回验。建议不是事实/用户立场；手稿与日记同为普通本机内容并随备份保存，不宣称额外加密。
