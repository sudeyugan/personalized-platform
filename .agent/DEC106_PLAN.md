# DEC106 多端首版

2026-10-18，用户批准：常开 Windows 作私人中枢、多 Windows 和 Android 独立本地资料/离线同步；手机含轻量伙伴。不是立即开放公网或远程接管电脑。

## 实施边界

- 独立中枢进程，不依赖主窗口。默认仅 loopback；远程须显式配置 HTTPS，程序不修改防火墙、自启动或安装系统服务。
- 中枢只存密文操作；每设备独立凭证，一次性限时邀请；同步密钥只在设备间由用户传递。删除传播用墓碑，并发保留为冲突，不能静默最后写入覆盖。
- 首批文本记录：写作/人物地点事件、待办/作业/日记/心情/课程/日程、经历册、想法手稿。素材文件、加密作品、音乐、本机偏好/浏览器/授权/任务/密钥不混入同步。素材缺失明确提示，不伪称附件已经同步。
- Android 独立轻量壳，复用同步协议；前台/恢复时同步，离线可编辑。桌宠显式请求悬浮层、前台服务通知；不移植电脑控制/摄像头唤醒。
- 同步不替代备份。撤销阻止以后访问，不抹去对方已取得的资料或密钥；密钥丢失无法由中枢恢复。

## 实现与验收

1. 共享协议/密文/本地 outbox、分支冲突与恢复；离线两端、重试幂等、删除与并发、篡改/错误密钥验证。
2. 独立中枢：持久化、认证/邀请/撤销、限额、TLS/CORS 边界与失败路径。
3. Windows 设置与持久化后同步接入，不干扰现有保存/解锁，不把整库或设备权限上送。
4. 手机轻量页面/原生悬浮层。工具链/设备不存在时必须标出 APK 与真机尚未验收，不能以 Web 预览冒充。
5. 风险匹配的整批验证、Windows 候选构建/运行保护、推送；真实双 Windows/Android 与网络部署集中人工验收。

当前工具链调查：WSL 有 Node24/Java，Windows 有 Cargo；未找到 Android SDK/ADB/Windows Java。未经确认不下载大型 SDK/接受许可，也不假定当前电脑就是常开中枢。

正式版本仍 2.0.0/M12 待人工验收，此批准增量不自动结项 M12 或命名 M13。
