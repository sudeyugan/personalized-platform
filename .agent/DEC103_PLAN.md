# DEC-103：隐私最小化的浏览器代理深化（2026-10-17）

用户批准执行/恢复、常用控件、模型理解搜索筛选、多步目标闭环四项，并要求更多利用DeepSeek但保护隐私。

## 范围与边界

- DeepSeek负责自然语言参数解释及下一步规划，本地核对当前控件、用户依据、参数形状、授权/预算；不再只准query逐字包含于原话。日期由模型选择范围、端点，本地依据北京时间计算校验，不从网页授予输入目的。
- 修复continued登录状态误挡。机器可读区分动作派发前陈旧、派发结果未知；前者有界重观察/重新决策，后者只观察核验、不重放。状态等待/多步预算保持有界，不取消陈旧引用检查。
- 扩展常见低风险菜单/弹窗关闭/自定义选项、日期和排序、同源frame及新标签页衔接。仅固定DOM语义，不接任意脚本、选择器、密码/Cookie或高影响动作；兼容扩展不静默升级操作协议。
- 默认模型工具视图只给固定操作语义、临时引用和必要统计证据，不给页面正文、私人标题或账号路径。需正文理解时使用独立显式工具、限定用户本次内容目的和节选，并强制现有发送前人工审查；不借普通查询自动脱敏许可跳过。云端仍能看到用户问题/必要站点和已批准的最小信息，不承诺绝对零泄漏或抵御恶意网站。
- 结果仍现场逐字证据复核、当前页面/已访问范围限定；私人原始回执只本轮RAM/本地呈现，不入历史、方法记忆或日志。读详情可能由网站产生已读等副作用，不能许诺所有导航纯读取。
