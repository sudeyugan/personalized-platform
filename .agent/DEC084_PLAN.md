# DEC-084 自动操作学习与 Edge 会话读取

用户反馈：不想手填方法；已登录B站仍不能查看关注直播，要求修复同类能力；指定日常浏览器Edge。

目标：成功操作自动形成受校验的工具流程经验，不需要填写表单；同类用户任务复用经验，但不扩大权限。新增通用Edge扩展连接与已授权页面DOM读取，B站关注直播为固定只读适配器示例，不做邮件专用或B站专用记忆。

架构：独立browser_bridge本机回环服务，主窗配置、随机连接码/绑定扩展Origin、DPAPI保存配对秘密、按HTTPS网站双侧授权、撤销/取消/超时/迟到隔离。扩展仅storage/scripting/alarms及本机连接，网站为可选权限；无cookies/debugger/任意JavaScript/HTTP代理/页面写入工具。配对需用户一次安装并授权，不擅自安装或授予权限。已有会话只由浏览器自身使用。

自动学习：从真实成功工具轨迹生成完整受限方法，参数取本次目标或前序结果而非记录原值；不保存正文/凭据/临时标签页或控件ID，不多调模型，不学习失败/不明结果或高风险工具。去重，停用/手改/删除不被自动覆盖；全局可关闭。相似命中仅当前用户任务的参考，歧义/写入确认保持。

验收：本机HTTP身份/大小/Origin/重放/配对过期/安全输出、浏览器撤权/标签页变更/隐私注入隔离、自动学习去重/关闭/删除抑制/不存原文、实际扩展隔离浏览器接线、Windows verify:full、Release/桌面产物核对。真实Edge安装及B站登录页集中用户验收，不自动读取账号。
