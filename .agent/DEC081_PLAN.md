# DEC-081 受控电脑接管首阶段

2026-10-11：用户在电脑接管方案调研后明确“可以的，着手吧”。本批实现有界、可见的单窗口接管；不是全盘授权或无人值守。正式2.0.0/M12保持，不提交推送。

## 首阶段范围与验收

- 复用 Windows/Rust、现有文字模型及电脑总开关；新增 UI Automation 读控件和结构化填值/调用，不依赖固定坐标，不改权限默认值。
- 用户选择唯一窗口和目标，明确同意本任务界面文字发送至已配置 DeepSeek；不发送截图、密码、聊天/资料库、整机窗口内容。未配置模型或关闭外部AI不得启动，不安装新云服务。
- 一次明确开始仅覆盖选定窗口、有限时长/步数；每轮重新观察、执行一项、再检查结果。模型不能调用文件/Shell/任意鼠标或扩大窗口；只读模式不允许操作。
- 原生绑定 HWND/进程和短期会话，过期/停止/目标消失/旧观察失效即拒绝，输入前复查控件与范围；密码字段拒绝。发送/提交/付款/删除/覆盖等动作首阶段交还用户，不用模型自称安全绕过门禁。
- 简洁任务面板显示当前阶段，支持暂停/停止；既有紧急停止撤销会话。暂停后不自动重复可能成功的动作，恢复重新观察；结束释放界面文本及会话，不保存屏幕内容。
- 定向覆盖参数/范围/只读/禁止动作/状态及撤销，Windows verify:full、隔离自建窗口 UIA 探针、Release/NSIS/桌面交付及哈希。浏览器模拟和测试不冒充通用软件成功。

## 后续边界

- Playwright 通用浏览器会话/网页 DOM 控制及截图视觉后备不是本阶段实现：前者涉及独立浏览器运行组件/登录与站点授权，后者需要用户选择可看图模型、截图外发与成本设置。先补完整单窗口闭环，再按明确配置推进；不得把本阶段称全电脑/全部网页接管。
- 文件整理继续用现有按目录授权工具，自动分类/批量可恢复方案另在后续场景推进，本阶段不改变 file.move/delete 的逐次确认。
