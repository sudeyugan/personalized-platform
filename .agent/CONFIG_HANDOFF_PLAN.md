# 已授权设备的配置交接（2026-10-20）

用户明确批准新设备可选「沿用已有配置」：旧设备按目标/范围批准，独立端到端加密传递 API Key，目标原生重新保护；可跟随或停止跟随并保留当前值。只扩展 M13.2/13.3，不推进远程任务/文件或合并 main。

## 实施与验收

- 独立协议/本机状态/中枢限额与过期中转，不新增普通 Records 集合，不把 Key 放进邀请、聊天、日志或明文配置。
- P-256 ECDH + HKDF-SHA256 + AES-256-GCM，原生封装/导入；请求/包用资料组 HMAC 认证防中枢替换。批准时核对请求指纹，绑定空间、双方设备、目标公钥、范围、序号；不保证抵御已持组密钥的恶意配对成员冒充。
- Windows DPAPI / Android Keystore 保护交接私钥与导入包。兼容 API26 的 Android ECDH 私钥由 Keystore AES 包封，不冒称硬件不可导出。WebView 只见公钥、密文和模型/声音标识，不新增明文 Key 读取接口。
- 原生系统确认并保存目标公钥/范围许可，普通密钥接口禁止写内部槽，封装前原生重查。拒绝/停止/已确认单次交接撤许可；单次许可保存当前Key快照，不可借重试取得后续轮换Key。Android确认45秒自动取消，Windows/Android实际原生确认UX仍需用户体验。
- 仅移交两端支持的 DeepSeek 与 ElevenLabs 设置，固定官方端点；不继承系统权限、浏览器登录、麦克风/摄像头/唤醒设置。
- 请求十分钟有效；批准后单目标最新包、序号防重；断网保留现有设置，成功导入才确认。可独立配置，保留当前值并停止后续接收。
- 定向覆盖篡改/错设备/超期/越权/拒绝/撤销/失败恢复/本机覆盖；跨层批次一次 full、Windows候选与Android构建，隔离虚构凭证验证，不用真实Key或部署中枢。
- 撤销只阻止后续交接，已收到 Key 须在供应商轮换；旧密文可能留在备份，不称安全擦除。真机/跨网仍集中人工验收。

当前：代码与风险匹配自动检查已收口，形成Windows和0.4.0-preview Android候选；真实原生确认、手机Keystore/跨网与自然体验待集中验收。具体证据与产物见 PROJECT_STATE，不自动结项M13。
