# DEC-072：独立歌词呈现与语音可靠性（2026-10-07）

用户批准伴随字幕、展开阅读及按需独立摆放；追加反馈：小鱼回答中途被截断、经常唤醒无响应、讲话开头漏识别且需贴近麦克风。

## 范围与顺序

1. 修复完整朗读遇段落即停止；语音交谈完整读完，不沿用文字聊天的前段上限，保留主动停止与打断。
2. 本地麦克风连续采集；本地唤醒和可选声纹通过后才接入已授权ElevenLabs。安全检查拒绝将唤醒前音频外发，本批采用仅验证通过后未来样本的内存衔接，丢弃全部待机队列，连接准备最多保留8秒、结束即清空；无唤醒前回放/保存音频。实时VAD/活动计时与错误恢复独立修复；提供本机麦克风选择、15秒本地音量检测和1～3倍唤醒采集增益，不修改系统音量或关闭声纹。
3. 独立透明歌词窗口，默认角色旁字幕，按需多句阅读/固定桌面；字号、透明度、穿透为本机偏好。仅当前歌曲显示数据，控制/逐曲校准仍由主窗复核，无整库/秘密/录音权限。
4. 窗口、音频状态、定位、队列分责，不扩大CharacterController/Bridge职责；无新来源、依赖、假逐字时间轴或自动播放控制。
