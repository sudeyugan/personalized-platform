# DEC-069：经历册简化与歌词查找修复

- 目标：用户授权重构经历册操作；修复歌词全部失败，示例《河流（live）》。不变更记录/封面/排行的数据格式，不删除旧数据，不替换既有提供商。
- 经历册：作品/足迹、搜索、排行与新增为主入口；整页编辑；默认名称、感想和档位，作者/时间/纸封为展开项；封面直接用当前名称查找，技术选项折叠；缺图为筛选，不再串行批次。
- 歌词：同一LRCLIB固定目的地先get后有界search；规范全半角括号/艺人分隔符但保留Live等版本身份与时长核对；专辑为优先项；区分无匹配/网络/限流；逐曲失败冷却不阻塞其他歌；显式重试仍遵守开关、隐私与速率限制。
- 验证：经历册新增/保存/放下/收纳恢复/排行，歌词身份、旧请求隔离、逐曲冷却和重试；一次verify:full（native网络变化）；Windows Release候选和桌面EXE更新，不更改正式2.0.0/M12状态，不提交推送。
- 边界：不新增歌词来源，不让AI生成带时间戳歌词，不把普通版当现场版；实际来源覆盖不足如实提示。用户示例未给歌手，不能猜测唯一录音。

- 2026-10-07结果：完整497前端/83Rust及最终21定向/UI静态通过，公开原生LRCLIB探针成功；Release/NSIS和桌面EXE已更新，证据见PROJECT_STATE。数据兼容与安全边界未偏离，用户具体现场版覆盖仍待核对，不冒充已解决来源缺词。
