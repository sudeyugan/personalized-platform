# DEC-087：浏览器连接自动维护与单入口网站管理

用户要求准备/重载扩展及打开目标页尽量自动，添加网站尽量只改一个地方。批准范围：一隅作为网站清单入口，Edge保留原生可选权限确认；本机固定目录的内置扩展资源随启用启动更新、已接入新协议的扩展有界自重载。旧0.1扩展不具备此能力，需一次人工迁移，首次安装与浏览器确认不得绕过。

实现：独立native维护/设置请求模块，已配对本机poll携带版本/应用清单/显式设置请求；网页不得连接或发指令，仍绑定Origin/DPAPI随机码。添加网站只填一隅，显式操作可自动打开扩展自有确认页；按钮直接调用permissions.request以保留真实用户手势，确认后核对本次id/epoch/时限/清单，才可打开本次勾选的精确目标域名。拒绝/取消/配置变更/迟到失败闭合，不授予全站。应用删除立即停止读取，扩展同步释放权限；扩展侧撤销仍独立有效，不自动重新授予。弹窗不重复维护网站清单。

自动更新只读取应用内置资源并写既有app_data/edge-extension，生成SHA-256内容指纹后最后写manifest、完成后才通知；重载最多同版本＋指纹目标一次，同协议版本的文件修改仍可识别，失败显示手动修复，不执行远程JS、不改浏览器策略/注册表/账号配置。网站打开限用户显式设置请求，不给模型新的navigate/点击/网页写入能力，不增加Cookie/密码/资料留存或后台网站查询。B站单入口可选完整直播+动态5精确域，不自动迁移扩张旧用户3域。

完成证据：最终冻结Windows full整体退出0（181文件1021前端/142 Rust、12默认忽略及类型/lint/Web构建），最终補充定向11文件89项通过，覆盖资源导出失败和同版本指纹取消。实际隔离Edge虚构桥接完成自动确认页/实际权限API（预授权fixture）/不打开网站选择/同版本内容指纹重载保留配对/失败一次后停止及360px明暗主题无横向溢出；不使用用户配置/账号。Windows Release/NSIS及桌面更新完成，241处应用源码镜像一致、项目/镜像/桌面EXE及NSIS哈希核对见PROJECT_STATE，既有2项lint/act/分包提示保持。docs:check通过；附加release:check因候选包与旧正式状态哈希不同失败，不改写正式基线、不称正式发布。旧版本迁移与真实授权/账号集中自然验收。

验证：版本迁移/重载防循环/旧协议/忙碌、唯一用户手势、授权拒绝/撤销/断开/epoch/配置变更、单入口/32域上限/不重复输入、跨站与真实主窗权限、资源导出完整性。定向及冻结Windows full、隔离实际Edge虚构桥接/确认页（非用户账号或原生授权弹窗验收）、最终Release/NSIS/桌面和镜像哈希。正式2.0.0/M12保持，旧改动保留，不提交推送。真实首次迁移/Edge提示由用户集中自然体验。
