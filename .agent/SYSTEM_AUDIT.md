## 触发条件

仅在以下情况执行完整审查：

1. 开始、完成或交接里程碑/正式发布。
2. 计划、架构、范围、验收标准、安全边界或持续风险变化。
3. 上下文压缩后无法确认目标和当前事实。
4. 连续失败、用户指出偏离，或状态文件可能失真。

普通问答、只读调查、文案/CSS 小修、定向测试通过和没有状态变化的任务不触发完整审查。时间间隔只提示长任务检查是否失真，不作为机械打卡。

## 审查要点

- 读取 `PROJECT_BRIEF.md`、`PROJECT_STATE.md` 当前部分及与任务直接相关的规则。
- 用代码、Git 和风险匹配的验证校验状态，不通读归档历史。
- 检查目标/范围/兼容性/安全边界是否变化，以及是否需要用户确认。
- 只更新事实发生变化的状态、计划、决定、风险或经验文档。
- 正式发布确认验证、安装包、哈希、文档与人工状态相互一致。

### 2026-09-24：Agent 电脑能力与系统权限边界审查

- 触发原因：Agent 首次获得 Windows 窗口、输入、剪贴板、文件、进程、Shell、通知和全屏录制能力，属于高风险权限与架构边界变化。
- 审查结果：架构边界合规。模型仍只能调用 Registry 中登记的 Tool；前端按 capability、risk、目标和长期规则判断，Rust 主进程在执行前复核同一策略并拒绝非主窗口。旧资料升级后电脑总开关保持关闭。
- 文件与进程：文件要求绝对路径并规范化现有路径/父目录，目录授权按边界匹配，敏感凭据路径需确认，文本限制 1 MiB，目录删除不递归。普通进程使用程序加参数数组，不经 Shell；PowerShell 永远逐次确认；只能停止由小鱼登记的子进程。普通打开工具拒绝非 HTTPS 协议和脚本/安装类扩展名。
- 录屏与停止：截图/录屏只调用已探测或用户指定的 FFmpeg；自定义输出需要默认录制目录、文件授权或逐次确认。托盘和全局快捷键可统一停止录屏及受管后台进程，录屏或受管进程活动时关闭主窗口只隐藏不退出。
- 审计与隐私：审计保存 Tool、脱敏参数形状、目标、权限原因、确认与结果，不记录正文、密码、Token 或密钥。截图、剪贴板、录屏和文件内容属于新的本机敏感面，必须由用户显式开启总开关；外发仍另经既有 Privacy/Egress Gateway。
- 验证：TypeScript 通过；lint 只有既有 warning；Agent 权限定向测试 18/18；Rust 39/39、1 项外网测试忽略；生产 Web、Windows Release 与 NSIS 构建通过，桌面副本与 Release SHA-256 一致：`9C1436DE9056A5E695CE370F7E6AC81EC514B86819ABA0AAAE4285F057E7A840`；安装包 SHA-256：`4FEF7AEBB24C18F423F5F75E414DEC38AEB0F0C064790F338359EAAB956DDDCC`。全量前端 104/109，5 项仍为既有设置/导航断言，故完整门禁保持未通过；本机 rustfmt 未安装。
- 人工项：需用真实 DeepSeek 验证 Tool 选择、逐次确认、目录授权、全屏/窗口录制、紧急停止、托盘提醒与 Windows 通知权限。应用完全退出后不会继续提醒或执行。

### 2026-09-23：本地模型下载源与任务生命周期审查

- 触发原因：本地模型新增国内镜像、持久下载源设置、跨页面任务单例与取消命令，涉及外部域名、并发和下载生命周期边界。
- 审查结果：合规。默认国内优先仅请求公开模型：KWS 走 ModelScope，声纹走固定 Hugging Face 国内镜像；自动模式失败后回退 Hugging Face/GitHub，全球模式才优先官方全球源。各来源均保持固定大小与 SHA-256 校验，镜像无法用不同内容替换模型。
- 数据与权限：下载请求只包含固定模型 URL 与通用一隅 User-Agent，不携带音频、声纹 embedding、资料、API Key 或设备标识。模型仍写入应用数据 `local-voice/models`，不进入资料备份。
- 生命周期：前端模块级单例复用同一 Promise、Channel 和进度快照，切换页面不停止任务；Rust `AtomicBool` 再次防止重复下载，并允许主窗口发出取消标记。取消在连接或当前响应块返回后生效，不宣称瞬时终止底层网络系统调用。
- 验证：国内声纹镜像直连返回 28,281,138 字节且 Linked ETag 与固定 SHA-256 一致；TypeScript、迁移测试 5/5、Rust 本地语音测试 3/3、生产 Web、Windows Release、NSIS 与桌面哈希核对通过。误触发全量前端 95/100，5 项仍为既有导航/旧设置断言。
- 人工项：需在真实网络下载中确认国内源速度、页面往返后进度恢复、取消延迟、失败后自动回退及再次下载行为。

### 2026-09-22：本地语音唤醒与声纹边界审查

- 触发原因：语音待机从持续云端转写改为本地关键词检测，并新增声纹特征与按需模型下载，属于音频、生物特征、网络和依赖边界变化。
- 审查结果：合规。待机音频只进入本机 sherpa-onnx；只有自定义唤醒词命中且可选声纹校验通过后，才沿用现有受限命令申请 ElevenLabs 短期令牌。云端聊天约 45 秒无活动后关闭并恢复本地待机，长期 Key 继续只由 Rust/DPAPI 保管。
- 数据与权限：录入只保存聚合后的 speaker embedding，不保存原始 PCM；特征使用现有 DPAPI SecretRepository，且不进入普通资料备份。声纹明确不是身份认证，不能放宽 Tool capability、scope、风险分级或逐次写入确认，也不具备抗录音重放保证。
- 下载边界：模型优先从固定 sherpa-onnx GitHub Release 地址按需下载；连接失败时，关键词文件回退 sherpa 官方文档列出的 ModelScope 仓库，声纹文件回退模型作者的 Hugging Face 仓库。所有来源逐文件执行大小上限和 SHA-256 校验，保存在应用数据的 local-voice/models，不随安装包或资料备份分发；公开再分发模型前仍需单独核对具体模型许可证与归属。
- 验证：TypeScript、生产 Web、迁移定向测试 5/5、Rust 30/30、Windows Release、NSIS 与桌面源/副本哈希核对通过；lint 仅既有非阻断警告。完整前端测试 95/100，5 个失败仍是旧设置折叠与导航入口断言；rustfmt 未安装，未运行格式器。
- 人工项：首次模型下载、Windows 麦克风授权、自定义中文唤醒词准确率、本人/非本人区分、播放录音重放风险、CPU 占用及 45 秒云端会话恢复需要真实设备自然体验。

### 2026-09-22：内容外发隐私网关第一阶段审查

- 触发原因：外部模型链路新增内容级检测、转换、确认和恢复，涉及 Agent 多步调用、Tool 参数、安全阻断及语音边界，属于隐私与安全架构变化。
- 审查结果：合规。Egress Gateway 包装 ModelProvider，不改变 Runtime/Registry/Permission/Application Service 顺序；模型看到占位符，Tool 参数在本机恢复后仍需 schema、scope、风险和逐次确认。SECRET 在 Provider 调用前抛错，用户确认不能绕过；预览只展示脱敏文本且不持久化。
- 边界：私密词典保存在本地资料库并随现有备份策略处理；朝问无交互预览但仍自动过滤。外部 STT 必须先接收原始音频，当前不声称文本过滤能保护上传前音频；要消除此项外发需另接本地 STT。
- 验证：TypeScript、生产 Web、定向隐私/信任/迁移测试 8/8、Rust 27/27、Windows Release 与 NSIS 通过；lint 仅既有非阻断警告。完整门禁全量前端 91/96，5 个既有导航/折叠 UI 断言继续失败，未归因于本次改动。
- 偏差与后续：第一阶段未增加资料实体级隐私标签，也未捆绑本地 NER。已调研 OpenAI Privacy Filter、rail-v2、GLiNER2 中文变体、繁中和多语言候选；必须先解决许可证与简体中文实测问题，再以可替换检测器接入现有网关。

### 2026-09-22：伙伴写入扩展与语音唤醒审查

- 触发原因：Create/Modify Tool 从首批动作扩展到多个业务模块，语音从用户按键录音增加可选持续监听，属于权限、安全和外发边界变化。

- 时间与语音：Agent Context 每轮按 Asia/Shanghai 生成日期、星期、时刻和时段，Runtime 与 Provider 同时携带。持续“小鱼”唤醒默认关闭，仅 ElevenLabs 可用；子窗口继续只取得 15 分钟短期 token，不接触长期 Key。命中唤醒词后进入 45 秒可续期的语音聊天窗口，Agent/TTS 忙碌时忽略转写；唤醒回合强制 2–4 句并可自动 TTS。
- 数据与兼容：旧资料库由 seed 合并补 `wakeEnabled=false`；日记普通导航重置今天但日历指定日期路径不变。新写入复用既有保存/备份链路，不新增存储格式；现有完整画布/立绘/WebM 数据不迁移。
- 验证：TypeScript、Agent/Provider 定向测试 18/18、前端生产构建、Rust Release、NSIS 与桌面源/副本哈希核对通过；未运行 lint 或全量测试。真实 DeepSeek 写入选择、Windows 麦克风授权、唤醒准确率、回声和 ElevenLabs 长时额度消耗待用户自然体验。
- 偏差：用户所说“完整写入”实现为常用可逆的应用内创建/修改，不包含删除、安全设置、任意文件、Shell 或 Windows 控制；这是沿用既定风险边界，不是任意电脑操作代理。

### 2026-09-21：伙伴文字与语音流式架构审查

- 触发原因：模型请求由整段响应改为 SSE，语音输入新增浏览器到 ElevenLabs 的实时 WebSocket，属于网络与密钥边界变化。
- 审查结果：合规。DeepSeek 仍只由主窗口 Rust 访问官方域名；模型仍只能经 Tool Registry、Permission Engine 和 Application Service 读取授权数据。新增地点与时间线工具继续复用 `records` 权限，没有 SQL、Repository、文件或 Shell 入口。
- 密钥与网络：ElevenLabs 长期 Key 仍由 Rust/DPAPI 保管；聊天窗口只获取 15 分钟失效且单次使用的 `realtime_scribe` token。CSP 仅新增官方 `wss://api.elevenlabs.io`，音频 worklet 同源托管。长期记忆未开放为 Tool，避免在缺少单独外发授权时发送给 DeepSeek。
- 状态与兼容：流式临时文本不写资料库，完成后仍只保存一条完整消息；非 ElevenLabs STT 保留原批量 Provider 回退。TTS 按句顺序生成和播放，保持现有 Voice ID/Provider 设置。
- 验证：TypeScript、Rust check、前端生产构建、伙伴定向测试 10/10、Windows Release 与 NSIS 通过；意外全量前端测试 78/85 通过，7 项中 6 项为既有旧 UI 断言，新增工具数量断言已同步并通过。真实 DeepSeek/ElevenLabs 账号、麦克风设备和首包延迟待本机自然体验。
- 偏差：没有扩大到写入 Tool、长期记忆外发、Computer Use、MCP 或 Live2D；TTS 当前为分句流式，不宣称单句内部音频帧流。

### 2026-09-20：桌面聊天独立窗口架构审查

- 触发原因：用户连续确认同一 companion WebView 向左扩展仍在 Windows/WebView2 实机闪烁，原窗口编排方案无法满足“立绘位置不变且无闪帧”的验收。
- 审查结果：合规。立绘与聊天拆为两个透明置顶子窗口，主窗口只负责定位、显隐、裁剪快照和 Agent/语音事件转发；没有改变模型、Tool、权限或资料访问路径。
- 安全边界：`companion` 与 `companion-chat` 共用仅含必要窗口/定向事件的 capability；Rust 自定义资料、密钥、备份和网络命令仍强制 `main` 标签。聊天窗口不读取素材，立绘素材继续受内存白名单守卫。
- 结构与兼容：`DesktopCompanionWindow` 只渲染和拖动立绘，`DesktopCompanionChatWindow` 只承载消息/输入/语音控件，`CompanionDesktopBridge` 统一协调；现有消息、长期记忆、Agent 会话输入和新对话语义不迁移数据。
- 验证：TypeScript、Rust check、生产前端、Rust Release 与三窗口 NSIS 构建成功；未运行 lint 或测试。左右贴边、多显示器/DPI 与真实透明 WebM 继续列为人工体验项。
- 偏差：属于针对实机缺陷的最小架构修正，不改变 M10 目标范围；旧同窗扩展命令和专用 Windows API 依赖已移除，避免保留双路径技术债。
- 同日 WebM 导入与显示补丁：视频字节上传和伙伴窗口读取均改为 Tauri 原始二进制 IPC，避免大文件 JSON 序列化停顿；上传命令仍只允许 `main` 调用，读取命令仍只允许 `companion` 且必须命中主窗口维护的当前素材白名单。Rust 继续执行 200 MB 上限并固定按 `video/webm` 保存；Unicode 文件名只经 Base64 请求头传递并经过现有文件名清理，不新增任意路径读取或文件系统权限。设置 UI 拆为静态/动态两个编辑页并显示分阶段导入和实际播放结果；元数据预读失败仅取消尺寸提示，不绕过文件大小、类型和权限校验，也不阻断素材保存。实机确认文件与入库副本无损且 Edge 可解码后，将 CSP 从只允许图片 Blob 修正为额外允许 `media-src 'self' blob:`；仍未允许任何远程媒体来源。
