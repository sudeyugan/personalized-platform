## 触发条件

仅在以下情况执行完整审查：

1. 开始、完成或交接里程碑/正式发布。
2. 计划、架构、范围、验收标准、安全边界或持续风险变化。
3. 上下文压缩后无法确认目标和当前事实。
4. 连续失败、用户指出偏离，或状态文件可能失真。

普通问答、只读调查、文案/CSS 小修、定向测试通过和没有状态变化的任务不触发完整审查。时间间隔只提示长任务检查是否失真，不作为机械打卡。

## 审查要点

- 读取 `PROJECT_BRIEF.md`、`PROJECT_STATE.md` 当前部分及与任务直接相关的规则。
- 用代码、Git 和风险匹配的验证校验状态，不通读归档历史。
- 检查目标/范围/兼容性/安全边界是否变化，以及是否需要用户确认。
- 只更新事实发生变化的状态、计划、决定、风险或经验文档。
- 正式发布确认验证、安装包、哈希、文档与人工状态相互一致。
