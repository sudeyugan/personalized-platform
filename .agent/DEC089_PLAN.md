# DEC-089：群体开播意图与已填登录表单接续

用户明确要求修复“现在B站有up主开播了吗”泛搜索，必要时重构；邮箱登录页已有浏览器缓存凭据，希望自动登录。当前扩展只读不能点击，属于批准的有限认证动作增量，不是任意网页操作。
