# Learnings and Process Improvements

> 保存可跨任务复用的经验，不记录一次性的过程流水账。

### 2026-10-09：Windows拖拽应检查WebView原生拦截

- Tauri主窗口未配置dragDropEnabled时默认开启原生拖放；本机CLI schema明确注明Windows前端HTML5拖放需禁用它。浏览器或jsdom的DragEvent通过不能替代桌面验收。若保留原生文件拖放，页内排序可用Pointer Events＋捕获＋坐标命中，显式禁止图片原生拖动，并覆盖轻点阈值、前后插入、拖后点击、取消/失焦、边缘滚动和卸载清理；同源静态命中先记风险，不把未复现入口说成已修复。

### 2026-10-08：找封面必须验证图片与采用保存闭环

- 漏检应覆盖“输入语法—来源范围—索引形态—身份—图片”的矩阵，不能逐本加ID映射。《雪中悍刀行》不仅缺纵横范围，真实搜索还只返回官方百科，括号主演又被误当作者；仅增加域名不足。原书名查询必须保留，作者组合独立补召回，身份排序应先于候选限额；未知作者不从用户提示伪造。官方百科只有明确唯一同名作品参考才有限跟进并重新核对真实作品；嵌套HTML不能用split切断尾部，应保留原文位置和UTF-8边界。书名召回/封面地址/真实栅格下载分开验证，CDN不可达不能用元数据成功抵充，也不因公开页可读而弱化TLS/验证。
- 官方域名中的keyword/SEO聚合页不等于具体作品页，路径数字不能当作品ID；本次《狩魔手记》首项漏图由SSR聚合数据格式差异造成。仅依据公开JSON明确的唯一主作品链接有限规范，再验证真实作品页ID并按规范URL去重，不从推荐/评论猜作品。需核对JSON所在对象，不能根据截断输出把字段名差异误认成本例根因。实际图片优先仅作同等身份匹配的次级排序，不能把不同作品有图当正确。
- 正确作品元数据不等于封面功能完成：网文候选固定coverUrl=None仍只能采用文字。验收应覆盖用户原书名/实际搜索配置、官方作品ID、白名单图片的真实字节，以及界面预览→「采用这张」→保存本地素材，不能仅用搜索命中代替。更名召回还需在前端排序保留明确线索，避免相似但不同的书名排在正确现名前。
- 删除入口要覆盖编辑页可发现性、取消、恢复、二次确认永久删除与持久往返；放下未保存草稿后，恢复不得复活这份草稿。记录删除与共享素材、既有备份删除不是同一授权，需明确告知并分别处理。

### 2026-10-07：桌面网络与自动查询必须验证真实启动条件

- 开发终端可能带HTTP(S)_PROXY，而双击EXE未继承；reqwest关闭default-features时需要显式system-proxy才能读取Windows已配置代理。只在测试子进程清除代理变量复现、不改用户环境：本次公开Bangumi旧版连接超时、补feature后元数据/白名单图片均成功。保留TLS/目的地/超时/字节边界，不能用终端联网成功代替桌面启动证据。
- 原生静态歌词探针不覆盖前端自动触发与负缓存：应同时核对真实媒体字段、暂停状态、授权开关和旧失败恢复。不可将封面代理根因套到仍能直连的QQ来源；暂停可授权查词，失败枚举需持久保存，显式重试不能继续复用空候选。

## 固化规则

当经验满足以下条件之一时，将其升级：

- 重复出现两次以上的错误：考虑加入 `AGENTS.md` 或机械检查。
- 稳定且重复的工作流：考虑创建 Skill。
- 可机械判断的问题：优先加入测试、lint、类型检查、hook 或 CI。
- 影响长期架构的结论：记录到 `DECISIONS.md`。
- 新的持续性风险：记录到 `RISKS.md`。

- 2026-10-04：Windows tao 的 startDragging/drag_window 使用 PostMessageW，Promise 成功不代表拖动结束；不能紧接其 then 吸边。当前桌宠仅拖动期间查询当前左键布尔值，在释放后布局，DOM pointerup为备用信号；无全局 hook 或历史。

### 2026-10-04：静态完整性不等于动画时序稳定

- 中性逐像素一致与极值无透明裂缝只能验证单帧，不能排除小尺寸像素图的逐行亚像素重采样抖动；需要跨时间采样，并隔离眼动/眨眼后比较身体。自然半身可保持固定轮廓、只在有限事件用整纹理变换，避免用持续高频变形制造待机感。
- 动画器的缓动状态不能把同一可变帧对象直接交给会缩放/加偏移的Renderer；输出嵌套坐标快照，由独立呈现模块调节，防止绘制变换反馈到下一帧内部状态。此原则适用于休息衰减、对话缩幅和拖动惯性。

### 2026-10-04：只读桌面气泡也需要最小原生通道

- Tauri核心event的listen/emit-to权限是通用事件命令，不按业务事件名限权；本机2.11.5源码event/plugin.rs确认无事件名CommandScope检查。不能仅凭“子窗只用两个API”宣称无法发送其他聊天/确认事件。
- 新状态显示窗用无通用event权限的capability；main标签守卫发布裁剪DTO，子窗标签守卫订阅Channel并发送有限固定请求，原生再匹配当前taskId。订阅编号防迟到卸载清掉新监听，隐私字段以serde deny_unknown_fields拦截；前端timeout/dismiss不是任务cancel。

### 2026-10-07：Windows预览与网络样本验证边界

- 隔离Vite预览也可能监听src-tauri/target，和Release编译同时运行会因锁定EXE触发EBUSY；完成视觉QA后先关闭自己的预览再打包。此错误不代表已成功打包的产品启动失败，不应为了处理工具冲突顺手重构产品运行时。
- 孤立挂载组件必须继承真实App容器的var(--bg)/var(--ink)，仅改data-theme而没有容器会产生假低对比；CDP各连接重新指定尺寸、JS表达式使用局部作用域，避免重复const污染。最终截图/溢出证据以修正后的真实主题容器为准。
- Windows Node辅助脚本也须进程级TLS=1，不能只保护pnpm命令；实际Rust HTTPS客户端的公开示例探针可验证产品网络通路，但不证明用户特定录音被歌词源收录。网络失败冷却必须区分本条记录和来源全局限流，不能让单条错误堵塞整库。

### 2026-10-07：语音衔接与透明歌词窗口

- 修复漏识别不构成上传唤醒前录音的授权。需要保留连续设备时，可丢弃全部待机队列，仅在唤醒及可选声纹通过后切换未来PCM消费者，按会话有界缓冲；不通过另一执行工具绕过隐私拒绝。
- 朗读模式必须在队列的字符上限和段落分割两处同时生效。空闲会话计时不应计作播放时限；回声过滤要覆盖近期句子和迟到的结束指令，暂时暂停但没有最终转写时必须恢复，不将自动测试当成真实声学验收。
- 独立阅读的字号改变也会改变当前行高度，跟随居中需监听字号/词变化而不只监听时间索引。当前歌曲大包按词变化发送，进度小包单独发送；位置采用目标屏物理尺寸/工作区，穿透必须有主设置恢复入口。

### 2026-10-08：目录查询必须验证最终查询词

- 已知官方URL和解析器回归通过不能证明搜索可用。Bing RSS把“完整书名＋作者＋多个平台名”返回成无关结果，完整书名加单一官方站点限制取得起点/番茄公开示例，但《我加载了恋爱游戏》仍退化成“我”字词典，不能推导完整标题策略普遍有效。实际反馈还暴露未沿用已有腾讯配置、拒收旧/移动官方路径和改名作品召回缺口；应覆盖用户原始标题、实际配置和官方ID，用最终Rust客户端验证，不能替换为更易命中的书名、另一条curl或硬编码别名/ID。官方摘要的明确更名线索只作有限再查询，推荐页不能当作品；保留来源白名单、同名核对与无图兜底，单例成功不代表所有平台覆盖。

### 2026-10-08：权限声明必须对应实际动作和实时范围

- 总开关、页面导航和功能动作是三层不同契约。给抽签页 app.open 不能称已经能抽签；模型“没有权限”的自然语言也不是权限审计证据。能力清单从实际注册工具派生，测试既有查询也有写入/控制，明确未接入动作及范围限制，不能为了“完整”自动绑定全部Store方法。
- 模型请求及确认会产生时间窗口；执行门禁和读服务必须使用同一当前权限范围。先确认不等于后来新硬拒绝的授权，取消也不能被同时切换的平衡策略反转。即时/任务导航都应走同一门禁；测试开启→关闭/确认→撤销/取消→自动及读取旧快照，而不只测初始配置。
- 本地文学随机结果可直接按实际题库呈现，无须模型续写。离线明确短指令、历史localOnly过滤和通用任务排除分别防后续外发；独立云端语音授权与降级旧版限制仍应说明，不宣称整个语音流程离线。
