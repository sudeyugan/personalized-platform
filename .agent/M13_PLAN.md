# M13：多端一隅与加密云中枢

2026-10-19，用户确认暂定采用云服务器部署中枢，并要求将多端归为新的里程碑；先记录方向，优先纠正 Android 过度简化、伙伴缺少屏幕适配的问题。

## 状态与授权

- M13 已规划，未正式启动或发布；M12 的真实 Provider/复合任务验收仍保留，不能自动标为通过。
- 当前 Android 改进继续在已批准的 `feature/multi-device` 分支，不合并 main。
- 云服务器方案已选，但厂商、地域、费用、账号与部署尚未确认。本次不购买、不开放公网、不迁移现有密钥或停止测试中枢。
- 云端默认协调/保存密文，理解与规划由发起设备组织并按既有许可调用模型，目标设备保留执行权。远程任务是后续实现，不是已有同步能力。

## 交付范围与顺序

1. **移动体验补齐（当前优先）**：不以只读文本列表冒充 PC 功能迁移。共享已有领域规则、美术和可移植组件；手机使用底部导航、工作区、全屏编辑、触摸布局。补齐已有同步文本的日常规划/心情回望/经历与创作资料操作、想法交互和阅读编辑，保留旧数据结构；未支持项明确说明，不删除原资料或静默降级富文本。
2. **手机伙伴**：复用 PC 原画与 Canvas 绘制，支持自由/左右/底部姿态、拖动吸边、屏幕旋转与安全区域、位置与大小偏好、休息/恢复；不叠加 PC 鼠标/摄像头追踪，不增加其他应用内容或屏幕采集权限。
3. **加密云中枢**：现有私人中枢部署方案产品化，受信任 HTTPS、认证、限额、备份/恢复、监控与升级。保留自建路径，不要求每人买服务器。公网部署需单独确认具体资源与边界。
4. **跨设备任务（后续）**：独立设备身份/授权、签名和过期/防重、本机最终复核、离线状态/取消/证据；先明确工具白名单，不直接同步本机运行任务或权限。
5. **推广前置**：共享托管需要租户隔离、设备恢复/撤销、滥用防护与运维验收；不把单用户 SQLite 原型直接开放多人注册。P2P 是可选后续优化，不阻塞首版，不做区块链或陌生节点互存。

## 完成条件

- Windows/Android 的已支持能力有逐项对照，不伪称完全等同；原数据可继续往返，编辑不丢字段，离线/冲突可恢复。
- 真实 Android WebView 的旋转、键盘、系统边缘、悬浮和休息状态自然体验通过；网页预览不代替真机证据。
- 云端只有密文与必要元数据，密钥/浏览器登录/本机权限不入中枢；真实跨网、离线补同步和恢复完成验证。
- 如纳入远程任务，必须有独立的权限与安全失败路径验收，不以“消息已发送”当“任务完成”。
- 自动验证按改动风险分批进行；候选 APK/Windows 构建与桌面运行保护、分支推送按现有规则。正式版本号和发布时机另定。
